# 데이터베이스 생성하기

총 5단계에 걸쳐 데이터베이스를 생성합니다.

1. 요구사항 분석 (Requirements Analysis)
2. 개념적 설계 (Conceptual Design)
3. 논리적 설계 (Logical Design)
4. 물리적 설계 (Physical Design)
5. 구현 (Implementation)

요구사항 분석: 데이터베이스 사용자에 따른 수행 업무와 필요한 데이터의 종류, 용도, 처리 형태, 흐름, 제약 조건 등을 수집합니다. 

개념적 설계: 현실 세계의 데이터를 추상적으로 표현하는 과정입니다. E-R 모델을 활용합니다.

논리적 설계: 개념적 설계를 바탕으로 DBMS에 종속적인 모델을 생성하는 단계입니다. 관계형 모델을 활용합니다.

물리적 설계: 표 형식의 데이터를 어떻게 하드웨어에 저장하고 관리할 것인지 결정합니다.

구현 단계: DBMS의 데이터 정의어(DDL)를 사용하여 실제 데이터베이스를 생성합니다.
