# E-R 모델

현실 세계를 컴퓨터에서 다루기 위해 현실 세계의 개념들을 개체와 관계로 표현한 모델입니다.

Peter Chen(피터 첸)이 1976년에 제안했습니다. 대표적인 개념적 데이터 모델입니다. 

ER 모델의 3대 구성 요소입니다.

- 개체 (Entity)
- 속성 (Attribute)
- 관계 (Relationship)

개체는 현실 세계의 객체입니다.
속성은 개체가 가진 특성입니다.
관계는 개체들 간의 관계를 의미합니다.
