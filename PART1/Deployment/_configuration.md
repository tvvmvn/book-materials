# 형상 관리 (Configuraton Management)

형상 관리는 소프트웨어의 변경 사항을 관리하기 위한 일련의 활동으로 소프트웨어 개발의 전 단계에 적용됩니다. 소프트웨어 개발의 전체 비용을 줄이고 개발 과정에 존재하는 방해 요인을 최소화하는 것을 목적으로 합니다. 

1. 형상 식별 (Identification)
2. 형상 통제 (Control)
3. 형상 감사 (Auditing)
4. 형상 보고 (Accounting)

형상 식별은 형상 항목(형상관리 대상)을 편리하게 수정하고 추적할 수 있도록 그것에게 이름, 관리 번호 등을 부여하고 관리 체계를 구축하는 단계입니다. 형상 항목은 요구사항 정의서, 설계서, 소스코드, 테스트케이스, 매뉴얼 등 S/W 생애주기에 존재하는 모든 것들이 해당됩니다.

형상 통제는 소프트웨어 변경 요구가 있을 때 형상 통제 위원회(CCB)가 이를 검토하고 반영하는 단계입니다. 수정이 완료된 형상 항목은 추후 변경 요구가 발생할 때 기준선(Baseline)이 됩니다.

형상 감사는 계획된 대로 변경이 이루어졌는지, 요구사항이 정확히 반영되었는지 검증하는 단계입니다.

형상 기록은 형상 관리의 전 단계를 기록하고 보고하는 단계입니다.


# S/W 버전 관리

버전 관리는 형상 관리의 하위 활동으로 소프트웨어의 소스 코드를 관리하는 활동입니다. 다음은 버전 관리에 사용되는 주요 용어들입니다.

- 저장소(Repository)
최신 버전의 파일들과 파일의 변경 내역이 저장되어 있는 곳입니다.

- 가져오기(Import)
빈 저장소에 처음으로 파일을 복사합니다.

- 체크아웃(Check-Out)
프로그램을 수정하기 위해 저장소에서 파일을 받아옵니다.

- 체크인(Check-In)
체크아웃 한 파일의 수정을 완료하고 저장소의 파일을 새로운 버전으로 갱신합니다.

- 커밋(Commit)
체크인을 수행할 때 이전에 갱신된 내용이 있는 경우에 충돌을 알리고 diff 도구를 이용해 수정한 후 갱신을 완료합니다.

- 동기화(Update)
저장소에 있는 최신 버전의 파일로 자신의 작업 공간을 동기화합니다.


# S/W 버전 관리 도구

공유 폴더 방식에서 클라이언트/서버 방식을 거쳐 현대에는 분산 저장소 방식이 널리 사용되고 있습니다. 

- 공유 폴더 방식
- 클라이언트/서버 방식
- 분산 저장소 방식
 

# 공유 폴더 방식

공유 폴더 방식은 버전 관리 자료가 지역 컴퓨터의 공유 폴더에 저장되고 관리되는 방식입니다. 파일의 변경 사항을 데이터베이스에 기록합니다. 
예) SCCS, RCS, PVCS, QVCS

SCCS(Source-Code Control System)은 벨 연구소에서 1972년 개발한 세계 최초의 버전 관리 시스템으로 UNIX 운영체제의 초기 역사를 함께합니다. 지금은 사용되지 않지만 현대 버전 관리의 뿌리와 같은 시스템입니다.

소스 코드에서 변경된 부분만 기록하고 추적하는 방법을 제안했습니다. 이 원리는 현재까지도 동일하게 적용되고 있습니다.


# 클라이언트/서버 방식

클라이언트/서버 방식은 버전 관리 자료가 서버에 저장되고 관리되는 방식입니다. 서버에 문제가 생기면 서버가 복구되기 전까지 다른 개발자와의 협업과 버전 관리가 중단됩니다. 
예) CVS, SVN

SVN(Subversion)은 아파치 소프트웨어 재단에서 2000년에 발표한 오픈소스 버전 관리 도구입니다. CVS의 단점이었던 파일과 디렉터리의 이름 변경과 이동에 관한 제한을 개선했습니다.


# 분산 저장소 방식

분산 저장소 방식은 버전 관리가 하나의 원격 저장소(Remote repository)와 개발자들의 지역 저장소(Local repository)에서 함께 관리되는 방식입니다. 지역 저장소에서도 버전 관리가 가능하기 때문에 원격 저장소에 문제가 생겨도 작업이 중단되지 않습니다.
예) Git, Bitkeeper, Mercurial

Git은 리누스 토발즈가 2005년 리눅스 커널 개발에 사용하기 위해 개발한 버전 관리 도구입니다. 특히 Git의 연장선이자 클라우드 서비스인 Github와의 연동으로 강력한 버전 관리와 협업 기능을 제공합니다. 현재 세계적으로 가장 많이 사용되는 버전 관리 도구입니다.
