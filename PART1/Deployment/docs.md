# 릴리즈 노트 (Release Note)

릴리즈 노트는 소프트웨어 출시(Release) 정보를 사용자와 공유하기 위한 문서입니다. 다음은 주요 릴리즈 노트의 항목들입니다.

- 머릿말 (Header)
- 개요 & 목적
- 수정 및 개선 내용
- 사용자 영향도

다음은 릴리즈 노트 예시입니다.

[Release Note] SmartApp v1.2.0
릴리즈 날짜: 2026-02-13

1. 핵심 업데이트
사용자의 편의를 위한 '다크 모드'가 공식 지원됩니다.

2. 신규 기능 (New Features)
메뉴 내 테마 선택 기능 추가
소셜 로그인(Google, Apple) 연동 지원

3. 버그 수정 (Bug Fixes)
특정 기기에서 앱 실행 시 비정상 종료되던 현상 수정
프로필 이미지 업로드 시 속도가 저하되던 문제 개선

4. 알려진 문제 (Known Issues)
저사양 태블릿 환경에서 다크 모드 전환 시 약 1초간 지연이 발생할 수 있습니다.


# 소프트웨어 매뉴얼 (S/W Manual)

S/W 매뉴얼은 크게 두 종류로 나눌 수 있습니다.

- 설치 매뉴얼 (Installation Manual)
- 사용자 매뉴얼 (User Manual)

설치 매뉴얼은 소프트웨어 설치 방법을 정리한 문서입니다. 설치 시작부터 끝까지 전 단계를 상세히 설명하고 설치 과정에서 발생할 수 있는 문제 상황에 대해 해결책을 제시합니다.

사용자 매뉴얼은 소프트웨어 사용 방법을 정리한 문서입니다. 예를 들어 S/W 실행 방법, 메뉴 설명, 버튼 사용법 등을 다룹니다.
