# 계층 7. 응용 계층

응용 계층은 여러분이 사용 중인 응용 프로그램이 네트워크와 처음으로 만나는 지점입니다. 
 

# 계층 6. 표현 계층

표현 계층은 다음의 3가지 작업을 수행하는 계층입니다.

- 데이터 변환: 다른 데이터 형식을 사용하는 시스템들이 통신할 수 있도록 데이터 형식을 맞춥니다. 
- 압축: 데이터를 빠른 속도로 전송하기 위해 위해 원본 파일을 압축해서 크기를 줄입니다.
- 데이터 암호화: 전송 도중 데이터가 탈취될 수 있는 경우 등에 대비해서 데이터를 암호화합니다.


# 계층 5. 세션 계층

세션 계층은 시스템 간의 연결(세션)을 설정하고 종료하는 일을 담당하는 계층입니다. 


# 계층 4. 전송 계층

데이터 전송(Transport) 방식을 결정하는 계층입니다.
전송할 데이터를 세그먼트(Segment)로 나누고 관리합니다.


# 계층 3. 네트워크 계층

데이터가 목적지에 도달하기 위해서 최적의 경로를 탐색하는 활동(라우팅)을 담당하는 계층입니다.
세그먼트를 패킷(Packet)으로 나누고 관리합니다.


# 계층 2. 데이터 링크 계층

인트라 네트워크 통신에서 전송 흐름과 오류를 제어하는 계층입니다. 대표적으로 스위치(Switch)가 데이터 링크 계층에 포함되는 장비입니다. 스위치는 기기의 하드웨어 주소 (MAC 주소)에 기반해 데이터를 전송합니다.

패킷을 프레임(Frame)으로 나누고 관리합니다.


# 계층 1. 물리 계층

프레임을 비트스트림(Bitstream)으로 변환합니다. 비트스트림은 0과 1로 구성된 데이터로 전기 신호와 비슷합니다.

실제 물리적인 전송 경로(해저 케이블 등)를 통해 전기 신호로 변환된 데이터를 전송하는 계층입니다.

소프트웨어적인 지식보다 기계나 전기 등에 관한 지식이 중요한 계층입니다.


# 응용 해보기

강이지와 고양이가 이메일을 주고받는 과정을 통해 OSI 모델을 이해해봅시다.

응용 계층: 강아지가 이메일 애플리케이션을 통해 고양이에게 이메일을 전송합니다. 이메일을 전송하므로 통신 프로토콜은 HTTP가 아닌 SMTP가 될 것입니다.

프레젠테이션 계층: 강아지의 이메일은 전송 전 안전하게 암호화됩니다. 또한 빠른 전송을 위해 압축됩니다.

세션 계층: 강이지와 고양이가 서로 이메일을 주고받을 수 있도록 연결(세션)을 설정합니다.

전송 계층: 원본 데이터를 여러 개의 조각(Segment)으로 나누고 이메일 데이터에 적합한 전송 방식을 결정합니다.

네트워크 계층: 세그먼트를 더 작은 조각인 패킷으로 나누고 각 패킷의 헤더에 출발지와 목적지의 IP 주소를 작성합니다. 또한 전송 가능한 여러 경로를 탐색한 다음 최적의 경로를 선택합니다.

데이터 링크 계층: 패킷은 이제 프레임(Frame)으로 나뉩니다.

물리 계층: 프레임은 이제 비트스트림로 바뀌고 마침내 전기 신호로 변환된 뒤 해저케이블과 전파 등을 타고 멀리멀리 날아가 고양이에게 날라갑니다.


여기까지 입니다. 수신 과정은 전송 과정과 반대로 하위 계층에서 상위 계층 방향으로 이동하겠죠?
