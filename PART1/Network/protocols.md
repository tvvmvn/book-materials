# 프로토콜 (Protocols)

프로토콜은 네트워크 상에서 원활한 통신을 위해 제안된 통신 표준입니다. 
다음은 프로토콜의 3대 구성 요소입니다.

- 구문(Syntax): 전송 데이터의 구조와 형식을 정의합니다.

- 의미(Semantics): 구문의 의미와 의미에 따른 제어 정보, 기타 협조 사항을 정의합니다.

- 시간(Timing): 전송 속도와 전송 순서를 정의합니다.

프로토콜 정의, 좀 어렵죠? 전화 통화에 비유해봅시다.

구문: 처음 인사, 본문 내용, 작별 인사 순서대로 이야기하세요.
의미: 작별 인사를 하면 전화를 서로 끊기로 합시다.
시간: 너무 빠르게 말하지 마세요.


# 프로토콜의 기능

- 단편화와 재결합 (Segmentation & Reassembly): 큰 데이터를 보낼 때 작게 쪼깨고 받는 쪽에서 다시 합치는 과정입니다.
- 캡슐화 (Encapsulation): 데이터에 헤더를 추가하는 과정입니다.
- 흐름 제어 (Flow Control): 송신측과 수신측의 속도 차이를 조절합니다.
- 오류 제어 (Error Control): 전송 중에 데이터가 바뀌거나 유실되는 경우 재전송을 요청하거나 받는 쪽에서 처리합니다.
- 동기화 (Synchronization): 송/수신 측이 같은 타이밍에 데이터를 읽도록 맞춥니다.
- 순서 제어 (Sequencing): 쪼개서 보낸 패킷들을 순서에 맞게 맞추는 기능입니다.
- 주소 지정(Addressing): 수신할 대상의 주소를 지정합니다.
- 다중화 (Multiplexing): 하나의 통신 회선을 여러 기기나 서비스가 공유하는 기술입니다.
- 경로 제어(Routing): 데이터를 전송할 최적의 경로를 탐색합니다.
