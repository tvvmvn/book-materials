# 경로 제어 (Routing)

라우팅은 데이터를 전송할 최적의 경로(Route)를 결정하는 일입니다. 라우팅은 라우터(Router)가 경로 제어표(Routing Table)에 기반해서 수행합니다. 

라우팅의 이해를 위해 우리 실생활과 연결시켜 봅시다. 자동차 내비게이션 또한 라우팅을 통해 우리에게 실시간으로 최적의 거리를 계산해 줍니다. 다만 여기서는 데이터 전송 경로를 결정하는 것이 아니라 사람의 물리적인 경로를 결정해주는 것이 다르겠지요.

라우팅이 적용되는 범위에 따라 다음의 2가지로 구분합니다.

- IGP
- EGP, BGP


# IGP

내부 게이트웨이 프로토콜 (IGP: Internal Gateway Protocol)은 하나의 자율 시스템(AS) 내부의 라우팅에서 사용되는 프로토콜입니다.

- RIP (Routing Information Protocol)
- OSPF (Open Shortest Path Protocol)

RIP는 홉수(Hop Count)를 기반으로 최적의 경로를 계산하는 알고리즘입니다. 홉(Hop)은 라우터 간의 한번 이동을 의미합니다. 다른 상황은 고려하지 않고 최소 홉수의 경로를 최적의 경로로 판단합니다.

설정이 간편하다는 장점이 있지만 홉수(Hop Count)를 최대 15홉 까지만 설정할 수 있어 대규모 네트워크에서는 사용할 수 없는 프로토콜입니다. 

최단 경로 탐색에 Bellman-Ford 알고리즘이 사용됩니다.

```
<RIP 최적경로 문제>
다음 그림에서 A-F는 라우터이고 각 링크 상의 숫자는 가중치 값을 나타낼 때 RIP를 이용해서 A와 F간의 최적 경로를 쓰세요.
```

OSPF는 RIP의 단점을 해결한 프로토콜로 대규모 네트워크에서 사용됩니다.
노드 간의 거리와 연결 상태 등을 실시간으로 계산해서 최적의 경로를 탐색합니다.
최적 경로 탐색에 Dijkstra 알고리즘을 사용합니다.


# EGP/BGP

EGP(External Gateway Protocol)와 BGP(Border Gateway Protocol)는 자율 시스템(AS) 간의 라우팅에 사용되는 프로토콜 입니다. 
BGP는 EGP의 단점을 보완한 프로토콜로 인터넷의 근간이 되는 프로토콜입니다.
