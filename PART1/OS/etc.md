# UNIX/LINUX 기본 명령어

- chmod
- ls
- mv
- rm
- uname
- fork
...

chmod는 파일의 보호 모드를 설정하고 파일의 사용 허가를 지정합니다.

<!-- 예) [chmod u=rwx abc.txt]
사용자 u에게 abc.txt 파일의 읽기(r), 쓰기(w), 실행(x) 권한을 부여합니다. -->

예제) UNIX 기반 시스템에서 batch.sh 파일에 대해 소유자와 그룹에게는 전체 권한을 주고 기타 사용자에게는 읽기, 실행 권한을 부여하는 명령문을 8진법 숫자를 이용하여 작성하세요.

답: chmod 775 batch.sh
해설: rwxrwxr-x는 8진수로 표현하면 775입니다.


# UNIX/LINUX 환경 변수

환경 변수란 시스템 소프트웨어의 동작에 영향을 미치는 값입니다.

환경 변수를 명령어나 스크립트에서 사용하려면 환경 변수 앞에 $를 입력해야 합니다.
set, env, printenv, setenv 중 하나를 입력하면 모든 환경 변수와 값을 출력합니다.

다음은 주요 환경 변수들입니다.

$HOME: 홈 디렉터리
$USER: 사용자 이름
