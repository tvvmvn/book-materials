# 프로세스 

프로세스(Process)는 실행 중인 프로그램(Program)을 의미합니다. CPU에 의해 처리됩니다.

프로세스 내의 실행 단위를 스레드(Thread)라고 부릅니다. 각 스레드는 프로세스 내에서 자원을 공유하며 함께 일합니다.


# PCB

PCB는 프로세스 제어 블록(Process Control Block)의 약자로 운영체제가 프로세스에 대한 정보를 관리하기 위해 생성하는 데이터입니다. 각 프로세스가 생성될 때 고유한 PCB가 함께 생성됩니다. 

PCB에 저장된 주요 정보들은 다음과 같습니다.

- PID(프로세스 식별자)
- 프로세스의 스케줄링 상태
- PC (Program Counter)
- 레지스터, 메모리 정보


# 프로세스 상태 전이

프로세스가 시스템 내에 존재하는 동안 상태가 변하는 것을 의미합니다. 

<그림 - 프로세스 상태 전이도>

다음은 프로세스의 대표적인 5가지 상태입니다.

- 생성 (New)
- 준비 (Ready)
- 실행 (Run)
- 대기 (Waiting/Blocked)
- 종료 (Terminated)

생성 상태는 프로세스가 새롭게 생성된 상태입니다. 사용을 위해 운영체제의 승인(Admit)을 기다리고 있습니다.

준비 상태는 프로세스가 CPU를 할당받기 위해 큐(Queue)에서 기다리고 있는 상태입니다.

실행 상태는 프로세스가 CPU를 할당받고 일을 하고있는 상태입니다. 스케줄러가 프로세스에게 CPU를 할당하는 과정을 디스패치(Dispatch)라고 합니다. 

선점형 스케줄링인 경우 만약 실행 상태에서 프로세스가 다른 프로세스에 의해 CPU를 뺏기면 준비 상태로 이동합니다.

대기 상태는 프로세스에서 입/출력이 발생해서 프로세스가 잠시 대기 중인 상태입니다. 
입/출력이 완료되면 스케줄러는 프로세스를 준비 상태로 이동시킵니다. 이 과정을 깨움(Wake Up)이라고 합니다.

종료 상태는 프로세스 처리가 완료된 상태입니다.
