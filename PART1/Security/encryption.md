# 암호화

비밀번호, 카드 번호 처럼 중요한 정보를 보호하기 위해 평문(원래 정보)을 암호문(암호화된 정보)으로 만드는 절차를 의미합니다. 반대로 암호문을 평문으로 변화하는 절차를 복호화라고 부릅니다.

- 개인키 암호화 (Private Key Encryption)
- 공개키 암호화 (Public Key Encryption)
- 해시 (Hash)


# 대칭키 암호화

동일한 키(대칭키)로 암호화 및 복호화하는 기법입니다. 처리 속도가 빨라 일반적인 암호화 경우나 데이터를 주고 받는 경우 등 일반적인 상황에서 많이 사용됩니다. 개인키(Private Key) 암호화라고도 부릅니다.

다음의 두가지 방식이 있습니다.

- 스트림 암호화 (Stream Encryption)
- 블록 암호화 (Block Encryption)


# 스트림 암호화

스트림 암호화는 평문과 동일한 길이의 스트림을 생성하고 비트 단위로 암호화하는 방식입니다. 

- TKIP 
- LFSR
- RC4


TKIP은 임시 키 무결성 프로토콜(Temporal Key Integrity Protocol)이라고도 불립니다. 

무선랜(와이파이)의 첫번째 보안 표준인 WEP는 고정키를 사용해 데이터를 암호화하는 RC4 알고리즘을 사용했기 때문에 보안이 취약했습니다. 

다음 보안 표준이었던 WPA에서는 이를 해결하기 위해 TKIP 알고리즘을 채택했습니다.
TKIP은 암호화를 할 때 고정된 키가 아니라 일시적인 키(Temporal Key)를 사용해 보안을 강화했습니다.


# 블록 암호화

한 번에 하나의 데이터 블록을 암호화 하는 방식입니다. 

- DES (Data Encryption Standard)
- AES (Advanced Encryption Standard)
- IDEA (International Data Encryption Algorithm)
- Skipjack
- ARIA/SEED


DES는 1975년 미국 NBS에서 발표한 대칭키 암호화 알고리즘입니다. 보안을 강화한 버전인 3DES (Triple DES)도 있습니다.

AES는 DES에 한계를 느낀 NIST(미국 표준 기술 연구소)가 2001년 발표한 대칭키 암호화 알고리즘으로 현재까지도 가장 널리 사용되고 있습니다. 키 길이에 따라 AES-128, AES-192, AES-256으로 분류됩니다.

IDEA는 스위스의 Lai, Messy가 1990년 개발한 알고리즘으로 PES를 보완한 알고리즘입니다.

Skipjack은 미국의 국가안보국(NSA)에서 개발한 암호화 알고리즘입니다. 음성 통신 장비의 하드웨어(클리퍼 칩)에 내장되어 음성 데이터를 암호화하는데 사용됩니다. 

ARIA와 SEED는 국내에서 개발한 블록 암호화 알고리즘입니다. SEED는 한국인터넷진흥원(KISA)이 1999년 개발했고 ARIA는 국가정보원과 산학연협회가 2004년 개발했습니다. 국내 금융권이나 공공기관에서 표준으로 사용되고 있습니다.


# 비대칭키 암호화

공개키 암호화라고도 불리는 비대칭키 암호화는 데이터를 암호화할 때 사용하는 공개키(Public Key)는 개방하고 복호화에 사용되는 비밀키(Secret Key)는 소유자가 관리합니다. 

복잡한 알고리즘을 사용해서 처리 속도가 느리기 때문에 특별한 경우에 주로 사용합니다.

예를 들어 두 컴퓨터가 안전하게 데이터를 주고받기 위해서는 보내는 쪽에서 데이터를 암호화하고 받는 쪽에서 데이터를 복호화하는 과정을 거칩니다. 보통 많은 데이터를 빠르게 주고받기 때문에 대칭키 암호화 방식으로 암호화/복호화를 합니다.

이를 위해 두 컴퓨터가 사전에 대칭키를 주고받는 과정을 거쳐야 하는데 그 과정에서 대칭키가 탈취될 가능성이 있습니다. 이 때 비대칭키가 대칭키를 안전하게 주고받는 용도로 사용됩니다. 보내는 쪽이 공개키로 비대칭키를 암호화해서 전송하면 받는 쪽에서 비밀키로 복호화는 방식입니다.

대표적인 비대칭키 암호화 기법으로 설계자인 Rivest, Shamir, Adleman의 이니셜을 따서 이름을 지은 RSA가 있습니다. RSA는 큰 숫자를 소인수분해 하기 어렵다는 것에 기반해서 만들어졌습니다.


# 해시 (Hash)

해시는 입력 데이터의 길이와 상관없이 고정된 길이의 복잡한 문자열로 변환하는 절차를 의미합니다. 해시를 수행하는 알고리즘을 해시 알고리즘이라고 부르고 해시 알고리즘에 의해 변환된 데이터를 해시값 또는 해시키라고 부릅니다. 해시값은 복호화가 불가능하기 때문에 해시를 단방향 암호화라고도 부릅니다.

해시의 대표적인 사례로 비밀번호 암호화가 있습니다. 사용자의 비밀번호는 유출의 위험에 대비해 해시값으로 변환되어 데이터베이스에 저장됩니다. 

해시는 데이터의 암호화 뿐만 아니라 정보 보호의 다양한 분야에서 활용됩니다.

- SHA 시리즈
- MD5 (Message Digest-5)
- N-NASH


SHA 시리즈는 미국의 국가안보국(NSA)이 설계하고 NIST(미국 국립표준기술 연구소)가 1993년에 발표한 해시 알고리즘입니다. 과거 표준이었던 SHA-1부터 현재 가장 널리 쓰이는 표준인 SHA-256까지 다양한 종류가 있습니다.

MD5는 R.Rivest가 MD4를 대체하기 위해 1991년 제안한 해시 알고리즘입니다. 

N-NASH는 NTT(일본 전신 전화) 주식회사에서 1989년 발표한 해시 알고리즘입니다.
