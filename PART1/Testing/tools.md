# 테스트 자동화 도구

테스트의 단계나 목적 등에 따라 다양한 테스트 도구가 존재합니다.

- 소스코드 품질 분석 도구
- 단위 테스트 도구
- 인터페이스 검증 도구
- UI 테스트 도구
- 성능 테스트 도구
- 기타 도구들


# 소스코드 품질 분석 도구

프로그램의 소스코드를 테스트하는 도구입니다. 테스트 진행시 프로그램의 실행 여부에 따라 정적/동적 분석 도구로 분류할 수 있습니다.

- 정적 분석 도구: 프로그램을 실행하지 않고 소스 코드 자체를 분석하여 코딩 표준 준수 여부, 잠재적인 결함, 보안 취약점 등을 찾아내는 도구입니다. 테스트 도구로 cppcheck, checkstyle, ccm, cobertuna, SonarQube, pmd 등이 있습니다.

- 동적 분석 도구: 프로그램이 실행중인 상태에서 코드에 존재하는 메모리 누수, 스레드 결함 등을 찾고 분석하는 도구입니다. 테스트 도구로 Avalanche, Valgrind 등이 있습니다


# 단위 테스트(Unit Testing) 도구

코드의 개별 함수/클래스 등 프로그램의 최소 단위를 검증하는 테스트 도구입니다.
테스트 도구로 xUnit 계열의 도구들이 있습니다. xUnit 다음의 테스트 도구들을 통칭하는 용어입니다.

- JUnit : Java 환경에서 사용되는 단위 테스트 도구
- CppUnit : C++ 환경에서 사용되는 테스트 도구
- PyUnit : Python 환경에서 사용되는 테스트 도구
- NUnit : 닷넷(.NET) 환경에서 사용되는 테스트 도구


# 분산 소프트웨어 및 인터페이스 테스트 도구

애플리케이션을 구성하는 여러 서비스 간의 연동(Interface)이 정상적으로 작동하는지 테스트하기 위한 도구입니다.

- STAF (S/W Testing Automation Framework): IBM이 개발한 인터페이스 테스트 도구로, 네트워크로 연결된 수많은 컴퓨터(노드)를 하나의 거대한 테스트 환경으로 묶어주는 테스트 인프라 관리 도구입니다. STAF는 각 노드에 STAF 데몬(Daemon)을 상주시킴으로서 중앙 제어기와 각 노드 간의 통신 채널을 형성합니다.

- FitNesse: 별도의 프로그램 설치없이 브라우저를 통해 사용할 수 있는 웹 기반의 인수 테스트(Acceptance) 프레임워크입니다. 테스트에 표(Table)를 활용하기 때문에 비개발자도 테스트를 수행할 수 있습니다.

- NTAF (NHN Testing Automation Framework): FitNesse의 장점인 협업 기능과 STAF의 장점인 재사용 및 확장성을 통합한 NHN(Naver)의 테스트 프레임워크입니다.

- Postman: GUI 환경에서 API 요청을 전송하고 응답을 수신할 수 있습니다.


# UI 테스트 도구

사용자가 애플리케이션을 사용하는 과정을 분석하고 테스트하는 도구입니다. 예를 들어 URL을 통한 접속, 폼 입력, 버튼 클릭 등 사용자의 일련의 행위들을 시뮬레이션하고 테스트할 수 있습니다.

- Selenium: 가장 많이 쓰이는 웹 테스트 자동화 도구로 다양한 브라우저와 개발 언어를 지원합니다.

- Watir (Web Application Testing In Ruby): Ruby 언어 기반의 테스트 도구로 쉽고 직관적인 문법이 특징입니다. Selenium을 기반으로 작동합니다.

- Cypress / Playwright: 최신 웹 환경에 최적화된 테스트 도구입니다.


# 애플리케이션 감시 도구 

실제 서비스 중인 애플리케이션의 상태를 추적하기 위해 모니터링 기능을 제공하는 도구입니다. APM(Application Performance Management) 도구라고도 불립니다.

- Jennifer: 상용 모니터링 도구로 직관적이고 강력한 UI를 갖추고 있습니다.
- Scouter: LG CNS에서 개발한 오픈소스 모니터링 도구입니다.


# 성능/부하 테스트 도구

애플리케이션의 성능을 측정하기 위해 의도적으로 시스템 부하를 일으키고 조절할 수 있는 테스트 도구입니다.

- JMeter : 자바 기반의 오픈소스 도구로 사용자가 작성한 시나리오에 따라 가상의 사용자를 만들어 서버에 부하를 줍니다. HTTP, FTP, DB 등 다양한 프로토콜을 지원합니다.
