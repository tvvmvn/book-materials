# 기타 테스트 분류 

다음과 같이 다양한 기준에 따라 테스트를 분류할 수 있습니다.

- 프로그램 실행 여부
- 테스트 목적
- 테스트 시각


# 프로그램 실행 여부에 따른 분류

- 정적 테스트 (Static Test)
- 동적 테스트 (Dynamic Test)

정적 테스트는 프로그램을 실행하지 않고 소스코드를 대상으로 실시하는 테스트입니다. 소스 코드에 대한 코딩 표준, 코딩 스타일, 코드 복잡도, 결함 등을 테스트합니다. 
예) 워크스루(Walkthrough), 인스펙션(Inspection)

동적 테스트는 프로그램이 실행 중인 상태에서 실시하는 테스트입니다. 
예) 블랙박스 테스트, 화이트박스 테스트


# 목적에 따른 분류

- 성능 테스트 (Performance Test)
- 회귀 테스트 (Regression Test)
- 강도 테스트 (Stress Test)
- 안전 테스트 (Security Test)
- 회복 테스트 (Recovergy Test)
- 구조 테스트 (Structure Test)
- 병행 테스트 (Parrallel Test)

성능 테스트는 소프트웨어의 성능과 효율성을 진단하는 테스트입니다. 

회귀 테스트는 소프트웨어에 변경이 생겼을 때 새로운 결함이 없는지 확인하는 테스트입니다.

강도 테스트는 실행 중인 소프트웨어에 업무량을 점진적으로 늘려가며 얼마나 잘 견디는지 확인하는 테스트입니다.


# 시각에 따른 분류

- 검증 (Verification)
- 확인 (Validation)

검증은 개발자의 시각에서 제품의 생산 과정을 테스트하는 활동입니다. 제품이 명세서대로 완성됐는지 확인합니다.

확인은 사용자의 시각에서 생산된 제품의 결과를 테스트하는 활동입니다. 사용자가 요구한 대로 제품이 완성됐는지 테스트합니다.
