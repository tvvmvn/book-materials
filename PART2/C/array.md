# 배열

배열은 여러 개의 값을 가질 수 있는 자료형입니다. 예를 들어 여러가지 과일을 담을 수 있는 과일 바구니 같은 역할을 합니다. 다음은 배열을 생성하는 문법입니다

```
자료형 배열이름[배열의 크기] = {배열의 각 요소}
```


# 배열 생성하기

배열의 크기는 배열을 먼저 선언하고 값을 나중에 할당하고 싶을 때 필요합니다.  배열의 각 요소는 콤마로 구분합니다. 다음은 3개의 요소로 이루어진 정수 배열입니다.

```c
#include <stdio.h>

int main() {
  int arr[] = {10, 20, 30};

  printf("");

  return 0;
}
```


# 요소에 접근하기

배열의 요소는 고유한 인덱스(index)를 가지고 있습니다. 첫번째 요소의 인덱스는 0이며 뒤로 갈수록 1씩 증가합니다. 요소에 접근 시에 사용됩니다.

다음은 3개의 요소로 이루어진 정수 배열입니다.

```c
#include <stdio.h>

int main() {
  int arr[] = {10, 20, 30};

  printf("%d\n", arr[0]);
  printf("%d\n", arr[1]);
  printf("%d\n", arr[2]);
  
  return 0;
}
```


# 요소 바꾸기

요소에 접근하는 경우와 마찬가지로 인덱스를 활용해 요소를 바꿀 수 있습니다.
<!-- e.g) bubble sort -->

```c
int myNumbers[] = {25, 50, 75, 100};

myNumbers[0] = 33;

printf("%d", myNumbers[0]); // 33
```


# 요소 개수 구하기

다음은 정수형 배열의 요소 개수를 구하는 과정입니다. C 언어에서 정수형 변수의 크기는 4바이트 입니다. 아래 배열은 4개의 정수로 구성되었으므로 16바이트의 크기를 가집니다. 따라서 배열의 크기를 정수형 변수의 크기로 나누어 주면 요소의 개수를 구할 수 있습니다.

```c
int myNumbers[] = {10, 25, 50, 75};
int length = sizeof(myNumbers) / sizeof(myNumbers[0]);
// 16 / 4 = 4

printf("%d", length);  // 4
```


# 2D 배열 (2 Dimentional Array)

행과 열을 가지는 테이블을 표현할 수 있습니다.
아래는 3행 2열 테이플입니다.

```c
#include <stdio.h>

int main() {
  // coordinates
  int crds[3][2] = {{100, 120}, {90, 100}, {110, 100}};
  
  printf("%d %d\n", crds[0][0], crds[0][1]);
  printf("%d %d\n", crds[1][0], crds[1][1]);
  printf("%d %d\n", crds[2][0], crds[2][1]);
}

// 100 120 
// 90 100 
// 110 100 
```
