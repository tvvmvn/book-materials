# 산술 연산자

산술 연산자는 수학적인 연산을 수행합니다.

- + (더하기): 두 수를 더합니다
- - (빼기): 앞에 수에서 뒤의 수를 뺍니다
- * (곱하기): 두 수를 곱합니다
- / (나누기): 앞의 수를 뒤의 수로 나눕니다
- % (나머지 연산자): 앞의 수를 뒤의 수로 나누고 나머지를 반환합니다


```c
#include <stdio.h>

int main() {
  int a = 5;
  int b = 2;

  printf("%d\n", a + b); //7
  printf("%d\n", a - b); //3 
  printf("%d\n", a * b); //10
  printf("%d\n", a / b); //2
  printf("%d\n", a % b); //1
}
```
