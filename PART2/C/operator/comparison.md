# 비교 연산자

두 값을 비교하는 연산을 수행합니다. 불리언 타입의 값을 반환합니다

1. == (동등 연산자): 두 값이 같으면 참, 다르면 거짓을 반환합니다.
2. != (비동등 연산자): 두 값이 다르면 참, 같으면 거짓을 반환합니다.
3. > (gt 연산자): 왼쪽의 숫자가 크면 참, 작으면 거짓을 반환합니다.
4. < (lt 연산자): 왼쪽의 숫자가 작으면 참, 크면 거짓을 반환합니다.
5. >= (gte 연산자): 왼쪽의 숫자가 더 크거나 같으면 참, 아니면 거짓을 반환합니다.
6. <= (lte 연산자): 왼쪽의 숫자가 작거나 같으면 참, 아니면 거짓을 반환합니다.


```c
#include <stdio.h>

int main() {
  int a = 1;
  int b = 2;

  printf("%d\n", a == b); //0
  printf("%d\n", a != b); //1
  printf("%d\n", a > b); //0
  printf("%d\n", a < b); //1
  printf("%d\n", a >= b); //0
  printf("%d\n", a <= b); //1
}
```
