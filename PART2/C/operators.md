# 산술 연산자

산술 연산자는 수학적인 연산을 수행합니다.

- + (더하기): 두 수를 더합니다
- - (빼기): 앞에 수에서 뒤의 수를 뺍니다
- * (곱하기): 두 수를 곱합니다
- / (나누기): 앞의 수를 뒤의 수로 나눕니다
- % (나머지 연산자): 앞의 수를 뒤의 수로 나누고 나머지를 반환합니다
- 증감/감소 연산자: 변수를 1 증가 또는 감소시킵니다

```c
#include <stdio.h>

int main() {
  int a = 5;
  int b = 2;

  printf("%d\n", a + b); //7
  printf("%d\n", a - b); //3 
  printf("%d\n", a * b); //10
  printf("%d\n", a / b); //2
  printf("%d\n", a % b); //1
}
```


# 증감/감소 연산자

증감 연산자: 변수를 1 증가시킵니다. 증감 연산자가 앞에 붙는 경우와 뒤에 붙는 경우에는 미세한 차이가 있습니다. 
예) 변수++, ++변수


```c
#include <stdio.h>

int main() {
  int a = 1;
  int b = 1;

  printf("a=%d, b=%d\n", ++a, b++);

  printf("a=%d, b=%d\n", a, b);
}

//a=2, b=1
//a=2, b=2
```

감소 연산자: 변수를 1 감소시킵니다. 감소 연산자가 앞에 붙는 경우와 뒤에 붙는 경우에는 미세한 차이가 있습니다.
예) 변수--, --변수

```c
#include <stdio.h>

int main() {
  int a = 1;
  int b = 1;

  printf("a=%d, b=%d\n", --a, b--);

  printf("a=%d, b=%d\n", a, b);
}

//a=0, b=1
//a=0, b=0
```


# 대입 연산자

변수에 값을 대입하는 연산을 수행합니다.

1. 기본 대입 연산자

= (변수 대입 연산자) x = 1 처럼 변수에 값을 할당할 때 사용합니다
+= (더하기 대입 연산자) x += y는 x = x + y와 같습니다
-= (빼기 대입 연산자) x -= y는 x = x - y와 같습니다
*= (곱하기 대입 연산자) x *= y는 x = x * y와 같습니다
/= (나누기 대입 연산자) x /= y는 x = x / y와 같습니다
%= (나머지 대입 연산자) x %= y는 x = x % y와 같습니다

2. 비트 연산용 대입 연산자

&= (비트and 대입 연산자) x &= y 는 x = x & y와 같습니다
|= (비트or 대입 연산자) x |= y 는 x = x | y와 같습니다
^= (비트xor 대입 연산자) x ^= y 는 x = x ^ y와 같습니다
<<= (왼쪽 시프트 대입 연산자) x <<= y 는 x = x << y와 같습니다
>>= (오른쪽 시프트 대입 연산자) x >>= y 는 x = x >> y와 같습니다


```c
#include <stdio.h>

int main() {
  int n = 1;

  n += 2;

  printf("%d", n);
}

//3
```


# 비교 연산자

두 값을 비교하는 연산을 수행합니다. 불리언 타입의 값을 반환합니다

== (동등 연산자): 두 값이 같으면 참, 다르면 거짓을 반환합니다.
!= (비동등 연산자): 두 값이 다르면 참, 같으면 거짓을 반환합니다.
> (gt 연산자): 왼쪽의 숫자가 크면 참, 작으면 거짓을 반환합니다.
< (lt 연산자): 왼쪽의 숫자가 작으면 참, 크면 거짓을 반환합니다.
>= (gte 연산자): 왼쪽의 숫자가 더 크거나 같으면 참, 아니면 거짓을 반환합니다.
<= (lte 연산자): 왼쪽의 숫자가 작거나 같으면 참, 아니면 거짓을 반환합니다.


```c
#include <stdio.h>

int main() {
  int a = 1;
  int b = 2;

  printf("%d\n", a == b); //0
  printf("%d\n", a != b); //1
  printf("%d\n", a > b); //0
  printf("%d\n", a < b); //1
  printf("%d\n", a >= b); //0
  printf("%d\n", a <= b); //1
}
```


# 논리 연산자

논리 연산을 수행합니다. 참 또는 거짓을 반환합니다.

- && (and): 앞과 뒤가 모두 맞으면 참, 하나라도 다르면 거짓을 반환합니다.
- || (or): 앞과 뒤 중에서 하나라도 맞으면 참, 둘 다 틀리면 거짓을 반환합니다
- ! (not): 참과 거짓을 뒤집습니다.

```c
#include <stdio.h>

int main() {
  int a = 1 > 0;
  int b = 1 < 0;

  printf("%d\n", a && b);
  printf("%d\n", a || b);
  printf("%d\n", !b);
}

// 0
// 1
// 1
```


# 비트 연산자

비트 연산자는 비트 단위의 연산을 수행합니다. 매우 빠른 속도

- & (and) &는 둘다 1이면 1을 반환합니다.
- | (or) |는 둘중에 하나가 1이면 1을 반환합니다
- ^ (xor) ^은 둘이 다르면 1을 반환합니다.
- ~ (not) ~(not)은 비트를 뒤집습니다.
- << (왼쪽 시프트 연산자): 왼쪽 끝에 입력한 숫자만큼 0을 집어넣습니다
- >> (오른쪽 시프트 연산자): 오른쪽 끝에 rightmost을 입력한 숫자만큼 집어넣습니다.


```c
#include <stdio.h>

int main() {
  int a = 10; // 0000 1010
  int b = 12; // 0000 1100

  printf("and: %d\n", a & b);// 0000 1000
  printf("or: %d\n", a | b);// 0000 1110
  printf("xor: %d\n", a ^ b);// 0000 0110
  printf("not: %d\n", ~a);// 1111 0101
  printf("left shift: %d\n", a << 1);// 0001 0100
  printf("right shift: %d\n", a >> 1);// 0000 0101

  return 0;
}

// and: 8
// or: 14
// xor: 6
// not: -11
// left shift: 20
// right shift: 5
```
