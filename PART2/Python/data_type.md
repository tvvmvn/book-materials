# 시퀀스 (Sequences)

- 순회 가능
- len() 함수 사용 가능
- 멤버쉽 연산자 사용 가능
- 언패킹 가능

시퀀스는 일련의 값들이 순서대로 저장되어있어 Indexing, Slicing 가능합니다.
연결(+), 반복(*) 연산자 사용이 가능합니다.

List (가변)
String (불변)
Tuple (불변)


# Set & Map

- 순회 가능
- len() 함수 사용 가능
- 멤버쉽 연산자 사용 가능
- 가변

Set: 수학의 집합(Set)을 구현한 자료형입니다. 강력한 집합 연산을 기능을 제공합니다.

Dictionary(Map): 각 데이터가 키-값 쌍(Key-Value Pair)으로 이루어진 자료형입니다. 검색 속도가 매우 빠른 것이 특징입니다.
