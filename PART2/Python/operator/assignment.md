# 대입 연산자

변수에 값을 할당하는 연산을 수행합니다


# 기본 대입 연산자

1. = (대입 연산자)
변수에 값을 대입합니다.
예) x = 1 

2. += (더하기 대입 연산자)
예) x += y 는 x = x + y 와 같습니다

3. -= (빼기 대입 연산자)
예) x -= y 는 x = x - y 와 같습니다

4. *= (곱하기 대입 연산자)
예) x *= y 는 x = x * y 와 같습니다

5. /= (나누기 대입 연산자)
예) x /= y 는 x = x / y 와 같습니다

6. %= (나머지 대입 연산자)
예) x %= y 는 x = x % y 와 같습니다

7. //= (몫 대입 연산자)
예) x //= y 는 x = x // y 와 같습니다

8. **= (거듭 제곱 연산자)
예) x **= y 는 x = x ** y 와 같습니다


# 비트 연산용 대입 연산자

1. &= (비트and 대입 연산자)
예) x &= y 는 x = x & y 와 같습니다

2. |= (비트or 대입 연산자)
예) x |= y 는 x = x | y 와 같습니다

3. ^= (비트xor 대입 연산자)
예) x ^= y 는 x = x ^ y 와 같습니다

4. >>= (오른쪽 시프트 대입 연산자)
예) x >>= y 는 x = x >> y와 같습니다

5. <<= (왼쪽 시프트 대입 연산자)
예) x <<= y 는 x = x << y 와 같습니다
