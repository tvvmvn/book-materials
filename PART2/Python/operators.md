# 연산자

Python divides the operators in the following groups:

1. 산술 연산자 (Arithmetic Operator)
2. 대입 연산자 (Assignment Operator)
3. 비교 연산자 (Comparison Operator)
4. 논리 연산자 (Logical Operator)
5. 식별 연산자 (Identity Operator)
6. 멤버 연산자 (Member Operator)
7. 비트 연산자 (Bit operator)

# 산술

수학적 연산을 수행할 때 사용됩니다.

1. +(더하기) 덧셈 연산을 수행합니다
예) 1 + 2 = 2

2. -(빼기) 빼기 연산을 수행합니다
예) 5 - 2  = 3

3. *(곱하기) 곱하기 연산을 수행합니다
예) 5 * 2 = 10

4. /(나누기) 나누기 연산을 수행합니다
예) 5 / 2 = 2.5

5. //(몫) 나눗셈을 수행 후 몫을 구합니다
예) 5 // 2 = 2

6. %(나머지) 나눗셈을 수행 후 나머지를 구합니다
예) 5 % 2 = 1

7. **(거듭제곱) 거듭 제곱 연산을 수행합니다
예) 5 ** 2 = 25


# 대입 연산자

변수에 값을 할당하는 연산을 수행합니다


# 기본 대입 연산자

1. = (대입 연산자)
변수에 값을 대입합니다.
예) x = 1 

2. += (더하기 대입 연산자)
예) x += y 는 x = x + y 와 같습니다

3. -= (빼기 대입 연산자)
예) x -= y 는 x = x - y 와 같습니다

4. *= (곱하기 대입 연산자)
예) x *= y 는 x = x * y 와 같습니다

5. /= (나누기 대입 연산자)
예) x /= y 는 x = x / y 와 같습니다

6. %= (나머지 대입 연산자)
예) x %= y 는 x = x % y 와 같습니다

7. //= (몫 대입 연산자)
예) x //= y 는 x = x // y 와 같습니다

8. **= (거듭 제곱 연산자)
예) x **= y 는 x = x ** y 와 같습니다


# 비트 연산용 대입 연산자

1. &= (비트and 대입 연산자)
예) x &= y 는 x = x & y 와 같습니다

2. |= (비트or 대입 연산자)
예) x |= y 는 x = x | y 와 같습니다

3. ^= (비트xor 대입 연산자)
예) x ^= y 는 x = x ^ y 와 같습니다

4. >>= (오른쪽 시프트 대입 연산자)
예) x >>= y 는 x = x >> y와 같습니다

5. <<= (왼쪽 시프트 대입 연산자)
예) x <<= y 는 x = x << y 와 같습니다

# 논리 연산자

논리 연산을 수행하고 불리언 타입으로 결과를 반환합니다

1. and 앞과 뒤가 모두 맞으면 참, 하나라도 다르면 거짓을 반환합니다.
예) x < 5 and x < 10

2. or 둘 중에 하나 이상 맞으면 참, 둘 다 틀리면 거짓을 반환합니다
예) x < 5 or x < 4

3. not 참과 거짓을 뒤집습니다.
예) not (1 > 0) 는 결과적으로 거짓을 반환합니다



# 멤버십 연산자

컬렉션 자료형에서 특정 값의 포함 여부를 검사하고 불리언 타입의 값을 반환합니다


# in

in은 검사 대상이 컬렉션에 포함됬는지 검사합니다. 

```python
fruits = ["apple", "banana", "cherry"]

print("banana" in fruits) # True
print("mango" in fruits) # False
```


# not in

not in은 검사 대상이 컬렉션에 포함되지 않았는지 검사합니다

```python
fruits = ["apple", "banana", "cherry"]

print("apple" not in fruits) # False
print("mango" not in fruits) # True
```


# 식별 연산자

단순히 두 객체의 값을 비교하는 연산이 아니라 메모리 상의 위치를 비교합니다. 검사 결과를 불리언 타입의 값으로 반환합니다. 다음의 두 종류가 있습니다.


# is

is는 두 값이 메모리 상에서 같은 곳에 위치하는지 검사합니다.
아래의 코드에서 a와 b는 같은 값을 가지고 있지만 별도로 생성된 변수입니다. 반면 c는 a를 대입했으므로 c와 a는 메모리 위치를 공유합니다

```py
a = [0, 1]
b = [0, 1]
c = a

print(a == b) # True
print(a is b) # False
print(a is c) # True
```


# is not

is not는 두 값이 메모리 상에서 다른 곳에 위치하는지 검사합니다

```python
a = [0, 1]
b = [0, 1]

print(a is not b) # True
```
