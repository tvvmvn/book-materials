# 춭력

- print
- end


# print

```py
print('hello world')

# hello world
```


# comma

콤마로 여러개의 입력값을 구분할 수 있습니다. 이 경우 출력할 때 띄어쓰기 처리합니다.

```py
print('hello', 'world')

# hello world
```


# row

보통 print 함수로 출력하면 한 줄을 모두 차지해서 다음 출력값은 자동으로 다음줄에서 출력됩니다. 만약 줄바꿈을 원하지 않는 경우 'end'를 사용하면 됩니다.

```py
print('hello', end = ' ')
print('world')

# 
# hello world
```
