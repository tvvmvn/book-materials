# Range

Range는 수정할 수 없는 숫자의 모음들로 구성된 자료 구조입니다.
주로 기본 반복문을 생성할 때 사용됩니다.

생성자로 Range를 생성합니다. 문법은 다음과 같습니다
```
range(시작, 끝, 간격)

- 시작: 기본값은 0입니다
- 끝(필수): 
- 간격: 기본값은 1입니다

시작부터 끝 - 1 까지 정해진 간격으로 숫자 모음을 생성합니다.
모든 인수값은 정수여야 합니다
```


# 생성하기

다음은 Range를 만드는 기본 과정입니다.
range는 출력할 때 내부의 원소를 볼 수 없습니다.

```python
print(range(5))
print(range(1, 5))
print(range(1, 5, 2))

# range(0, 5)
# range(1, 5)
# range(1, 5, 2)
```


# 사용 사례

기본 반복문을 만들 때 사용됩니다.

```py
for i in range(5):
  print(i, 'times exeucted')
```
