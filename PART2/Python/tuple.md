# Tuple

튜플은 읽기전용(read-only) 시퀀스입니다. 
즉 한번 생성하고 난 뒤에 요소의 추가/삭제/수정이 불가능합니다.


# 튜플 생성하기

소괄호 안에 값들을 나열하고 콤마로 구분합니다. 소괄호는 생략 가능합니다.
만약 튜플을 이루는 요소가 하나라면 값 뒤에 콤마(,)를 찍어야 합니다. 그렇지 않으면 파이썬이 튜플이 아니라 하나의 값으로 인식합니다.

```python
t1 = (100, 200)
t2 = 100, 200
t3 = (300,)

print(t1)# (100, 200)
print(t2)# (100, 200)
print(t3)# (300,)
```
