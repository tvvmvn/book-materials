# INSERT INTO

INSERT INTO는 테이블에 레코드를 추가하는 명령어입니다. 

```sql
INSERT INTO 테이블_이름 (컬럼1, 컬럼2, 컬럼3, ...)
VALUES (컬럼1 값, 컬럼2 값, 컬럼3 값, ...);
```
삽입하지 않은 컬럼의 값은 자동으로 NULL이거나 기존에 지정한 기본값이 적용됩니다.
삽입문에서 만약 모든 컬럼을 삽입한다면 컬럼 이름을 생략할 수 있습니다.


# 적용하기

예제) 이름, 학년, 성별, 이메일 등 4개의 컬럼으로 구성된 테이블 <학생>이 있을 때

이름(김철수), 성별('남'), 이메일(kim@example.com) 데이터를 삽입하세요.
```sql
INSERT INTO 학생 (이름, 성별, 이메일) VALUES ('김철수', '남', 'kim@example.com');
```

이름(김철수), 학년(1), 성별(남), 이메일(kim@example.com) 데이터를 삽입하세요.
```sql
INSERT INTO 학생 VALUES ('김철수', 1, '남', 'kim@example.com');
```
