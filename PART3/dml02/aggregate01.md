# 집계 함수

테이블의 각 레코드들을 대상으로 여러 연산을 수행할 수 있습니다. 
GROUP BY (HAVING) 명령어를 추가해서 레코드 그룹을 대상으로 연산을 할 수도 있습니다.

```sql
SELECT 집계_함수 FROM 테이블 
```

다음은 집계 함수의 종류입니다.

- MIN
- MAX
- COUNT
- SUM
- AVG


# MIN & MAX

레코드들로부터 제시한 컬럼의 최소값과 최대값을 구하는 함수입니다.

예제) <제품>테이블에서 가장 비싼 상품의 가격을 조회하세요.
```sql
SELECT MAX(가격) FROM 제품;
```


# COUNT()

주어진 컬럼을 포함한 레코드의 개수를 세는 함수입니다. 
COUNT는 집계 함수 중 예외적으로 *(와일드카드) 인자를 가질 수 있습니다. 

예제) <제품>에서 총 레코드의 개수를 조회하세요.
```sql
SELECT COUNT(*) FROM 제품;
```

예제) 테이블 <제품>에서 총 레코드의 개수를 조회하세요. ('제품명'이 NULL인 레코드는 포함하지 않습니다)
```sql
SELECT COUNT(제품명) FROM 제품;
```


# SUM()

레코드들로부터 주어진 컬럼의 합을 구하는 함수입니다.

예제) 다음은 <제품>으로부터 제품의 총 판매량을 조회하세요.
```sql
SELECT SUM(판매량) FROM 제품;
```


# AVG()

레코드들로부터 주어진 컬럼의 평균을 구하는 함수입니다.

예제) 테이블 <제품>으로부터 모든 제품의 평균 가격을 조회하세요.
```sql
SELECT AVG(가격) FROM 제품;
```
