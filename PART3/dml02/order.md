# ORDER BY

추출할 레코드의 순서를 정렬하는 명령어입니다. 정렬 명령을 따로 명시하지 않으면 ASC가 적용됩니다. 

```sql
... FROM 테이블 
ORDER BY 컬럼1 ASC/DESC, 컬럼2 ASC/DESC, ..

ASC: 문자는 알파벳순(A-Z), 숫자는 오름차순(1-9)으로 정렬됩니다.
DESC: 문자는 역알파벳순(Z-A), 숫자는 내림차순(1-9)으로 정렬됩니다.
```


예제) <학생> 테이블에서 '이름'을 기준으로 알파벳순으로 정렬하고 조회하세요.
```sql
SELECT * FROM 학생 ORDER BY 이름;
```

예제) <학생>에서 '이름'을 기준으로 역알파벳순으로 정렬하고 조회하세요.
```sql
SELECT * FROM 학생 ORDER BY 이름 DESC;
```

예제) <학생>에서 먼저 '이름'을 기준으로 정렬하고 '이름'이 같은 레코드 그룹에서 '생년월일'을 기준으로 정렬하고 조회하세요.
```sql
SELECT * FROM 학생 ORDER BY 이름, 생년월일;
```

예제) '이름'을 기준으로 알파벳순으로 정렬하고 '이름'이 같은 레코드 그룹에서 '생년월일'을 기준으로 내림차순 정렬하고 조회하세요.
```sql
SELECT * FROM 학생
ORDER BY 이름 ASC, 생년월일 DESC;
```
