# 별칭 (Alias)

명령문을 작성할 때 컬럼과 테이블을 조작자가 원하는 대로 이름(별칭)을 지을 수 있습니다. 기존의 컬럼/테이블의 이름이 길거나 읽기 어려운 경우 별칭을 사용하면 효과적입니다. 

- 컬럼 별칭
- 테이블 별칭


# 컬럼 별칭

```sql
... 컬럼이름 AS 별칭

AS는 생략 가능합니다. 띄어쓰기 하면
```

예제)
<제품>테이블에서 '제품ID'를 'ID', '제품명'을 '이름'으로 조회하세요.
```sql
SELECT 제품ID AS ID, 제품명 AS 이름
FROM 제품;
```


# 테이블 별칭

테이블 별칭은 명령문에서 테이블 이름을 여러번 언급해야 할때 효과적입니다.

```sql
테이블 AS 별칭;
```

테이블 별칭이 없는 경우와 있는 경우 두가지를 비교해봅시다. 별칭이 있는 경우가 더 짧은 문장이라는 것을 알 수 있습니다

예제) <학생>, <전공>를 활용하여 1학년 학생들을 그들이 가입한 전공 정보와 함께 조회하세요.
```sql
SELECT * FROM 학생 JOIN 전공
ON 학생.전공ID = 전공.전공ID
WHERE 학생.학년 = 1;
```

예제) <학생>, <전공>를 활용하여 1학년 학생들을 그들이 가입한 전공 정보와 함께 조회하세요. 이때 학생의 별칭은 s, 전공의 별칭은 c를 적용하세요.
```sql
SELECT * FROM 학생 AS s JOIN 전공 AS c
ON s.전공ID = c.전공ID;
WHERE s.학년 = 1;
```
