# 조인 (Join)

- 내부 조인 (Inner Join)
- 외부 조인 (Outer Join)


# 내부 조인

두 테이블을 대상으로 교차곱을 수행한 다음 ON에 명시된 조건을 만족하는 레코드를 추출합니다.

```sql
... FROM 테이블1 JOIN 테이블2
ON 테이블1.컬럼 = 테이블2.컬럼;
```

예제) 다음과 같이 <학생>, <학과> 테이블이 있을 때 학생들을 각자가 속한 학과 정보와 함께 조회하세요.
```sql
SELECT 학번, 이름, 학과.학과ID, 학과명 
FROM 학생 JOIN 학과 
ON 학생.학과ID = 학과.학과ID;
```
주의! 컬럼을 선택할 때 '학과.학과ID'라고 하는 이유는 학과ID가 <학생>, <학과> 두 군데 모두 있기 때문입니다. 두 테이블 중 하나를 적으면 됩니다.(출력 결과는 차이 없음)


# 외부 조인

- LEFT JOIN
- RIGHT JOIN
- FULL JOIN


# LEFT JOIN

INNER JOIN을 수행하고 왼쪽 테이블에서 빠진 레코드들도 포함시킵니다. 이렇게 포함된 왼쪽 레코드들은 오른쪽 테이블에 속한 컬럼값으로 NULL을 가집니다.

```sql

```

예제) 다음과 같이 <학생>, <학과> 테이블이 있을 때 학생들을 각자가 속한 학과 정보와 함께 조회하세요. 단 학과에 가입하지 않은 학생도 포함시키세요.
```sql
SELECT 학번, 이름, 학과.학과ID, 학과명 
FROM 학생 LEFT JOIN 학과 
ON 학생.학과ID = 학과.학과ID;
```


# RIGHT JOIN

INNER JOIN을 수행 후 오른쪽 테이블에서 빠진 레코드들을 포함시킵니다. 이렇게 포함된 오른쪽 레코드들은 왼쪽 테이블에 속한 컬럼값으로 NULL을 가집니다.

```sql
...
FROM 테이블1 RIGHT JOIN 테이블2
ON 테이블1.컬럼 = 테이블2.컬럼;
```


# FULL JOIN

INNER JOIN 결과에 왼쪽 테이블과 오른쪽 테이블에서 빠진 레코드들도 포함시키는 명령어입니다. 이렇게 추가된 레코드들에서 반대편에 속한 컬럼들은 NULL 값을 가집니다.

```sql
...
FROM 테이블1 FULL JOIN 테이블2
ON 테이블1.컬럼 = 테이블2.컬럼;
```
