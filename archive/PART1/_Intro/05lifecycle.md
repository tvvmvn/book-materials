# S/W 생애주기란

소프트웨어를 개발하기 위해 `설계부터 유지/보수까지의 과정`을 각 단계별로 나눈 것이다.

*주요 모형*

- 폭포수 모형
- 나선형 모형
- 프로토타입 모형


소프트웨어 생명주기의 개념 이해를 돕기 위해 의자를 만드는 과정에 비유해봅시다.
즉 '의자의 생명주기'와 같습니다

1. 요구사항
디자이너, 공장, 판매자 등이 각자의 요구 사항 (계획)
을 가지고 회의하고 통합된 요구사항을 도출합니다

2. 설계
생산에 들어가기에 앞서 요구사항을 토대로 의자의 설계도를 작성합니다

3. 개발 / 테스트 
프로토 타입을 개발하여 여러번의 테스트를 거친후
최종적으로 의자 완성

4. 패키징 
판매하기 위해 의자를 패키징(포장)

5. 배포
판매를 위해 전국의 매장으로 배포됩니다

6. 유지 / 보수 
판매가 완료된 뒤에도 판매자는 일정 기간동안 A/S 를 제공해야합니다
