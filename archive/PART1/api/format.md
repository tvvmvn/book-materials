# API 데이터 교환에 사용되는 포멧

XML/JSON


### XML

eXtensible Markup Language.  
특수한 목적을 갖는 마크업 언어를 만드는데 사용되는 다목적 마크업 언어.  
사용자가 직접 태그를 지정할 수 있다. 트리 구조

```
<data></data>
```

### JSON

JavaScript Object Notation.  
데이터 객체를 속성/값의 쌍 (Attrubute-Value pairs) 형태로 표현하는
개방형 표준 포멧.  
비동기 작업에서 사용되는 AJAX에서 XML을 대체하고 있다.

```
{ "key": "value" }
```
