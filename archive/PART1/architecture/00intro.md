## S/W 아키텍처 설계의 4가지 기본원리

1. 모듈화 (Modularity)
2. 추상화 (Abstraction)
3. 단계적 분해 (Stepwise Refinement)
4. 정보 은닉 (Information Hiding)

**모듈화** 작고 독립적인 모듈을 만들고 그 모듈들을 조립하여 큰 프로그램을 만든다.  
개발 및 수정, 유지보수가 용이해진다.  
모듈은 작게는 하나의 객체, 함수일 수 있고 크게는 하나의 시스템일 수도 있다.

```
예를 들어볼까요? 스마트폰이 있습니다. 스마트폰은 여러개의 독립적인
모듈들의 조합입니다. 카메라 모듈, 배터리 모듈, 디스플레이 모듈 등 말이죠.
```

**추상화** 추상적인 개념을 먼저 설계 후 구체적인 내용을 만들어간다.
과정의 추상화, 자료의 추상화, 제어의 추상화 등이 있다

**단계적 분해** 상위 모듈에서 시작하여 하위 모듈을 설계해나간다.

**정보 은닉** 모듈의 내부 자료를 숨기는 것.  
정해진 인터페이스로만 통신 가능  
모듈 간의 결합도가 감소하고 보안성이 증가한다.

```
예를 들어, 여러분에게 거액의 현금이 있다면 아무곳에나 두지 않고 
안전한 금고에 저장하려고 할 것입니다. 그리고 아무나 접근할 수 없도록 
복잡한 비밀번호(정해진 인터페이스)를 설정하려고 하겠죠?
```
