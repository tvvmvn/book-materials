## 결합도 (Coupling)

모듈 간에 상호 의존하는 정도.  
결합도가 낮을수록 품질이 높다.  

*종류*

1. 자료 결합도
2. 검인 결함도
3. 제어 결합도
4. 외부 결합도
5. 공통 결합도
6. 내용 결합도


**자료결합도** 모듈 간의 인터페이스가 자료 요소로만 구성될 때의 결합도.

**검인 결합도** 모듈 간의 인터페이스로 배열이나 레코드 등의 자료 구조가
전달 될 때의 결합도

**제어 결합도** 어떤 모듈이 다른 모듈 내부의 논리적인 흐름을 제어하기위해
제어 신호나 제어 요소를 전달할 때 결합도

**외부 결합도** 어떤 모듈에서 선언한 변수를 외부의 다른 모듈에서 참조할 때 결합도

**공통 결합도** 공유되는 데이터를 여러 모듈이 사용할 때 결합도

**내용 결합도** 한 모듈이 다른 모듈 내부의 기능 및 자료를 직접
참조하거나 수정할 때 결합도


## 응집도 (Cohesion)

모듈 내부의 요소들이 서로 관련된 정도.  
응집도가 높을수록 품질이 높다.  

*종류*

1. 우연적 응집도
2. 논리적 응집도
3. 시간적 응집도
4. 절차적 응집도
5. 교환식 응집도
6. 순차적 응집도
7. 기능적 응집도


**우연적 응집도** 서로 관련없는 요소로만 구성 된 경우 응집도

**논리적 응집도** 유사한 성격/형태를 갖는 요소들로 구성 된 경우 응집도

**시간적 응집도** 특정 시간에 처리되는 요소들로 구성된 경우 응집도

**절차적 응집도** 요소들이 모듈의 기능을 순차적으로 처리하는 경우 응집도

**통신적 응집도** 동일한 입/출력을 사용하여 서로 다른 기능을 수행하는 요소들이 모인 경우 응집도

**순차적 응집도** 특정 작업에 대한 모듈의 출력 데이터를 다음 작업의
입력데이터로 사용할 경우 응집도

**기능적 응집도** 요소들이 단일 문제의 해결을 수행하는 경우 응집도


## Fan in / Fan Out

### Fan In 

한 모듈로 들어오는 모듈의 수.  
한 모듈을 제어하는 모듈의 수 

### Fan Out

한 모듈에서 나가는 모듈의 수.  
한 모듈이 제어하는 모듈의 수
