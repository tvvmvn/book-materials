## 하향식 비용산정 

과거의 유사한 경험을 바탕으로 전문 지식이 많은 개발자들이 참여한 회의를 통해 비용을 산정하는 비과학적인 방법입니다.

*종류*

- 전문가 감정 기법
- 델파이 기법


## 상향식 비용 산정

프로젝트의 세부적인 작업 단위별로 비용을 산정한 후에 전체 비용을 산정하는 방법입니다.

*종류*

- LOC 기법
- 개발 단계별 인/월/수 기법
- 수학적 산정 기법

## COCOMO

건설적 비용 모형 (COnstructive COst MOdel).  
`LOC 기법`을 활용하여 개발 비용을 산정한다.  
Bohem이 제안


### LOC (Line Of Code) 기법

코드 줄의 수를 바탕으로 개발 비용 및 기간 등을 예측하는 방법 

#### 산정 공식

1. 노력(인월) = 개발기간 * 투입인원 = LOC / 인당 생산성(월평균 생산가능한 코드줄 수)
2. 개발비용 = 노력(인월) x 단위 비용(1인당 월평균 인건비)
3. 개발 기간 = 노력(인월) / 투입 인원
4. 생산성 = LOC / 노력(인월)


```
Q. 코드 30,000줄, 프로그래머 5명, 각 프로그래머의 월평균 생산성이 300줄 일때 개발 기간은 얼마일까요?  

노력 = LOC / 인당 생산성 = 30,000 / 300 = 100
투입인원 = 5
개발기간 = 노력 / 인원 = 100 / 5 = 20

답: 20개월
```


### COCOMO의 소프트웨어 개발 유형

1. 조직형(Organic Mode)
2. 반분리형(Semi-Detached Mode)
3. 내장형(Embedded Mode)


#### 조직형

5만 줄 이하의 소규모 소프트웨어  

예) 사무용

#### 반분리형

5 - 30만 줄의 소프트웨어.  

예) 운영체제, DBMS, 컴파일러 등

#### 내장형

30만 줄 이상 초대형 규모의 소프트웨어.  
시스템 소프트웨어

예) 운영체제, 트랜잭션 시스템, 미사일 유도 시스템 등


## Putnam

S/W 생명주기 동안에 필요한 `노력의 분포`를 예상하는 모형.  
생명주기 예측모델이라고도 한다.  
Rayleigh-Norden 곡선을 기반으로 한다.  
Putnam이 제안

![putnam](./putnam.jpg)

Rayleigh-Norden 곡선은 프로젝트 기간에 따른 노력(인력) 투입 변화를 나타내는 그래프입니다. 
일반적으로 개발 초기에는 필요한 노력이 적고, 개발 중반에 집중되며, 
후반에는 다시 감소하는 형태를 보입니다


## FP Model

기능 점수 (Function Point).  
기능을 증대시키는 요인별로 가중치 부여

### 기능 점수의 구성 요소 

- 외부 입력 (EI)
- 외부 출력 (EO)
- 외부 질의 (EQ)
- 내부 논리 파일 (ILF)
- 외부 인터페이스 파일 (EIF)


*복잡도에 따른 구성요소의 가중치를 나타내는 표*
