## 암호화 개념

중요한 정보를 보관하거나 전송할 때 보안을 위해 평문을 암호문으로 변환하는 것을 의미합니다. 암호문을 원래의 평문으로 바꾸는 것을 복호화라고합니다.

*암호화 종류*

- 양방향 암호화
- 단방향 암호화


## 양방향 암호화

암호화와 복호화 모두 가능합니다

- 개인키 암호화 (Private Key Encryption)
- 공개키 암호화 기법 (Public Key Encryption)


## 개인키 암호화

데이터를 `동일한 키`로 암호화하고 복호화합니다.
대칭 암호화 또는 단일키 암호화라고도 부릅니다.
암호화와 복호화 속도가 빠릅니다.
관리해야할 키의 수가 많습니다.

*종류*

- 스트림 암호화
- 블록 암호화


### 스트림 암호화 

평문과 동일한 길이의 스트림을 생성하고 비트단위로 암호화한다.
다음의 종류가 있습니다.

- LFSR
- RC4


### 블록 암호화 

한번에 하나의 데이터 블록을 암호화합니다.
다음 4가지의 종류가 있습니다.

- DES (Data Encyption Standard)
- AES (Advanced Encryption Standard)
- SEED
- ARIA

**DES** IBM이 개발하고 1975년 미국 NBS에 의해 미국의 국가표준으로 발표된 알고리즘입니다.

```
블록크기: 64비트
키 길이: 56비트
16회 라운드 수행
```

**AES** 미국 표준 기술 연구소(NIST)에서 2001년 발표한 알고리즘입니다.
DES의 한계를 느낀 NIST에서 공모한 후 발표했습니다. 

```
블록크기: 128비트 
키 길이: AES-128, AES-192, AES-256로 구분됩니다
```


## 공개키 암호화

데이터를 암호화할 때 사용하는 공개키(Public Key)는 사용자에게 공개하고 복호화할 때 사용하는 비밀키(Secret Key)는 관리자가 비밀리에 보관합니다.
비대킹 암호 기법이라고도 불립니다.
암호화와 복호화 속도가 느립니다.
관리해야할 키의 수가 적습니다.
대표적으로 RSA가 있습니다

**RSA(Rivest Shamir Adleman)** 1978년 MIT의 Rivest, Shamir, Adleman이 제안한 알고리즘입니다. 큰 숫자를 소인수분해하기 어렵다는 사실에 기반하여 만들어졌습니다.


## 단방향 암호화 (Hashing)

입력 데이터를 고정된 길이의 값으로 변환하는 것을 말합니다.  
해시 알고리즘을 해시 함수라고 부르고 해시 함수로 변환된 값을 해시값 또는 해시키라고 부릅니다.

*종류*

- SHA 시리즈
- HAVAL
- MD4
- MD5

```
단방향 암호화를 언제 사용할까요? 
가장 자주 볼수 있는 사례로 비밀번호가 있습니다.
비밀번호가 유출되어도 복호화가 되지 않기 때문에 안전합니다.
그렇다면 비밀번호를 어떻게 검증할까요?
사용자가 입력한 비밀번호를 똑같은 해시함수로 변환 후 
변환된 값(해시값)을 비교하는 것이지요.
```

**SHA 시리즈** 1993년 미국의 국가안보국(NSA)이 설계하고 미국 국립표준기술연구소(NIST)가 발표했습니다.

**MD5**  1991년에 R.Rivest가 예전에 쓰이던 MD4를 대체하기 위해 고안한 해시 함수입니다. 

```
블록 크기: 512비트
키 길이: 128비트
```
