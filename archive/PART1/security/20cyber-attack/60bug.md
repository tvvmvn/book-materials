# Bug / 이상 / 보안 약점

- Memory Buffer Overflow
- TOCTOU
- 하드코딩된 암호화 키
- 널포인터 역참조


### Memory Buffer Overflow

정보가 다른 장치로 전송될 때 일시적으로 데이터를 기억하는 중간 장치를 메모리 버퍼(Memory Buffer)라고 합니다.

연속된 메모리 공간을 사용하는 프로그램에서 할당된 버퍼의 범위를 넘어선 위치에서 자료를 읽거나 쓰려고 할 때 발생하는 보안 약점입니다.

메모리 버퍼를 사용할 경우 적절한 버퍼의 크기를 설정하고, 설정된 범위의 메모리 내에서 읽거나 쓰도록 함으로써 방지할 수 있다


### TOC TOU  

검사 시점(Time Of Check)과 사용 시점(Time Of Use)을 고려하지 않고 코딩하는 경우 발생하는 보안 약점입니다.

```
프로세스A가 자원X를 사용하기 위해 검사한 결과, X는 사용가능한 자원임을 확인했습니다. 이제 자원X를 사용하기 위해 X를 요청하였더더니 그 사이에 프로세스 B가 A보다 먼저 자원X에 대한 사용 요청을 내고 사용해버림으로써 A는 X를 사용할 수 없는 상황이 발생합니다.
```


### 널포인터 역참조

널포인터가 가리키는 메모리의 위치에 값을 저장할 때 발생한는 보안 약점입니다.
포인터를 이용하기 전에 NULL 널값을 갖고 있는지 검사함으로써 방지할 수 있습니다.
널포인터 역참조로 오류가 발생하는 경우 "메모리 0x00000000을 참조했습니다" 라는 오류메시지가 발생합니다.

**스택가드(Stack Guard)**  널포인터 역참조와 같이 주소가 저장되는 `스택`에서 발생하는 보안 약점을 막는 기술입니다. 메모리상에서 프로그램의 복귀 주소와 변수 사이에 특정 값을 저장한 후 그 값이 변경되었을 경우 Overflow 상태로 판단하여 프로그램 실행을 중단함으로써 잘못된 복귀 주소의 호출을 막습니다.

```
함수의 실행이 끝나면 자신을 호출한 함수로 되돌아가야합니다. 이때 스택은 복귀할 주소를 기억하는데 사용됩니다.
함수는 호출된 순서의 역순으로 되돌아가야 하기 때문입니다.
```
