# ETC

## 세션 통제 관련 용어

**세션** 서버와 클라이언트의 연결을 의미합니다

**세션 통제** 세션의 연결과 그로 인해 발생하는 정보를 관리하는 것을 의미합니다.

**세션ID (Session ID)** 서버가 다수의 클라이언트를 구분하기 위해 부여하는 키입니다.

**스레드(Thread)** 프로세스 내의 작업 단위입니다. 시스템의 자원을 할당받아 실행하는 프로그램의 단위입니다.

**다중 스레드(Multiple Thread)** 두개 이상의 스레드가 생성되어 동시 처리되는 다중 작업을 다중 스레드 또는 멀티 스레드라고 부릅니다.

**URL Rewrite** 쿠키를 사용할 수 없는 환경에서 세션ID 전달을 위해 URL에 세션ID를 포함하는 것을 의미합니다.


## 입력 데이터 검증 및 표현 관련 용어

보안 점검 내용 중 '입력 데이터 검증 및 표현'은 `입력 데이터`로 인해 발생하는 문제들을 예방하기 위해 구현 단계에서 검증해야 하는 항목입니다.

- 경로 순회 (Directory Traversal)
- 스크립트 (Script)


**경로 순회** 경로를 탐색할 때 사용하는 '/', '\', '..' 등의 기호를 악용하여 허가되지 않은 파일에 접근하는 방식입니다

**스크립트** 소프트웨어를 수행하는데 필요한 처리 절차가 기록된 텍스트입니다. 대표적인 스크립트는 asp, jsp, php 등이 있습니다
