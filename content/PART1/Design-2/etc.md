
# 클린 코드와 배드 코드

코딩을 할 때에는 배드 코드(Bad Code)를 배제하고 클린 코드(Clean Code)로 작성합니다. 배드 코드란 이해하기 어렵고 유지보수하기 어려운 코드입니다. 코드의 로직이 복잡하게 얽힌 스파게티 코드, 아주 오래되고 문서나 개발자가 없어 유지보수 작업이 어려운 외계인 코드 등이 있습니다.

클린 코드란 누구나 쉽게 이해하고 유지보수하기 좋은 코드입니다. 5가지 클린코드 작성 원칙은 다음과 같습니다.

- 가독성: 누구든지 코드를 쉽게 읽을 수 있도록 작성합니다. 이해하기 쉬운 변수명 사용하기, 들여쓰기를 잘 하기 등의 실천 사항이 있습니다

- 단순성: 코드를 간단하게 작성합니다. 예를 들면 하나의 함수/클래스가 여러 작업을 처리하기보다 맡은 작업에 따라 세분화합니다

- 의존성 배제: 모듈들이 서로 의존하는 정도를 낮추고 독립적으로 설계합니다. 한 모듈의 변화가 다른 모듈에 미치는 파급효과가 적어집니다.

- 중복 최소화: 중복되는 코드를 삭제하고 가능한한 코드를 재활용 합니다.

- 추상화: 상위 클래스/함수에서는 간략하게 작성하고 상세 내용은 하위 클래스/함수에서 구현합니다.
