# API 

- 개념
- 종류
- 동기/비동기 
- 통신용 데이터 포멧

API는 정의 및 프로토콜 집합을 사용하여 두 소프트웨어 구성 요소가 서로 통신할 수 있게 하는 메커니즘입니다. 예를 들어, 기상청의 소프트웨어 시스템에는 일일 기상 데이터가 들어 있습니다. 휴대폰의 날씨 앱은 API를 통해 이 시스템과 ‘대화’하여 휴대폰에 매일 최신 날씨 정보를 표시합니다.

아키텍처에 따라 다음과 같이 분류할 수 있습니다.

- REST API
- SOAP API
- RPC API
- Web Socket API


## SOAP API

SOAP API는 단순 객체 접근 프로토콜(SOAP)을 사용하고 클라이언트와 서버는 XML을 사용하여 메시지를 교환합니다. 무거운 구조 때문에 과거에 더 많이 사용되었습니다. 하지만 금융권, 대기업 등 보안이 중요한 분야에서는 여전히 많이 쓰이고 있습니다.

WSDL(웹서비스 게시 언어)파일을 통해 클라이언트는 API 서버에 어떠한 요청이 가능한지 파악할 수 있습니다.


## REST API

REST API는 오늘날 웹에서 볼 수 있는 가장 많이 사용되고 유연한 API입니다. 
무거운 구조의 SOAP API를 많은 분야에서 대체하고 있습니다. 데이터 교환에 JSON을 사용합니다.


## 사용 범위 따른 API 분류

- 프라이빗 API
- 공개 API

프라이빗 API는 기업 내부에 있으며 비즈니스 내에서 시스템과 데이터를 연결하는 데만 사용됩니다.

퍼블릭 API는 일반에 공개되며 누구나 사용할 수 있습니다. 이러한 유형의 API와 관련된 권한 부여와 비용이 있을 수도 있고 없을 수도 있습니다.


## 비동기 통신

API에서 사용되는 통신 방식입니다. 클라이언트가 서버에 요청을 보내고 응답이 올 때까지 무기한 기다리는 동기 방식과 달리 비동기 방식은 응답을 기다리는 동안 다음 작업을 진행합니다. 따라서 클라이언트 측에서 블록 상황이 발생하지 않고 생산성이 증가하게 됩니다.


## 데이터 교환용 포멧

API 통신에서 사용되는 데이터 교환용 포멧에는 크게 XML과 JSON이 있습니다.

- JSON (JavaScript Object Notation)
- XML (eXtensible Markup Language)

XML: 마크업 언어이면서 데이터 교환에도 사용되는 포멧입니다. 태그 안에 데이터를 기술하는 구조입니다. 사용자가 직접 태그를 정의할 수도 있습니다. 

```xml
<name></name>
<age></age>
```

JSON: 자바스크립트 문법을 사용한 데이터 교환 포멧입니다. 키-값 쌍으로 이루어진 구조를 가지고 있습니다. 간단한 문법과 편리한 사용성으로 XML을 대체하고 있습니다.

```json
{ "name": "", "age": "" }
```
