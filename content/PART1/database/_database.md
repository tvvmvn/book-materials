# Database

데이터베이스는 여러 사람에 의해 공동으로 사용될 데이터를 중복을 배제하여 통합하고, 쉽게 접근하여 처리할 수 있도록 저장장치에 저장하여 항상 사용할 수 있도록 하는 운영 데이터입니다.


# DBMS

데이터베이스 관리 시스템(Database Management System)의 약자로 사용자의 요구에 따라 정보를 생성해주고 데이터베이스를 관리해주는 소프트웨어입니다. 많은 문맥에서 데이터베이스 그 자체를 의미하기도 합니다.

예) Postgresql, MySQL, Oracle, MongoDB 

DBMS는 다음의 3가지 필수 기능을 가지고 있습니다.

- 정의 기능 (Definition)
- 조작 기능 (Manipulation)
- 제어 기능 (Control)


정의 기능은 데이터의 형과 구조에 대한 정의, 이용 방식, 제약 조건 등을 명시하는 기능입니다. 

조작 기능은 데이터 검색, 갱신, 삽입, 삭제 등을 위해 인터페이스 수단을 제공하는 기능입니다. 

제어 기능은 데이터의 무결성, 보안, 권한 검사, 병행 제어를 제공하는 기능입니다.


# 시스템 카달로그 (System Catalogue)

시스템 그 자체에 관련이 있는 다양한 객체에 관한 정보를 포함하는 시스템 데이터베이스입니다. 시스템 카탈로그 내의 각 테이블은 사용자를 포함하여 DBMS에서 지원하는 모든 데이터 객체에 대한 정의나 명세에 관한 정보를 유지관리하는 시스템 테이블입니다. 

카탈로그가 생성되면 데이터 사전에 저장되기 때문에 좁은 의미로는 카탈로그를 데이터 사전이라고도 합니다.


# 스키마 (Schema)

스키마는 우리 말로 개요(Schema)를 의미하는 단어로 데이터베이스를 다루는 과정에서 광범위하게 사용되는 용어입니다.

일반적으로 다음과 같이 분류합니다.

- 외부 스키마 (External Schema)
- 개념 스키마 (Conceptual Schema)
- 내부 스키마 (Internam Schema)

외부 스키마는 사용자나 응용 프로그래머가 각 개인의 입장에서 필요로 하는 데이터베이스의 논리적 구조를 정의한 스키마입니다. 

개념 스키마는 데이터베이스의 전체적인 논리적 구조를 나타냅니다. 모든 응용 프로그램이나 사용자들이 필요로 하는 데이터를 종합한 조직 전체의 데이터베이스로서 하나만 존재합니다. 

내부 스키마는 물리적 저장장치의 입장에서 본 데이터베이스의 구조입니다. 실제로 저장될 레코드의 형식, 저장 데이터 항목의 표현 방법, 내부 레코드의 물리적 순서 등을 나타냅니다.
