# 데이터베이스 생성하기

총 5단계에 걸쳐 데이터베이스를 생성합니다.

1. 요구사항 분석 (Requirements Analysis)
2. 개념적 설계 (Conceptual Design)
3. 논리적 설계 (Logical Design)
4. 물리적 설계 (Physical Design)
5. 구현 (Implementation)


# 요구사항 분석

요구조건 분석은 데이터베이스를 사용할 사람들로부터 필요한 용도를 파악하는 것입니다. 

데이터베이스 사용자에 따른 수행 업무와 필요한 데이터의 종류, 용도, 처리 형태, 흐름, 제약 조건 등을 수집합니다. 수집된 정보를 바탕으로 요구조건 명세를 작성합니다


# 개념적 설계

개념적 설계는 현실 세계의 데이터들을 컴퓨터에 옮기는 첫번째 과정으로, 추상적이고 단순하게 표현합니다. 일반적으로 E-R 모델을 활용합니다.

또한 트랜잭션을 모델링하는 단계 입니다. 트랜잭션은 데이터베이스가 처리할 업무의 단위입니다. 


# 논리적 설계

개념적 설계도(ER 모델)를 바탕으로 DBMS가 처리할 수 있는 논리적 구조를 만듭니다. 보통 관계형 데이터 모델을 활용합니다.

또한 트랜잭션 인터페이스를 설계하는 단계입니다. 


# 물리적 설계

물리적 설계는 성능을 위해 데이터베이스의 물리적 구조를 최적화하는 단계입니다.
다음은 물리적 설계 단계에서의 주요 활동들입니다.

- 인덱스 설계: 검색 속도를 높이기 위해 인덱스를 설계합니다.
- 파티셔닝 (Partioning): 대규모의 레코드로 구성된 테이블은 무거워서 연산 성능이 떨어질 수 있으므로 나누어 저장합니다.
- 클러스터링: 자주 같이 쓰이는 데이터들을 물리적으로 가까운 곳에 모읍니다.


# 구현 단계

구현 단계는 DBMS의 데이터 정의어(DDL)를 사용하여 실제 데이터베이스를 생성합니다.
