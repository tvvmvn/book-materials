# 데이터 모델

현실 세계의 정보들을 컴퓨터에 표현하기 위해 정보들을 추상적이고 체계적으로 표현한 모형입니다. 한마디로 데이터베이스 설계도입니다.
<!-- 종류나 예시가 필요해 -->

데이터 모델의 3대 구성 요소는 다음과 같습니다.

- 구조 (Structure)
- 연산 (Operation)
- 제약조건 (Constraint)


구조는 데이터베이스에 논리적으로 표현될 데이터 개체들 간의 관계를 정의합니다. 데이터 모델의 정적인 측면을 나타내며, "데이터가 어떻게 생겼는가?"에 대한 답입니다.
예) 개체, 속성, 관계

연산은 데이터베이스에 저장된 실제 데이터를 처리하는 작업에 대한 명세입니다. 데이터 모델의 동적인 측면을 나타내며, 데이터베이스를 조작하는 규칙입니다.
예) 조회(Select), 삽입(Insert), 삭제(Delete), 수정(Update)

제약 조건은 데이터의 정확성과 일관성을 유지하기 위해 데이터가 허용되는 규칙입니다. 데이터 무결성(Integrity)을 보장하기 위한 핵심 요소입니다.
예) 개체 무결성, 참조 무결성, 도메인 무결성 등

데이터 모델의 구성 요소를 건물에 비유해봅시다.
구조는 건물의 도면 (방의 배치, 구조)
연산은 건물을 이용하는 법 (출입, 이동)
제약 조건은 건물의 안전 규칙 (제한 구역, 정원 초과 금지)
