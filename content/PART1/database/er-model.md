# E-R 모델

개체와 개체 간의 관계를 기본 요소로 이용하여 현실 세계의 무질서한 데이터를 개념적인 논리 데이터로 표현하기 위한 방법입니다. 1976년 피터 첸에 의해 제안되었습니다. 대표적인 개념적 데이터 모델입니다. 

구성 요소

- 개체
- 관계
- 속성

개체는 세상에 독립적으로 존재하는 객체입니다. (예: 학생, 교수, 강의)
속성은 개체나 관계가 가진 고유한 특성입니다. (예: 이름, 학번, 전공)
관계는 개체와 개체 사이의 논리적인 연결을 의미합니다.(예: 수강하다, 가르치다)
