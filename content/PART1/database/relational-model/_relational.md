# 관계형 데이터 모델

관계형 데이터 모델(Relational Data Model)은 1970년 E.F. Codd 박사에 의해 제안된 모델로, 데이터를 2차원 표(Table) 형태로 표현하고 관리하는 방식입니다. 현재 전 세계적으로 가장 널리 사용되는 데이터베이스 모델의 표준입니다.


## 관계형 데이터 모델의 구조

*그림 - 릴레이션*

- 릴레이션
- 튜플
- 속성
- 도메인

릴레이션은 데이터들을 표(Table)의 형태로 표현한 것으로 구조를 나타내는 릴레이션 스키마와 실제 값들인 릴레이션 인스턴스로 구성됩니다.

튜플은 릴레이션을 구성하는 각각의 행을 의미합니다. 튜플은 속성의 모임으로 구성됩니다. 튜플의 수를 카디널리티 또는 기수라고 합니다. 파일구조에서 레코드와 같은 의미입니다.

속성은 데이터베이스를 구성하는 가장 작은 논리적 단위로 개체의 특성을 기술합니다. 속성의 수를 디그리(Degree) 또는 차수라고 합니다. 속성은 파일구조에서 데이터 항목 또는 데이터 필드에 해당합니다.

도메인은 하나의 애트리뷰트가 취할 수 있는 같은 타입의 원자값들의 집합입니다. 예를 들면 '성별' 속성의 도메인은 '남과 여' 두가지 값의 집합입니다.


## 키

키는 데이터베이스에서 조건을 만족하는 튜플을 찾거나 순서대로 정렬할 때 기준이 되는 속성을 말합니다.

키는 다음과 같은 종류가 있습니다

- 슈퍼키
- 후보키
- 기본키
- 대체키
- 외래키

*그림 - 키의 집합 관계*

슈퍼키는 한 릴레이션 내에 있는 속성들의 집합으로 구성된 키입니다. 슈퍼키는 릴레이션을 구성하는 모든 튜플에 대해 유일성은 만족하지만 최소성을 만족하지 못합니다.

후보키는 릴레이션을 구성하는 속성들 중에서 튜플을 유일하게 식별하기 위해 사용되는 속성들의 부분 집합을 의미합니다. 후보키는 기본키로 사용할 수 있는 속성들을 의미합니다. 후보키는 유일성과 최소성을 모두 만족시켜야 합니다

기본키는 후보키 중에서 특별히 선정된 메인 키이며 중복된 값을 가질 수 없습니다. 기본키는 한 릴레이션 안에서 튜플을 유일하게 구별할 수 있는 속성입니다. 대체키는 후보키가 둘 이상일 때 기본키를 제외한 나머지 키들을 의미하며 보조키라고도 부릅니다.

외래키는 다른 릴레이션의 기본키를 참조하는 속성들의 집합을 의미합니다. 외래키로 지정된 속성은 참조 릴레이션의 기본키에 없는 값은 입력할 수 없습니다

*그림 - 외래키와 기본키*

```
- 유일성: 하나의 키로 하나의 튜플을 유일하게 식별할 수 있어야 한다
- 최소성: 키를 구성하는 속성들 중에서 하나를 제거하면 유일하게 식별할 수 꼭 필요한 최소의 속성으로 구성되야 한다
```


## 무결성

무결성은 데이터베이스에 저장된 데이터와 그것이 표현하는 현실 세계의 실제값이 일치하는 정확성을 의미합니다. 

주요 무결성은 다음과 같습니다.

- 개체 무결성: 테이블의 기본키를 구성하는 어떤 속성도 NULL이나 중복값을 가질 수 없다
- 참조 무결성: 외래키 값은 NULL이거나 참조 릴레이션의 기본키 값과 동일해야 한다. 즉 릴레이션은 참조할 수 없는 외래키 값을 가질 수 없다
- 사용자 정의 무결성: 속성의 값이 사용자가 정의한 속성의 제약조건에 만족되어야 한다
- 도메인 무결성: 속성의 값은 정의된 도메인에 속한 값이어야 한다


## 관계대수 

관계형 데이터베이스에서 원하는 정보와 그 정보를 검색하기 위해 어떻게 유도할 것인가를 기술하는 절차적인 언어입니다. 관계대수는 릴레이션을 처리하기 위해 연산자와 연산규칙을 제공하며 피연산자와 연산결과가 모두 릴레이션입니다.

관계형 모델에 적용하기 위해 특별히 개발된 순수 관계 연산자와 수학의 집합 이론에서 사용하는 일반 집합 연산자가 있습니다.

- 순수 관계 연산자
- 일반 집합 연산자


## 일반 집합 연산자

수학의 집합 이론에서 사용하는 연산자입니다.


- 합집합 (A⋃B)
- 교집합 (A⋂B)
- 차집합 (A˗B)
- 교차곱 (A×B)

합집합은 두 릴레이션에 존재하는 튜플의 합집합은 구하되 결과로 생성된 릴레이션에서 중복되는 튜플은 제거하는 연산입니다. 합집합의 카디널리티는 두 릴레이션 카디널리티의 합보다 크지 않습니다

교집합은 두 릴레이션에 존재하는 튜플의 교집합을 구하는 연산입니다. 교집합의 카디널리티는 두 릴레이션 중 카디널리티가 적은 릴레이션의 카디널리티보다 크지 않습니다

차집합은 두 릴레이션에 존재하는 튜플의 차집합을 구하는 연산입니다. 차집합의 카디널리티는 릴레이션 R의 카디널리티보다 크지 않습니다

교차곱은 두 릴레이션에 있는 튜플들의 순서쌍을 구하는 연산입니다. 교차곱의 디그리는 두 릴레이션의 디그리를 더한 것과 같고 카디널리티는 두 릴레이션의 카디러리티는 곱한 것과 같습니다.


## 일반 집합 연산자

- Select (σ)
- Project (ㅠ)
- Join (⋈)
- Division (÷)

Select는 릴레이션에 존재하는 튜플 중에서 선택 조건을 만족하는 튜플의 부분 집합을 구하여 새로운 릴레이션을 만드는 연산입니다. 릴레이션의 행에 해당하는 튜플을 구하는것이므로 수평 연산이라고도 합니다. 기호는 σ(시그마)입니다

Project는 주어진 릴레이션에서 속성 리스트에 제시된 속성 값만을 추출하여 새로운 릴레이션을 만드는 연산입니다. 릴레이션의 열에 해당하는 속성을 추출하는 것이므로 수직 연산자라고도 합니다. 기호는 ㅠ(파이)입니다

Join은 공통 속성을 중심으로 두개의 릴레이션을 하나로 합쳐서 새로운 릴레이션을 만드는 연산입니다. Join의 결과는 교차곱을 수행한 다음 Select를 수행한 것과 같습니다. 기호는 ⋈(보우타이)입니다

Division은 X⊃Y인 두 개의 릴레이션 R(X)와 R(Y)가 있을 때 R의 속성이 S의 속성값을 모두 가진 튜플에서 S가 가진 속성을 제외한 속성만을 구하는 연산입니다.
기호는 ÷(나누기)입니다.


## 관계 해석

관계 데이터의 연산을 표현하는 방법입니다. 관계 데이터 모델의 제안자인 코드(E.F.Codd)가 수학의 술어 해석에 기반을 두고 관계 데이터베이스를 위해 제안했습니다. 관계 해석은 원하는 정보가 무엇이라는 것만 정의하는 비절차적 특성을 지닙니다. 원하는 정보를 정의할 때에는 계산 수식을 사용합니다.
