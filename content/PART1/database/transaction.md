# 트랜잭션 (Transaction)

데이터베이스의 상태를 변화시키는 하나의 논리적 기능을 수행하기 위한 작업의 단위 또는 한꺼번에 모두 수행되어야할 일련의 연산들을 의미합니다.

예를 들어 <거래> 트랜잭션을 구성하는 연산들은

1. 내 계좌에서 돈 빼기
2. 상대방 계좌에 돈 넣기


# 트랜잭션의 특성 

트랜잭션의 4가지 특성입니다. 앞글자를 따서 ACID 라고도 부릅니다.

- 원자성 (Atomicity)
- 일관성 (Consistency)
- 독립성 (Isolation)
- 영속성 (Durability)

원자성: 트랜잭션은 쪼개질 수 없습니다. 즉 트랜잭션을 구성하는 연산들은 DB에 모두 반영되거나 아니면 전혀 반영되지 않아야 합니다.(All or Nothing). 

일관성: 트랜잭션은 데이터베이스의 일관성을 지켜야합니다. 즉 잘못된 트랜잭션으로 DB의 일관성을 해쳐서는 안됩니다.

독립성: 여러 트랜잭션이 동시에 실행 중일 때, 각 트랜잭션들은 서로를 방해하지 말고 독립적으로 실행되어야 합니다.

영속성: 트랜잭션이 성공적으로 처리한 결과는 데이터베이스에 영구적으로 보존되어야 합니다. 시스템 장애가 생겨도 마찬가지입니다.


# 트랜잭션 분석

트랜잭션과 테이블 간에 CRUD 매트릭스(CRUD Matrix)를 만들어서 트랜잭션을 분석하는 활동입니다. 데이터베이스 개념적 설계 단계에서 수행됩니다.

<그림 - CRUD Matrix>

CRUD 분석을 통해 많은 트랜잭션이 몰리는 테이블을 파악할 수 있으므로 디스크 구성 시에 유용한 자료로 활용할 수 있습니다. 

CRUD 매트릭스의 각 셀에는 C(Create), R(Read), U(Update), D(Delete)의 앞 글자가 한 개 이상 작성됩니다.
