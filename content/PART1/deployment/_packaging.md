# S/W 패키징 (S/W Packaging)

소프트웨어 패키징은 완성된 소프트웨어를 시장에 배포하기 전에 수행하는 일련의 활동입니다. 소프트웨어와 관련 문서 등을 함께 묶어 배포용 파일을 만들고 불법 복제 등을 방지하기 위한 보안 적용 등의 작업을 포함합니다.

다음은 패키징 과정에서 수행하는 주요 작업들입니다.

1. 빌드(Build)
2. 암호화
3. 패키징

빌드 단계는 소스 코드를 바탕으로 실행 파일을 만드는 과정을 의미합니다.
예) .exe, .jar, .apk

암호화 단계는 디지털 콘텐츠를 보호하기 위해 DRM(Digital Rights Management)의 기술 요소들을 활용해 실행 파일을 암호화하는 단계입니다.

패키징 단계는 암호화된 소프트웨어 본체와 그와 관련된 모든 문서를 모아 배포를 준비하는 단계입니다.


# 릴리즈 노트 (Release Note)

릴리즈 노트는 소프트웨어 출시(Release) 정보를 사용자와 공유하기 위한 문서입니다. 다음은 주요 릴리즈 노트의 항목들입니다.

- 머릿말 (Header)
- 개요 & 목적
- 수정 및 개선 내용
- 사용자 영향도

다음은 릴리즈 노트 예시입니다.

[Release Note] SmartApp v1.2.0
릴리즈 날짜: 2026-02-13

1. 핵심 업데이트
사용자의 편의를 위한 '다크 모드'가 공식 지원됩니다.

2. 신규 기능 (New Features)
메뉴 내 테마 선택 기능 추가
소셜 로그인(Google, Apple) 연동 지원

3. 버그 수정 (Bug Fixes)
특정 기기에서 앱 실행 시 비정상 종료되던 현상 수정
프로필 이미지 업로드 시 속도가 저하되던 문제 개선

4. 알려진 문제 (Known Issues)
저사양 태블릿 환경에서 다크 모드 전환 시 약 1초간 지연이 발생할 수 있습니다.


# 소프트웨어 매뉴얼 (S/W Manual)

S/W 매뉴얼은 크게 두 종류로 나눌 수 있습니다.

- 설치 매뉴얼 (Installation Manual)
- 사용자 매뉴얼 (User Manual)

설치 매뉴얼은 소프트웨어 설치 방법을 정리한 문서입니다. 설치 시작부터 끝까지 전 단계를 상세히 설명하고 설치 과정에서 발생할 수 있는 문제 상황에 대해 해결책을 제시합니다.

사용자 매뉴얼은 소프트웨어 사용 방법을 정리한 문서입니다. 예를 들어 S/W 실행 방법, 메뉴 설명, 버튼 사용법 등을 다룹니다.


# 빌드 도구

빌드 과정을 자동화하고 관리하는 도구입니다. 다음은 Java 환경에서 사용되는 대표적인 빌드 도구들입니다.

- Gradle
- Maven

Gradle은 안드로이드 앱 개발 환경에서 사용되는 빌드 도구입니다. 안드로이드 뿐만 아니라 플러그인을 설정하면 자바, C/C++, 파이썬 등의 언어로 작성된 앱도 빌드할 수 있습니다. 간결한 문법과 빠른 처리 속도로 가장 많이 사용되는 빌드 도구입니다.
빌드 설정 파일은 Groovy DSL 기반의 build.gradle입니다.

Maven은 아파치 소프트웨어 재단에서 개발한 빌드 도구입니다. 의존성을 설정하여 라이브러리를 관리합니다. Gradle 대비 상대적으로 복잡한 문법과 느린 속도를 가진 레거시 빌드 도구입니다. 빌드 설정 파일은 XML기반의 pom.xml입니다.


# CI/CD

CI/CD는 지속적 통합(Continuous Integration) 및 지속적 배포(Continuous Deployment)를 의미합니다. 빌드부터 패키징, 배포까지 모두 자동화된 프로세스를 의미합니다. 지속성을 강조하는 애자일 개발 환경의 구현이라고볼 수 있습니다. 다음은 주요 CI/CD 도구입니다.

- Jenkins
- Github Actions

Jenkins는 가장 많이 사용되는 CI/CD 도구로, 자바 기반의 오픈소스 도구입니다. SVN, Git 등 대부분의 형상 관리 도구와 연동이 가능합니다. Web UI 제공으로 편리한 사용성이 장점입니다.

Github Actions는 깃허브에서 제공하는 CI/CD 도구입니다. 깃허브와의 연동으로 간단한 설정만으로 CI/CD 환경을 구축할 수 있습니다.
