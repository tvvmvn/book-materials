# 소프트웨어 프레임워크(Framework)

프레임워크는 소프트웨어 개발 과정에서 필요한 기초적인 모든 것들을 제공하는 도구 모음과 같습니다. 프레임워크를 사용하면 소프트웨어를 쉽고 빠르게 개발할 수 있습니다.

마치 프레임워크는 밀키트와 같습니다. 일일이 필요한 메뉴들을 사고 손질하고 요리법을 학습해야 할 필요가 없이 손질된 메뉴들과 요리법을 제공하므로 빠르게 요리할 수 있습니다.

소프트웨어의 아키텍처에 따라 다양한 프레임워크가 존재합니다.

- 서버 프레임워크
- 데스크톱 앱 프레임워크
- 모바일 앱 프레임워크
- 웹앱 프레임워크


# 소프트웨어 개발 프레임워크의 특징

- 모듈화 (Modularity)
- 재사용성 (Reusability)
- 확장성 (Extensibility)
- 제어의 역흐름 (Inversion of Control)

모듈화: 소프트웨어를 작은 기능 단위인 모듈로 분해하고 관리하므로 소프트웨어의 품질이 향상되고 유지보수가 용이합니다.

재사용성: 프레임워크는 재사용이 가능한 모듈들을 제공함으로써 반복적인 작업을 줄여줍니다.

확장성: 프레임워크는 개발에 필요한 최소한의 규칙(인터페이스)만을 제공하므로 필요에 따라 다양한 구조로 확장될 수 있습니다.

제어의 역흐름: 개발 과정에서 주도권을 개발자가 아니라 프레임워크가 가집니다. 즉 개발자가 프레임워크가 정한 규칙에 따라서 개발을 하게 됩니다. 이는 일관적이고 안정적인 개발 과정을 보장합니다.


# 서버 개발 프레임워크

서버 프로그램 개발 시 아키텍처 모델 구현, 네트워크 설정, 요청 및 응답 처리 등을 손쉽게 처리할 수 있도록 클래스/인터페이스를 제공해주는 프레임워크입니다. 대부분 MVC 패턴을 기반으로 개발되었습니다.

- Spring
- Node.js
- Django
- Codeigniter
- Ruby on Rails
