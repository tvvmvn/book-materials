# 소프트웨어 개발 방법론

소프트웨어 개발 방법론은 소프트웨어 개발의 방법을 연구하는 분야로 수많은 개발 과정과 시행착오로부터 얻어진 여러가지 기법과 설계 도구들이 축적되며 발전되어 왔습니다. S/W 개발 방법론은 소프트웨어의 품질 향상은 물론 개발 과정의 생산성과 효율성 증대에 그 목적이 있습니다. 다음은 주요 개발 방법들입니다.

- 구조적 방법 (Structual Method)
- 객체 지향 (Object-Oriented)
- CBD (컴포넌트 기반 설계)
- 애자일 (Agile)
- 정보 공학적 접근 
- 제품 계열 방법 


# 구조적 방법

구조적 방법이란 분할과 정복(Divide and Conquer) 원리에 기반한 개발 방법입니다. 분할과 정복이란 크고 복잡한 문제를 해결 가능한 수준의 단위까지 쪼개고 하나씩 정복하여 마침내 문제를 해결하는 방법입니다.

과정은 다음과 같이 진행될 수 있습니다. 시스템을 여러 계층의 자료 흐름도로 표현하고 최하위 자료 흐름도의 프로세스를 소단위 명세서(Mini-Spec)를 활용해 상세히(코드 수준으로) 작성합니다.


# 객체 지향

마치 부품을 조립하여 완성품을 만드는 것처럼 소프트웨어를 객체의 모임으로 생각하고 각 객체들을 만들고 조립해서 소프트웨어를 개발하는 관점을 의미합니다. 규모가 커지면 복잡도가 크게 증가하고 유연성이 떨어지는 구조적 방법론의 문제점을 해결하기 위해 개발되었습니다.


# CBD (컴포넌트 기반 설계)

컴포넌트 기반 설계(Component Based Design)는 기존에 개발되고 인증이 완료된 컴포넌트들을 활용해 새로운 소프트웨어를 개발하는 방법입니다. 필요한 컴포넌트가 이미 개발된 경우 새로운 컴포넌트를 개발하지 않을 수 있어 시간과 노력을 절감할 수 있습니다. 예를 들어 애플리케이션에 지도 기능이 필요할 때 이미 지도 컴포넌트가 존재한다면 새롭게 지도 기능을 개발하지 않고 새로운 소프트웨어에 적용할 수 있습니다.
