# 미들웨어 (Middleware)

중간(Middle)과 소프트웨어(Software)가 합쳐진 단어로 운영 체제와 응용 프로그램 또는 서버와 클라이언트 사이에서 다양한 서비스를 제공하는 소프트웨어입니다. 

- RPC 
- MOM
- TP-Monitor
- ORB
- WAS 
- 데이터베이스


# RPC (원격 프로시저 호출)

원격 프로시저를 마치 로컬 프로시저처럼 호출할 수 있는 기능을 제공하는 미들웨어입니다. 예를 들어 RPC를 활용하면 클라이언트가 자신의 로컬 환경에서 다른 로컬 함수들을 호출하듯이 원격지의 함수를 별다른 절차없이 호출할 수 있습니다.


# MOM (메시지 지향 미들웨어)

메시지 기반의 비동기형 메시지를 전달하는 미들웨어입니다. 온라인 업무보다는 이기종 분산 데이터 시스템에서 데이터 동기를 위해 사용됩니다.


# TP-Monitor

온라인 트랜잭션 업무에서 트랜잭션을 처리하고 감시하는 미들웨어입니다. 항공기나 철도 예약 업무 등 사용자 수가 증가해도 빠른 응답 속도를 유지해야 하는 업무에 사용됩니다.


# ORB (객체 관계 브로커)

코바 표준을 구현한 객체지향 미들웨어입니다. 최근에는 TP-Monitor의 장점인 트랜잭션 처리/모니터링을 추가적으로 구현한 제품도 있습니다.


# WAS (웹 애플리케이션 서버)

사용자의 요구에 따라 변하는 동적 콘텐츠를 처리하는 미들웨어입니다.
