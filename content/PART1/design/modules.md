# 모듈

모듈은 모듈화를 통해 분리된 시스템의 각 기능입니다. 서브루틴, 서브시스템, 작업 단위 등이 여기에 해당합니다. 


## 결합도

모듈 간에 상호 의존하는 정도 또는 두 모듈 사이의 연관관계를 의미합니다. 소프트웨어의 품질은 결합도가 약할수록 높고 결합도가 강할수록 낮습니다.

결합도가 낮은 순에서 높은 순으로 정렬된 결합도의 종류입니다

1. 자료 결합도
2. 스탬프 결합도
3. 제어 결합도
4. 외부 결합도
5. 공통 결합도
6. 내용 결합도


자료 결합도는 모듈 간의 인터페이스가 자료 요소로만 구성될 때의 결합도입니다.

스탬프 결합도는 모듈 간의 인터페이스로 배열이나 레코드 등의 자료 구조가 전달 될 때의 결합도입니다

제어 결합도는 어떤 모듈이 다른 모듈 내부의 논리적인 흐름을 제어하기 위해 제어 신호나 제어 요소를 전달할 때의 결합도입니다. 하위 모듈에서 상위 모듈로 제어 신호가 이동해서 사위 모듈이 상위 모듈에게 처리 명령을 내리는 권리 전도 현상이 발생할 수 있습니다

외부 결합도는 어떤 모듈에서 선언한 변수를 외부의 다른 모듈에서 참조할 때의 결합도입니다

공통 결합도는 공유되는 공통 데이터 영역을 여러 모듈이 사용할 때의 결합도입니다. 예를 들어 모듈들이 모듈 밖에 선언된 전역 변수를 갱신하는 방식으로 상호작용 하는 경우가 있습니다.

내용 결합도는 한 모듈이 다른 모듈의 내부 자료와 기능을 직접 참조하거나 수정할 때의 결합도입니다.


## 응집도

응집도는 모듈의 내부 요소들이 서로 관련되어 있는 정도를 의미합니다. 소프트웨어의 품질은 응집도가 강할수록 높고 응집도가 낮을수록 낮습니다.

응집도나 높은 것에서 낮은 것으로 정렬한 목록입니다

1. 기능적 응집도
2. 순차적 응집도
3. 교환적 응집도
4. 절차적 응집도
5. 시간적 응집도
6. 논리적 응집도
7. 우연적 응집도

- 기능적 응집도: 모듈 내부의 모든 기능요소들이 단일 문제와 관련되어 수행됩니다

- 순차적 응집도: 한 모듈 내 하나의 활동으로부터 나온 출력 데이터를 다른 모듈이 입력 데이터로 사용합니다

- 교환적 응집도: 동일한 입력과 출력을 사용하여 서로 다른 기능을 수행하는 구성 요소들이 모인 경우에 해당합니다

- 절차적 응집도: 모듈이 다수의 관련된 기능을 가질 때 모듈안의 구성 요소들이 그 기능을 순차적으로 수행하는 경우입니다.

- 시간적 응집도: 특정 시간에 처리되는 몇 개의 기능을 모아 하나의 모듈로 작성할 경우입니다

- 논리적 응집도: 유사한 성격을 갖거나 특정한 형태로 분류되는 처리 요소들로 하나의 모듈이 형성되는 경우입니다

- 우연적 응집도: 모듈 내부의 각 구성 요소들이 서로 관련없는 요소로만 이루어진 경우입니다

## 공통 모듈

공통 모듈은 여러 프로그램에서 공통으로 사용할 수 있는 모듈입니다. 공통 모듈을 구현할 때는 해당 기능을 명확히 이해할 수 있도록 다음과 같은 명세 기법을 준수해야 합니다

- 정확성
- 명확성
- 완전성
- 일관성
- 추적성
