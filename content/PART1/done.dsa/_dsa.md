# DSA (Data Structure & Algorithm)

자료 구조와 알고리즘은 프로그램을 구성하는 양대 구성요소 입니다.


# 자료 구조 (Data Structure)

자료 구조란 자료를 기억 장치의 공간 내에 저장하는 방법이나 처리 방법, 자료 간의 관계 등을 연구하는 분야를 의미합니다. 자료의 모양에 따라 크게 다음과 같이 두가지 유형으로 구분할 수 있습니다.

- 선형 구조 (Linear Structure) 
- 비선형 구조 (Non-Linear Structure) 

선형 구조는 일련의 자료들이 논리적으로 선(Line)을 이루듯이 일렬로 정렬되어 있는 자료 구조를 의미합니다. 배열, 연결 리스트, 스택, 큐, 데크 등이 있습니다.

비선형 구조는 논리적으로 선의 형태가 아닌 다양한 모양을 가지는 자료 구조를 의미합니다. 트리, 그래프 등이 있습니다.


# 알고리즘

문제 해결을 위한 일련의 절차를 의미합니다.


# 시간 복잡도 (Time Complexity)

시간 복잡도는 주어진 알고리즘을 수행하기 위해 프로세스가 수행하는 연산의 횟수를 의미합니다. 시간 복잡도가 낮을 수록 알고리즘의 처리 시간이 짧고 시간 복잡도가 높을 수록 알고리즘의 처리 시간이 깁니다.

시간 복잡도는 빅오 표기법(Big-O Notation)으로 표현합니다. 빅오 표기법은 알고리즘의 실행 시간이 최악일 때를 표기하는 방법입니다. 다음은 빅오 표기법으로 표현한 주요 시간 복잡도입니다.

- O(1)
- O(log n)
- O(n)
- O(n log n)
- O(n^2)
- O(2^n)


*그림 - 시간 복잡도를 표현한 그래프*


O(1)는 문제 해결에 입력값(n)에 관계없이 일정한 시간이 필요합니다.
예) 배열에서 인덱스로 값 찾기, 스택의 삽입, 삭제

O(log n)는 입력값(n)이 커져도 연산 시간이 완만하게 증가합니다.
예) 이진 탐색

O(n)는 연산에 필요한 시간이 입력값(n)과 1:1의 관계를 가집니다.
예) for 문

O(n log n)는 문제 해결에 n(log n)의 시간이 필요합니다.
예) 힙 정렬, 2Way 합병 정렬

O(n^2)는 문제 해결에 입력값(n)의 제곱 만큼의 시간이 필요합니다.
예) 중첩 반복문, 삽입 정렬, 선택 정렬, 버블 정렬, 퀵 정렬 등

O(2^n)는 문제 해결에 2의 n(입력값)제곱 만큼의 시간이 필요합니다.
예) 피보나치 수열
