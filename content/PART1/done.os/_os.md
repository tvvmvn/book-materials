# 운영체제 (Operating System)

사용자와 컴퓨터 하드웨어 간의 인터페이스 역할을 담당하는 시스템 소프트웨어입니다. 
다음은 운영체제의 4대 핵심 기능입니다.

- 프로세스 관리
- 메모리 관리
- 파일 및 저장장치 관리
- 입/출력 장치 관리


# 운영체제의 구성

- 커널 (Kernel)
- 사용자 인터페이스 (UI)

커널은 운영체제의 핵심으로 메모리에 상주하며 작동하는 프로그램입니다. UI를 통해 전달받은 명령을 처리합니다. 

UI는 커널과 사용자 사이의 다리 역할을 합니다. GUI, CLI 등이 있습니다. 예를 들어 사용자는 화면(GUI)과 마우스를 사용해 운영체제에게 명령을 내릴 수 있습니다.


# 종류

- 일반 PC용 OS
- 모바일용 OS
- 서버용 OS

일반 PC용으로 MacOS, Windows 등이 있습니다. MacOS는 애플(Apple)이 1980년대 개발한 운영체제입니다. 애플 PC에서만 사용 가능한 운영체제입니다. 윈도우는 마이크로소프트가 1990년대 개발한 운영체제로 세계에서 가장 높은 점유율을 가진 운영체제입니다.

모바일용 운영체제로 Android, iOS가 있습니다. 안드로이드는 Google에서 개발한 오픈소스 모바일 운영체제입니다. 리눅스 커널 위에서 작동하고 자바와 코틀린으로 응용 프로그램을 개발합니다. iOS는 마찬가지로 애플 제품에서만 사용 가능한 모바일 운영체제입니다.

서버용으로 Unix, Linux가 있습니다. 유닉스는 AT&T 벨 연구소와 MIT, General Electric이 1960년대에 공동으로 개발한 시분할 시스템 기반 운영 체제입니다. 

대부분 C 언어로 작성되어 이식성이 높습니다. 트리 구조의 파일 시스템을 가지고 있습니다. MacOS, iOS, 리눅스, 안드로이드 등 대부분의 운영체제가 바로 유닉스를 바탕으로 개발되었습니다.

리눅스는 리누스 토발즈(Linus Torvalds)가 1991년 유닉스를 기반으로 개발한 오픈소스 운영체제로 유닉스와 거의 완벽하게 호환됩니다. 서버용으로 가장 많이 사용되는 운영체제입니다.


# UNIX/LINUX 기본 명령어

- chmod
- ls
- mv
- rm
- uname
- fork
...

chmod는 파일의 보호 모드를 설정하고 파일의 사용 허가를 지정합니다.

<!-- 예) [chmod u=rwx abc.txt]
사용자 u에게 abc.txt 파일의 읽기(r), 쓰기(w), 실행(x) 권한을 부여합니다. -->

예제) UNIX 기반 시스템에서 batch.sh 파일에 대해 소유자와 그룹에게는 전체 권한을 주고 기타 사용자에게는 읽기, 실행 권한을 부여하는 명령문을 8진법 숫자를 이용하여 작성하세요.

답: chmod 775 batch.sh
해설: rwxrwxr-x는 8진수로 표현하면 775입니다.


# UNIX/LINUX 환경 변수

환경 변수란 시스템 소프트웨어의 동작에 영향을 미치는 값입니다.

환경 변수를 명령어나 스크립트에서 사용하려면 환경 변수 앞에 $를 입력해야 합니다.
set, env, printenv, setenv 중 하나를 입력하면 모든 환경 변수와 값을 출력합니다.

다음은 주요 환경 변수들입니다.

$HOME: 홈 디렉터리
$USER: 사용자 이름
