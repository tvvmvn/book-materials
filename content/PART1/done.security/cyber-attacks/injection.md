# 주입 공격

URL 입력, 게시글 업로드 등 사용자의 입력 기능을 악용한 공격입니다.

- XSS
- SQL 주입
- OS 명령어 삽입
- 경로 조작 공격


# XSS (Cross Site Scripting)

사용자의 입력 기능을 악용해 웹사이트에 악성 스크립트(보통 자바스크립트)를 삽입합니다. 사용자가 웹사이트에 방문하면 악성 스크립트가 사용자의 웹브라우저에서 실행됩니다.

사용자가 웹사이트에서 입력하는 데이터가 서버 측에서 실행가능한 코드로 해석되지 않도록 필터링해서 예방할 수 있습니다. 


# SQL 주입 (SQL Injection)

사용자 입력 기능을 악용해 악의적인 SQL 명령어를 데이터베이스에 삽입합니다. 이를 통해 데이터를 조작하거나 유출시킵니다.

마찬가지로 사용자가 웹사이트에서 입력하는 데이터가 데이터베이스에서 실행가능한 코드로 해석되지 않도록 필터링해서 예방할 수 있습니다. 


# 운영체제 명령어 삽입 (OS Command Injection)

공격자가 사용자 입력을 악용해서 서버의 운영체제 명령어(OS Command)를 조작하는 공격입니다.

예방 방법으로 소스코드에서 OS 명령어를 직접 호출하지 말고 프로그래밍 언어에서 제공하는 내장 라이브러리를 사용합니다. 또 사용자 입력값에서 운영체제 명령어로 쓰일 수 있는 문자들을 제거합니다.


# 경로 조작 (Path Traversal) 공격

../ 와 같은 경로 제어 문자를 악용한 공격입니다.

만약 서버가 사용자 입력값으로 서버의 경로 조작이 가능하도록 설계된 경우 심각한 보안 약점이 될 수 있습니다. 예를 들어 공격자가 URL에 경로 제어 문자를 삽입해서 서버 내의 폴더에 불법적으로 접근할 수 있습니다.

사전에 외부에서 접근할 수 있는 경로를 제한하거나 사용자 입력값에서 경로 제어 문자를 필터링 하는 등의 예방 방법이 있습니다.
