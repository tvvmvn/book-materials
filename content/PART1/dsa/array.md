# 배열

크기와 자료형이 동일한 자료들이 순서대로 나열된 자료의 집합입니다.
반복적인 데이터 처리 작업에 적합한 구조입니다. 정적인 자료구조로 기억 장소의 추가가 어렵습니다.

*그림 - 배열*


# 정렬 알고리즘

배열의 요소를 정렬하는 알고리즘입니다.

- 버블 정렬
- 선택 정렬
- 삽입 정렬


## 버블 정렬

오른쪽으로 진행하며 인접한 두 개의 레코드 값을 비교하고 비교 결과에 따라 레코드의 위치를 서로 교환합니다. 시간 복잡도는 O(n^2)입니다

```
배열 {8, 5, 6, 2, 4}를 버블 정렬로 정렬해보자.

1회
{8, 5, 6, 2, 4} => 1, 2 비교 
{5, 8, 6, 2, 4} => 2, 3 비교
{5, 6, 8, 2, 4} => 3, 4 비교
{5, 6, 2, 8, 4} => 4, 5 비교
{5, 6, 2, 4, 8}

2회
{5, 6, 2, 4, 8} => 1, 2 비교
{5, 6, 2, 4, 8} => 2, 3 비교
{5, 2, 6, 4, 8} => 3, 4 비교
{5, 2, 4, 6, 8}

3회
{5, 2, 4, 6, 8} => 1, 2 비교
{2, 5, 4, 6, 8} => 2, 3 비교
{2, 4, 5, 6, 8}

4회
{2, 4, 5, 6, 8} => 1, 2 비교 
{2, 4, 5, 6, 8} 
```


## 선택 정렬

n개의 레코드 중에서 최소값을 찾아 첫번째 레코드 위치에 놓고 나머지 (n - 1)개 중에서 다시 최소값을 찾아 두번째 레코드 위치에 놓는 작업을 반복합니다. 시간 복잡도는 O(n^2)입니다.

```
배열 {8, 5, 6, 2, 4}를 선택 정렬로 정렬해보자.

1회
{8, 5, 6, 2, 4} => 1, 2 비교
{5, 8, 6, 2, 4} => 1, 3 비교
{5, 8, 6, 2, 4} => 1, 4 비교
{2, 8, 6, 5, 4} => 1, 5 비교
{2, 8, 6, 5, 4}

2회
{2, 8, 6, 5, 4} => 2, 3 비교
{2, 6, 8, 5, 4} => 2, 4 비교
{2, 5, 8, 6, 4} => 2, 5 비교
{2, 4, 8, 6, 5} 

3회
{2, 4, 8, 6, 5}  => 3, 4 비교
{2, 4, 6, 8, 5}  => 3, 5 비교
{2, 4, 5, 8, 6}  

4회 
{2, 4, 5, 8, 6} => 4, 5 비교
{2, 4, 5, 6, 8} 
```


## 삽입 정렬

레코드를 이전 값들과 각각 비교하고 비교한 값이 더 큰 경우 레코드를 비교한 값 자리에 삽입합니다. 시간 복잡도는 O(n^2)입니다.

```
배열 {8, 5, 6, 2, 4}를 삽입 정렬로 정렬해보자.

1회
{8, 5, 6, 2, 4} => 1, 2 비교
{5, 8, 6, 2, 4} 

2회
{5, 8, 6, 2, 4} => 1, 3 비교
{5, 8, 6, 2, 4} => 2, 3 비교
{5, 6, 8, 2, 4} 

3회
{5, 6, 8, 2, 4} => 1, 4 비교
{2, 5, 6, 8, 4} => 2, 4 비교
{2, 5, 6, 8, 4} => 3, 4 비교
{2, 5, 6, 8, 4}

4회
{2, 5, 6, 8, 4} => 1, 5 비교
{2, 5, 6, 8, 4} => 2, 5 비교
{2, 4, 5, 6, 8} => 3, 5 비교
{2, 4, 5, 6, 8} => 4, 5 비교
{2, 4, 5, 6, 8} 
```
