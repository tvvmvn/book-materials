# 배열 (Array)

자료형이 동일한 구성 요소들이 차례대로 나열된 자료 집합입니다. 

*그림 - 배열*

그렇다면 배열은 어디에 사용될까요? 일련의 목록 형태들이 배열로 표현될 수 있습니다. 예를 들어 매출 데이터나 게시물 목록, 할일 목록 등. 특히 2차원 배열을 사용하면 표(Table)의 형태를 표현할 수도 있어 활용도가 높습니다.


# 물리적 구조와 코드 구현

배열에서 구성 요소들이 메모리 상에서 일렬로 붙어 있습니다. 따라서 중간에 자료를 삽입하거나 특정 요소를 삭제하는 등의 작업을 하기 어렵습니다. 반면 주어진 구성 요소들을 활용하여 반복적인 작업을 할 때 효율적인 자료 구조입니다.

*그림 - 메모리 상에서의 배열 모습*

```c
#include <stdio.h>

int main() {
  int my_array[] = {7, 12, 9, 4, 11};
  int size = sizeof(my_array) / sizeof(my_array[0]);
  int minVal = my_array[0];

  for(int i = 0; i < size; i++) {
    if(my_array[i] < minVal) {
      minVal = my_array[i];
    }
  }

  printf("Lowest value: %d\n", minVal);
  return 0;
}

// Lowest value: 4
```


# 정렬 알고리즘

배열의 요소를 정렬하는 알고리즘입니다.

- 버블 정렬 (Bubble Sort)
- 선택 정렬 (Selection Sort)
- 삽입 정렬 (Insertion Sort)


# 버블 정렬

오른쪽으로 진행하며 인접한 두 개의 레코드 값을 비교하고 비교 결과에 따라 레코드의 위치를 서로 교환합니다. 시간 복잡도는 O(n^2)입니다

```
배열 {8, 5, 6, 2, 4}를 버블 정렬로 정렬해보자.

1회
{8, 5, 6, 2, 4} => 1, 2 비교 
{5, 8, 6, 2, 4} => 2, 3 비교
{5, 6, 8, 2, 4} => 3, 4 비교
{5, 6, 2, 8, 4} => 4, 5 비교
{5, 6, 2, 4, 8}

2회
{5, 6, 2, 4, 8} => 1, 2 비교
{5, 6, 2, 4, 8} => 2, 3 비교
{5, 2, 6, 4, 8} => 3, 4 비교
{5, 2, 4, 6, 8}

3회
{5, 2, 4, 6, 8} => 1, 2 비교
{2, 5, 4, 6, 8} => 2, 3 비교
{2, 4, 5, 6, 8}

4회
{2, 4, 5, 6, 8} => 1, 2 비교 
{2, 4, 5, 6, 8} 
```


# 선택 정렬

n개의 레코드 중에서 최소값을 찾아 첫번째 레코드 위치에 놓고 나머지 (n - 1)개 중에서 다시 최소값을 찾아 두번째 레코드 위치에 놓는 작업을 반복합니다. 시간 복잡도는 O(n^2)입니다.

```
배열 {8, 5, 6, 2, 4}를 선택 정렬로 정렬해보자.

1회
{8, 5, 6, 2, 4} => 1, 2 비교
{5, 8, 6, 2, 4} => 1, 3 비교
{5, 8, 6, 2, 4} => 1, 4 비교
{2, 8, 6, 5, 4} => 1, 5 비교
{2, 8, 6, 5, 4}

2회
{2, 8, 6, 5, 4} => 2, 3 비교
{2, 6, 8, 5, 4} => 2, 4 비교
{2, 5, 8, 6, 4} => 2, 5 비교
{2, 4, 8, 6, 5} 

3회
{2, 4, 8, 6, 5}  => 3, 4 비교
{2, 4, 6, 8, 5}  => 3, 5 비교
{2, 4, 5, 8, 6}  

4회 
{2, 4, 5, 8, 6} => 4, 5 비교
{2, 4, 5, 6, 8} 
```


# 삽입 정렬

레코드를 이전 값들과 각각 비교하고 비교한 값이 더 큰 경우 레코드를 비교한 값 자리에 삽입합니다. 시간 복잡도는 O(n^2)입니다.

```
배열 {8, 5, 6, 2, 4}를 삽입 정렬로 정렬해보자.

1회
{8, 5, 6, 2, 4} => 1, 2 비교
{5, 8, 6, 2, 4} 

2회
{5, 8, 6, 2, 4} => 1, 3 비교
{5, 8, 6, 2, 4} => 2, 3 비교
{5, 6, 8, 2, 4} 

3회
{5, 6, 8, 2, 4} => 1, 4 비교
{2, 5, 6, 8, 4} => 2, 4 비교
{2, 5, 6, 8, 4} => 3, 4 비교
{2, 5, 6, 8, 4}

4회
{2, 5, 6, 8, 4} => 1, 5 비교
{2, 5, 6, 8, 4} => 2, 5 비교
{2, 4, 5, 6, 8} => 3, 5 비교
{2, 4, 5, 6, 8} => 4, 5 비교
{2, 4, 5, 6, 8} 
```


# 버블 정렬을 C로 구현한 코드

```c
#include <stdio.h>

int main() {
  int my_array[] = {64, 34, 25, 12, 22, 11, 90, 5};
  int n = sizeof(my_array) / sizeof(my_array[0]);

  for (int i = 0; i < n-1; i++) {
    for (int j = 0; j < n-i-1; j++) {
      if (my_array[j] > my_array[j+1]) {
        int temp = my_array[j];
        my_array[j] = my_array[j+1];
        my_array[j+1] = temp;
      }
    }
  }

  printf("Sorted array: ");
  for (int i = 0; i < n; i++) {
    printf("%d ", my_array[i]);
  }
  printf("\n");

  return 0;
}

// Sorted array: 5 11 12 22 25 34 64 90
```
