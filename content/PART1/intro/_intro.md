# 소프트웨어 공학 (S/W Engineering)

소프트웨어 공학은 소프트웨어의 위기(Software Crisis)를 극복하기 위한 방안으로 연구된 학문입니다. 소프트웨어 위기란 1960년대 후반 체계적인 절차가 없이 진행되어 온 개발로 인해 발생한 소프트웨어의 품질 문제, 개발 비용 증가, 유지보수 불가 등의 복합적 문제를 의미합니다.

소프트웨어 공학은 소프트웨어도 대규모 건축물을 지을 때처럼 공학(Engineering)적 지식을 바탕으로 개발해야 한다는 개념입니다. 


# 소프트웨어 재공학 (S/W Re-engineering)

소프트웨어 재공학은 기존 소프트웨어에 현대적인 기술을 적용해 새롭게 구축하는 방법을 연구하는 학문입니다. 기존의 것이 이미 널리 사용중이거나 방대한 크기인 경우 재구축하는 과정이 더 효율적일 수 있습니다.

S/W 재공학은 쉽게 말해 낡은 건물을 허물고 새로 짓는 대신, 최신 설비로 리모델링하는 과정을 다룹니다.

만약 여러분이 개발 회사에 입사해 새로운 프로젝트가 아닌 기존의 서비스를 다듬고 확장하는 업무를 하게 된다면 여러분은 이미 재공학 과정에 서있는 것입니다.


# 소프트웨어 역공학 (S/W Reverse-engineering)

역공학은 말그대로 '거꾸로(Reverse)'라는 뜻으로, 이미 개발이 완료되고 실제 운영 중인 소프트웨어로부터 설계도/요구사항을 추출하는 과정을 연구하는 분야입니다. 

역공학은 S/W가 오래 전에 만들어져 문서가 유실된 경우 또는 타사의 프로그램을 분석하여 개발에 참고하기 위한 목적 등에 사용될 수 있습니다.


# 소프트웨어 재사용 (S/W Reuse)

소프트웨어 재사용은 이미 개발되고 인정받은 소프트웨어를 신규 소프트웨어 개발에 사용하는 과정을 의미합니다. 예를 들어 기존 소프트웨어의 부품들을 선별하고 적용하는 경우가 있습니다. S/W 재사용을 통해 개발 시간이 단축되고 소프트웨어의 품질이 향상됩니다.

예를 들어 새로운 소셜 미디어를 만드는 과정을 생각해봅시다. 팔로잉, 좋아요 등의 기능들을 이미 존재하고 검증이 완료됬기 때문에 새롭게 개발하는 것 보다 재사용하는 편이 낫습니다.


# CASE 도구

CASE는 컴퓨터-보조 S/W 공학(Computer-Aided S/W Engineering)의 약자로
CASE 도구는 소프트웨어 개발에 사용되는 소프트웨어들을 의미합니다.

요구사항, 설계 등 개발 전반부에서 사용되는 도구를 UpperCASE 도구라고 부르고 구현, 테스트, 유지보수 등 개발 후반부에서 사용되는 도구를 LowerCASE 도구라고 부릅니다.
