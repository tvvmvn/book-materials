# 네트워크

네트워크는 두 대 이상의 컴퓨터를 전화선이나 케이블 등으로 연결하고 자원을 공유하는 것을 의미합니다


# 토폴로지 (Topology)

네트워크를 이루는 장치들이 물리적 또는 논리적으로 배치된 구조를 의미합니다

- 성형(Star)
- 링형(Ring)
- 버스형(Bus)
- 망형(Mesh)

*그림 - 네트워크 구축 모형*


성형: 중앙 허브에 모든 장치가 연결됩니다. 관리가 쉽지만 중앙 허브가 고장 나면 네트워크 전체가 마비됩니다.

망형: 모든 장치가 서로 직접 연결됩니다. 신뢰성이 매우 높지만 구축 비용이 많이 듭니다.

버스형: 하나의 공통된 통신 회선에 장치들이 나열됩니다. 설치가 간단하지만 회선이 끊기면 네트워크 전체에 영향을 미칩니다.

링형: 인접한 장치 간 연결되며 원형을 이룹니다. 충돌이 적지만 장치 하나만 고장 나도 전체 네트워크에 영향을 미칩니다


# 규모에 따른 네트워크 분류

- LAN (Local Area Network)
- MAN (Metropolitan Area Network)
- WAN (Wide Area Network)

LAN : 학교, 회사, 집 등 비교적 좁은 지역을 연결하는 근거리 통신망 (예: 사무실 내의 Wi-Fi나 이더넷).

MAN : 하나의 도시나 대도시 지역을 연결하는 네트워크.

WAN : 국가나 대륙처럼 매우 넓은 범위를 연결하는 광역 통신망. 인터넷이 세계에서 가장 큰 WAN입니다.
