# 데이터 전송 방식

- 가상회선 방식(Virtual Circuit)
- 데이터그램 방식(Datagram)

가상회선 방식은 출발지에서 목적지까지 전송 경로(가상 회선)를 미리 연결하고 가상 회선을 따라 데이터를 순차적으로 전송하는 방식입니다. TCP 프로토콜이 가상회선 방식을 사용합니다.

데이터그램 방식은 사전 연결을 수행하지 않고 순서에 상관없이 개별적으로 데이터를 전송하는 방식입니다. 패킷 헤더에 목적지 주소를 붙입니다. 이 방식에서 사용되는 패킷을 데이터그램이라고 부릅니다. UDP 프로토콜이 데이터그램 방식을 사용합니다.


# DNS (Domain Name System)

IP 주소는 192.168.1.1 처럼 숫자로만 구성되는데, 사람이 보기 편하도록 문자로 표현한 것을 도메인 네임(Domain Name) 이라고 부릅니다. 예를 들어 google.com이 도메인 네임입니다. 이러한 주소 변환을 수행하는 시스템을 DNS이라고 부르며 이 시스템을 운영하는 서버를 DNS 서버라고 부릅니다.


# 사설 IP / 공인 IP

우리가 흔히 말하는 IP 주소는 공인 IP 주소이며 집이나 사무실 등에 정해진 만큼만 할당할 수 있습니다. 하지만 인터넷에 발달로 많은 기기들이 인터넷에 접속해야 할 필요가 생겼고 이를 해결하기 위해 등장한 것이 사설 IP 주소입니다. 

사설 IP 주소는 공인 IP가 제공하는 하나의 네트워크 공간 내에서만 유효한 주소입니다. 다른 네트워크의 사설 IP와 중복되도 문제가 없으므로 사설 IP를 통해 많은 기기들을 인터넷에 연결시킬 수 있습니다.

예를 들어 우리집에 들어오는 인터넷 선은 하나이지만 컴퓨터 뿐만 아니라 스마트폰, 태블릿, 프린터 등이 모두 사설 IP를 통해 인터넷에 접속할 수 있습니다.


# NAT (Network Address Translation)

네트워크 주소 변환(NAT)은 공인 IP 주소와 사설 IP주소를 서로 변환하는 기술입니다. 

일반적으로 외부에 요청을 전송하기 위해서는 응답받을 공인 IP주소를 요청 헤더에 담아야 합니다. 왜냐하면 외부에서는 사설IP를 알지 못하기 때문입니다. 

NAT는 사설 네트워크 내의 기기로부터 요청을 미리 받고 요청 헤더에 담긴 사설 IP 주소를 공인 IP주소로 변환합니다. 덕분에 사설 네트워크 내의 기기가 외부에 요청을 전송할 수 있습니다.

반대로 외부로부터 응답이 오면 NAT는 응답을 미리 받아 응답 헤더에 담긴 공인 IP를 요청을 전송한 기기의 사설 IP로 변환합니다. 덕분에 사설 네트워크 내에서 올바른 기기가 응답을 받을 수 있습니다.
