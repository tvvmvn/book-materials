## 개념

인터넷에 연결된 모든 컴퓨터 자원을 구분하기 위한 고유한 주소입니다.
8비트씩 4부분, 총 32비트의 크기를 가집니다.

네트워크 부분과 호스트 부분의 길이에 따라 다음과 같이 5가지 클래스로 구분합니다.

- A 클래스
- B 클래스
- C 클래스
- D 클래스
- E 클래스

A 클래스: 첫 비트가 0 - 127으로 시작하는 클래스입니다. 8비트가 네트워크 비트이며 24비트가 호스트 비트입니다. 따라서 약 128개의 네트워크를 가질 수 있고 각 네트워크당 약 1700만개 정도의 호스트를 가질 수 있습니다. 네트워크의 수는 적지만 호스트가 많이 필요한 경우, 예를 들면 대도시나 대규모 기업 등에 할당되는 클래스입니다

B 클래스: 첫 비트가 128 - 191으로 시작하는 클래스입니다. 16비트가 네트워크 비트이며 16비트가 호스트 비트입니다. 따라서 약 1만 6천개 정도의 네트워크를 가질 수 있고 각 네트워크 당 약 6만 5천개의 호스트를 가질 수 있습니다. 적당한 네트워크 수와 호스트 수가 필요한 경우, 예를 들면 중소 기관/기업 등에 할당되는 클래스입니다

C 클래스: 첫 비트 192 - 223으로 시작하는 클래스입니다. 32비트 중 네트워크 비트는 24비트이고 호스트 비트는 8비트입니다. 따라서 약 2백 만개의 네트워크를 가질 수 있고 각 네트워크 당 254개의 호스트를 가질 수 있습니다. 많은 네트워크가 필요하지만 호스트 수는 많이 필요하지 않은 경우, 예를 들면 소규모 기관/기업 등에 할당되는 클래스입니다.

가용 가능한 호스트의 수를 계산할 때는 항상 2를 빼야합니다. 호스트 비트가 모두 0인 경우는 네트워크 주소를 나타내고 모두 255인 경우는 브로드캐스트 주소용으로 예약되어 있기 때문입니다.

예를 살펴봅시다. 172.30.1.80이라는 IP 주소가 있습니다. 첫 8비트가 172이므로 B클래스에 속한 주소라는 것을 알 수 있습니다. 해당 주소가 속한 네트워크의 주소는 172.30.0.0이고 브로드캐스트 주소는 172.30.255.255입니다.


## 서브넷 마스크

IP 주소 체계에서 네트워크 주소의 범위를 표현하는 방법입니다. 네트워크 비트에 해당하면 1, 호스트 비트에 해당하면 0으로 표기합니다

예를 들면, 

A 클래스의 서브넷 마스크: 11111111.00000000.00000000.00000000
B 클래스의 서브넷 마스크: 11111111.11111111.00000000.00000000.
C 클래스의 서브넷 마스크: 11111111.11111111.11111111.00000000.


## 서브네팅

하나의 네트워크를 세분화 시키는 기술입니다. 네트워크 수는 부족하지만 호스트 수가 남는 경우에 유용하게 사용됩니다. 

예를 들어, 직원 수가 각각 100명인 회사 A와 회사 B가 있습니다. 두 회사 모두 C 클래스에 속한 네트워크를 할당받지만 주소 낭비가 심하게 됩니다. 따라서 하나의 네트워크를 2개로 나누어 각각 126개의 호스트를 가진 두 개의 서브넷을 회사 A와 B에 할당합니다

C 클래스에 속한 192.168.1.0 네트워크를 2개로 나누어보겠습니다.
2개로 나누는 경우 서브넷 마스크의 호스트 비트에서 1개를 1로 바꿉니다.
즉 서브넷 마스크는 11111111.11111111.11111111.10000000가 됩니다.
이를 10진수로 표기하면 255.255.255.128입니다
첫번째 서브넷의 네트워크 주소는 192.168.1.0입니다.
두번째 서브넷의 네트워크 주소는 192.168.1.128입니다.

클래스를 사용하지 않는 IP 주소 체계입니다.
서브넷 마스크를 별도로 표기하지 않고 IP 주소 뒤에 함께 표기합니다.
예를 들면 IP 주소 192.168.1.0/24가 있을 때 24비트가 네트워크 주소, 8비트가 호스트 주소라는 뜻입니다.
