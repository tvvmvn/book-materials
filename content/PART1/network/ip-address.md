# IP 주소

인터넷에 연결된 모든 컴퓨터를 구분하기 위해 사용되는 고유한 주소입니다. IPv4와 후속작인 IPv6가 있습니다.

예를 들어 사람들이 집이나 사무실 주소를 통해 서로 물건을 주고받는 것처럼 인터넷에서는 IP 주소를 활용해 데이터를 주고받습니다.


# IPv4 

8비트씩 4부분으로 구성되며 총 32비트의 크기를 가집니다.
네트워크와 호스트 구성 방식에 따라 다음과 같이 5가지 클래스로 구분합니다.

- A 클래스
- B 클래스
- C 클래스
- D 클래스
- E 클래스


A 클래스는 첫 비트가 0 - 127으로 시작하는 클래스입니다. 8비트가 네트워크 비트이며 24비트가 호스트 비트입니다. 따라서 약 128개의 네트워크를 가질 수 있고 각 네트워크당 2^24개의 호스트를 가질 수 있습니다. 

네트워크의 수는 적지만 호스트가 많이 필요한 경우, 예를 들면 국가나 대형 ISP(통신사)에 할당됩니다.


B 클래스는 첫 비트가 128 - 191으로 시작하는 클래스입니다. 16비트가 네트워크 비트이며 16비트가 호스트 비트입니다. 따라서 약 1만 6천개 정도의 네트워크를 가질 수 있고 각 네트워크 당 약 2^16개의 호스트를 가질 수 있습니다. 

적당한 네트워크 수와 호스트 수가 필요한 경우, 예를 들면 중대형 기관에 할당되는 클래스입니다


C 클래스는 첫 비트가 192 - 223으로 시작하는 클래스입니다. 32비트 중 네트워크 비트는 24비트이고 호스트 비트는 8비트입니다. 따라서 약 2백 만개의 네트워크를 가질 수 있고 각 네트워크 당 2^8개의 호스트를 가질 수 있습니다. 

많은 네트워크가 필요하지만 호스트 수는 많이 필요하지 않은 경우, 예를 들면 소규모 기관이나 가정용 등으로 사용되는 클래스입니다.


D 클래스는 첫 비트가 224 - 239로 시작하는 클래스입니다. 멀티캐스트 용으로 사용됩니다.


E 클래스는 실험용 주소로 실생활에서 사용되지는 않습니다.


일반적으로 한 네트워크 내에서 실제로 사용 가능한 호스트의 수를 계산할 때는 2를 빼야합니다. 호스트 비트가 모두 0인 경우는 네트워크 주소를 나타내고 모두 255인 경우는 브로드캐스트 주소용으로 예약되어 있기 때문입니다.


# IPv4 주소 예시

예를 살펴봅시다. IP 주소 200.10.20.30가 있습니다.

첫번째. 호스트가 속한 네트워크의 클래스 파악하기
첫 자리가 200이므로 C 클래스에 속한 주소라는 것을 알 수 있습니다. 

두번째. 호스트가 속한 네트워크의 네트워크 주소와 브로드캐스트 주소
네트워크 주소: 200.10.20.0
브로드캐스트 주소: 200.10.20.255

세번째. 이 네트워크의 총 사용가능한 호스트의 수
사용 가능한 호스트의 IP 주소는 200.10.20.1 ~ 200.10.20.254입니다.
총 254개입니다.


# IPv6 

IPv4의 주소 부족 문제를 해결하기 위해 개발된 차세대 주소 체계입니다.
거의 무한에 가까운 주소를 제공할 수 있습니다. 또한 IPv4에 비해 성능이 향상되고 보안이 강화되었습니다.

16비트씩 8부분, 총 128비트로 구성됩니다. 각 부분을 16진수로 표현하고 콜론으로 구분합니다. 다음은 IPv6 주소의 실제 모습입니다.

예) 2001:0db8:0000:0000:0000:ff00:0042:8329


# IPv6의 데이터 전달 방식(Casting)

- 유니캐스트(Unicast)
- 멀티캐스트(Multicast)
- 애니캐스트(Anycast)


유니캐스트는 서버와 클라이언트가 서로 데이터를 주고받는 상황처럼 일대일(1:1) 통신을 의미합니다. 인터넷 서핑, 이메일, 영상 시청 등 우리가 일상 생활에서 가장 많이 사용하는 통신 방식입니다.


멀티캐스트는 하나의 서버가 여러 대의 클라이언트에게 데이터를 보내는 상황처럼 일대다(1:N) 통신을 의미합니다. 단체 채팅, 화상 회의, 라이브 스트리밍 등이 멀티캐스트 방식으로 통신합니다.


애니캐스트는 클라이언트가 같은 일을 하는 여러 개의 서버 중에서 지리적으로 가장 가까운 서버에 요청을 보내는 상황처럼 근접 거리 기반의 일대일(1:1) 통신을 의미합니다. 예를 들어 콘텐츠 전송 네트워크(CDN)처럼 우리가 잘 모르지만 항상 이용하고 있는 기술이 애니캐스트 방식으로 통신합니다.
