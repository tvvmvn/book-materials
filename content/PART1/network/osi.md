# OSI Model

다른 시스템 간의 원활한 통신을 위해 ISO(국제 표준화 기구)에서 제안한 
네트워크 통신 체계입니다.

- 계층 7. 응용 계층 (Application Layer)
- 계층 6. 표현 계층 (Presentation Layer)
- 계층 5. 세션 계층 (Session Layer)
- 계층 4. 전송 계층 (Transport Layer)
- 계층 3. 네트워크 계층 (Network Layer)
- 계층 2. 데이터 링크 계층 (Data Link Layer)
- 계층 1. 물리 계층 (Physical Layer)

1-3 계층을 하위 계층, 4-7 계층을 상위 계층으로 구분하기도 합니다.


# 계층 7. 응용 계층

응용 계층은 여러분이 사용중인 응용 프로그램과 네트워크가 만나는 지점입니다. 


# 계층 6. 표현 계층

- 데이터 변환: 서로 다른 시스템이 다른 데이터 형식을 사용할 경우 데이터 변환을 수행해서 통신을 가능하게 합니다.
- 압축: 데이터를 빠른 속도로 전송하기 위해 위해 원본 파일을 압축해서 크기를 줄입니다.
- 데이터 암호화: 전송 도중 데이터가 탈취될 수 있는 경우 등에 대비해서 데이터를 암호화합니다.


# 계층 5. 세션 계층

두 시스템 간의 연결을 설정하고 종료하는 일을 담당하는 계층입니다. 


# 계층 4. 전송 계층

종단 시스템 간 데이터 전송(Transport)을 담당하는 계층입니다.
네트워크 간 통신에 대해서 흐름 제어와 오류 제어를 담당합니다.
데이터를 세그먼트(Segment)로 나누고 관리합니다.

- 흐름 제어: 연결 속도가 빠른 송신자가 연결 속도가 느린 수신자를 압도하지 않도록 퇴적의 전송 속도를 결정합니다.
- 오류 제어: 데이터 수신이 완료되었는지 확인하고 수식되지 않은 데이터가 있는 경우 재전송을 요청합니다.


# 계층 3. 네트워크 계층

데이터가 목적지에 도달하기 위해서 최적의 물리적 경로를 탐색하는 활동인 라우팅(Routing)을 담당하는 계층입니다.
세그먼트를 패킷(Packet)으로 나누고 관리합니다.


# 계층 2. 데이터 링크 계층

시스템 간 연결 설정, 유지, 종료를 담당하는 계층입니다.
인트라 네트워크 통신에서 흐름 제어와 오류 제어를 담당합니다.

패킷을 프레임(Frame)으로 나누고 관리합니다.


# 계층 1. 물리 계층

전송에 필요한 두 장치 간의 실제 접속과 절단 등 
기계적, 전기적, 기능적, 절차적 특성에 대한 규칙을 정의하는 계층입니다.

프레임을 1과 0으로만 표현된 데이터인 비트스트림(Bitstream)으로 나누고 관리합니다.


# 응용 해보기


강이지와 고양이가 이메일을 주고받는 과정을 통해 OSI 모델을 이해해봅시다.

응용 계층: 강아지가 이메일 애플리케이션을 통해 친구에게 이메일을 전송합니다. 이메일을 전송하므로 통신 프로토콜은 HTTP가 아닌 SMTP가 될 것입니다.

프레젠테이션 계층: 강아지의 이메일은 전송 전 안전하게 암호화됩니다. 또한 빠른 전송을 위해 압축됩니다.

세션 계층: 강이지와 고양이가 서로 이메일을 주고받을 수 있도록 연결(세션)을 설정합니다.

전송 계층: 원본 데이터를 여러 개의 조각(Segment)으로 나눕니다.

네트워크 계층: 세그먼트는 더 작은 조각인 패킷으로 나누어집니다. 각 패킷은 최적의 전송을 위해 나누어져 전송될 것이므로 패킷마다 목적지의 IP 주소가 작성됩니다.

데이터 링크 계층: 패킷은 이제 프레임(Frame)으로 나뉩니다. 이제 전송 준비가 끝났습니다.

물리 계층: 프레임은 이제 비트스트림로 바뀌고 마침내 전기 신호로 변환된 뒤 해저케이블과 전파 등을 타고 멀리멀리 날아가 고양이에게 날라갑니다.

여기까지입니다. 수신 과정은 반대로 생각하면 됩니다.
