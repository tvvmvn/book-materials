# OSI Model

다른 시스템 간의 원활한 통신을 위해 ISO(국제 표준화 기구)에서 제안한 네트워크 통신 체계입니다

1. 물리 계층
2. 데이터 링크 계층
3. 네트워크 계층
4. 전송 계층
5. 세션 계층
6. 표현 계층
7. 응용 계층


## 물리 계층

전송에 필요한 두 장치 간의 실제 접속과 절단 등 기계적, 전기적, 기능적, 절차적 특성에 대한 규칙을 정의합니다.


## 데이터 링크 계층

시스템 간 연결 설정과 유지 및 종료를 담당합니다


## 네트워크 계층

시스템 간의 네트워크 연결을 관리하고 데이터의 교환과 중계 기능을 담당합니다


## 세션 계층

송/수신 측 간의 관련성을 유지시키고 대화 제어를 담당합니다


## 표현 계층

상이한 데이터 표현 형태를 갖는 시스템 간의 상호 접속을 위해서 코드 변환, 데이터 암호화 및 압축, 구문 검색 등의 기능을 담당합니다.


## 응용 계층

응용 프로그램이 OSI 환경에 접근할 수 있도록 서비스를 제공합니다.
