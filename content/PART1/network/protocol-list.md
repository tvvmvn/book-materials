## TCP

가상 회선 방식을 기반으로 하는 양방향 연결 서비스를 제공합니다. 패킷의 다중화, 순서 제어, 오류 제어, 흐름 제어 등의 기능을 제공합니다. OSI 7계층에 속합니다


## IP

데이터그램 방식을 기반으로 하는 비연결형 서비스를 제공합니다. 패킷의 분해 및 조립, 주소 지정, 경로 선택 기능을 등을 제공합니다.
OSI 7 계층에 속합니다


## UDP

데이터 전송 전에 연결을 설정하지 않는 비연결형 서비스를 제공하는 프로토콜입니다. TCP에 비해 상대적으로 단순한 헤더 구조를 가지기 때문에 오버헤드가 적고 흐름 제어나 순서 제어가 없어 전송 속도가 빠르다는 장점이 있습니다. 실시간 전송에 유리하며 신뢰성보다는 속도가 중요시되는 네트워크에서 주로 사용됩니다. 


## ICMP

IP와 조합하여 작동하며 통신 중에 발생하는 오류를 처리하고 전송 경로를 변경하는 등의 역할을 수행하는 제어 메시지를 관리하는 프로토콜입니다.


## ARP/RARP

ARP는 호스트의 IP 주소를 호스트와 연결된 네트워크 접속 장치의 MAC 주소로 변환하는 기능을 수행하는 프로토콜입니다. 
RARP는 ARP와 반대로 물리적 주소를 IP 주소로 변환하는 기능을 수행하는 프로토콜로 역순 주소결정 프로토콜이라고 불립니다.
