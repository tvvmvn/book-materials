# 프로토콜

프로토콜은 서로 다른 기기들 간의 데이터 교환을 원활하게 수행할 수 있도록 표준화시킨 통신규약입니다.

프로토콜의 기본 요소

- 구문(Syntax)
- 의미(Semantics)
- 시간(Timing)

구문: 전송하고자 하는 데이터의 형식, 부호화, 신호 레벨 등을 규정합니다

의미: 정확한 정보 전송을 위한 협조 사항과 제어 정보 등을 규정합니다

시간: 통신 속도, 메시지의 순서 등을 규정합니다


# 프로토콜의 기능

- 단편화와 재결합
- 캡슐화
- 연결 제어
- 흐름 제어
- 오류 제어
- 동기화
- 주소 지정

단편화와 재결합: 송신 측에서 긴 데이터 블록을 전송하기 쉬운 작은 단위(패킷)로 나누는 것을 단편화라 하고, 수신 측에서 이를 원래 데이터로 합치는 것을 재결합이라고 합니다.


연결 제어: 데이터 전송 시 연결을 설정하는 방식에 따라 두 가지로 나뉩니다.

- 가상회선 방식: 데이터를 보내기 전 상대방과 미리 가상의 경로(가상회선)을 설정하고 경로를 따라 패킷을 전송합니다. TCP 프로토콜이 가상 회선 방식을 사용합니다
- 데이터그램 방식: 연결 설정 없이 독립적인 데이터 단위(데이터그램)로 패킷을 전달합니다. IP, UDP 프로토콜 등이 데이터그램 방식을 사용합니다.


흐름 제어: 전송되는 패킷의 양이나 속도를 제어하는 기능입니다.

- 정지/대기 : 수식측의 확인 신호(ACK)를 받은 후 다음 패킷을 전송합니다.
- 슬라이딩 윈도우: 사전에 수신측으로부터 한번에 전송받을 수 있는 패킷의 양(Window Size)을 전달받은 뒤 그 양 만큼 한번에 패킷을 전송합니다.


오류 제어 : 전송 중에 데이터가 변형되거나 손실되었는지 확인하고 이를 바로잡는 기능입니다.

- 검출: 체크섬(Checksum)이나 CRC를 통해 데이터의 무결성을 확인합니다.
- 복구: 오류가 발견되면 재전송을 요청(ARQ)하거나 스스로 오류를 수정합니다.


동기화: 두 통신 장치 간에 데이터를 주고받는 시점이나 타이밍을 일치시키는 기능입니다.
