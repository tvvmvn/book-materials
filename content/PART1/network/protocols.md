# 프로토콜 (Protocols)

프로토콜은 네트워크 상에서 원활한 통신을 위해 제안된 통신 표준입니다. 
다음은 프로토콜의 3대 구성 요소입니다.

- 구문(Syntax): 전송 데이터의 구조와 형식을 정의합니다.

- 의미(Semantics): 구문의 의미와 의미에 따른 제어 정보, 기타 협조 사항을 정의합니다.

- 시간(Timing): 전송 속도와 전송 순서를 정의합니다.

프로토콜 정의, 좀 어렵죠? 전화 통화에 비유해봅시다.

구문: 처음 인사, 본문 내용, 작별 인사 순서대로 이야기하세요.
의미: 작별 인사를 하면 전화를 서로 끊기로 합시다.
시간: 너무 빠르게 말하지 마세요.


# 프로토콜의 기능

프로토콜이 수행하는 기능으로 단편화/재결합, 캡슐화, 흐름 제어, 오류 제어, 동기화, 순서 제어, 주소 지정(Addressing), 다중화, 경로 제어(Routing) 등이 있습니다.

# 흐름 제어

전송되는 패킷의 양이나 전송 속도를 제어하는 기능입니다.

- 정지-대기 (Stop-and-Wait): 수신측의 확인 신호(ACK)를 받은 후 다음 패킷을 전송합니다. 한 번에 하나의 패킷만 전송할 수 있습니다. 

- 슬라이딩 윈도우(Sliding Window): 사전에 수신자로부터 한번에 전송받을 수 있는 패킷의 양(Window Size)을 전달받습니다. 데이터를 전송할 때 미리 협의한 윈도우 사이즈 만큼 패킷을 전송합니다.
