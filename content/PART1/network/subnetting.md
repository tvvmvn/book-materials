# 서브네팅 (Subnetting)

하나의 네트워크를 여러 개의 네트워크(서브넷)로 분할하는 기술입니다. 네트워크가 낭비되는 것을 방지할 수 있습니다.

예를 들어, 직원 수가 각각 100명인 회사 A와 회사 B가 있습니다. 두 회사 모두 C 클래스에 속한 네트워크(254개 호스트 수용 가능)를 할당받지만 각 회사에서 100개가 넘는 주소가 낭비가 낭비됩니다. 

따라서 네트워크 관리자는 C에 속한 하나의 네트워크를 2개의 네트워크(서브넷)로 나누어 두 회사에게 하나씩 제공합니다. 그러면 각 서브넷은 127개의 호스트를 가질 수 있으므로 모든 직원들에게 충분히 IP 주소를 제공하고 낭비되는 공간이 현저히 줄어듭니다.


# 서브넷 마스크 (Subnet Mask)

# CIDR (Classless Inter-Domain Routing) 표기법

네트워크의 범위를 IP 주소 뒤에 작성하는 표기법입니다. 서브넷 마스크를 별도로 작성할 필요가 없습니다.

예를 들어 IP 주소 192.168.1.0/24가 있을 때 24비트가 네트워크 주소, 나머지 8비트가 호스트 주소라는 뜻입니다.
