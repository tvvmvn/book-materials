# TCP/IP

OSI 모델과 함께 시스템 간 올바른 송/수신을 위한 프로토콜 체계입니다. 

1. 응용 계층
2. 전송 계층
3. 인터넷 계층
4. 네트워크 접근 계층


## 응용 계층

응용 프로그램 간의 데이터 송/수신 기능을 제공합니다

프로토콜: HTTP, FTP, DNS 등


## 전송 계층

송/수신 시스템 간의 신뢰성 있는 통신 기능을 제공합니다.

프로토콜: TCP, UDP 등


## 인터넷 계층

데이터 전송을 위해 주소 지정, 경로 설정 기능을 제공합니다

프로토콜: IP, ICMP, ARP, RARP


## 네트워크 계층

실제 데이터(프레임)를 송/수신 하는 역할을 담당합니다.

프로토콜: 이더넷, HDLS, ARQ 등
