운영체제란 컴퓨터 시스템의 자원들을 효율적으로 관리하고 사용자가 컴퓨터를 편리하고 효과적으로 사용할 수 있도록 환경을 제공하는 여러 프로그램의 모임입니다. 컴퓨터 사용자와 하드웨어 간의 인터페이스로 동작하는 시스템 소프트웨어의 일종입니다. 프로세서, 기억장치, 입/출력 장치, 파일 등의 자원을 관리합니다.


# 주요 운영체제

- UNIX
- LINUX
- Android

1960년대 AT&T 벨 연구소, MIT, General Electric이 공동으로 개발한 운영체제입니다. 시분할 시스템을 위해 설계된 대화식 운영체제입니다. 대부분 C언어로 작성되어 이식성이 높고 장치, 프로세스 간의 호환성이 높습니다. 트리 구조의 파일 시스템을 가집니다. 

UNIX의 구성

- 커널
- 쉘

커널: UNIX의 가장 핵심적인 부분으로 하드웨어를 보호하고 프로그램과 하드웨어 간의 인터페이스 역할을 담당합니다. 프로세스 관리, 기억 장치 관리, 파일 관리, 입/출력 관리, 프로세스 간 통신, 데이터 전송/변환 등 여러가지 기능을 수행합니다

쉘: 사용자의 명령어를 인식하고 프로그램을 호출하고 명령을 수행하는 명령어 해석기입니다. 시스템과 사용자 간의 인터페이스를 담당합니다.

리눅스는 1991년 리누스 토발즈가 UNIX를 기반으로 개발한 오픈소스 운영체제입니다. 

안드로이드는 구글 사에서 개발한 리눅스 커널 위에서 작동하는 오픈소스 모바일 운영체제입니다. 자바와 코틀린으로 응용 프로그램을 개발합니다.
