# 기억장치 관리 전략

보조기억장치의 프로그램이나 데이터를 주기억장치에 적재시키는 시기, 위치 등을 지정하여 한정된 주기억장치의 공간을 효율적으로 사용하기 위한 활동입니다

- 반입 전략(Fetch)
- 배치 전략(Placement)
- 교체 전략(Replacement)


# 반입 전략

보조기억장치에 보관중인 프로그램이나 데이터를 언제 주기억장치로 적재할 것인지 결정하는 전략입니다

- 요구 반입: 실행 중인 프로그램이 특정 프로그램이나 데이터의 참조를 요구할 때 적재합니다
- 예상 반입: 실행중인 프로그램에 의해 참조가 될 프로그램이나 데이터를 예상하고 적재하는 방법입니다.


# 배치 전략

새로 반입되는 프로그램이나 데이터를 주기억장치의 어느 위치에 적재시킬 것인지를 결정하는 전략입니다

- 최초 적합(First Fit)
- 최적 적합(Best Fit)
- 최악 적합(Worst Fit)

최초 적합: 프로그램이나 데이터가 들어갈 수 있는 크기의 빈 영역 중에서 첫번째 분할 영역에 배치시킵니다

최적 적합: 프로그램이나 데이터가 들어갈 수 있는 크기의 빈 영역 중에서 단편화를 가장 작게 남기는 분할 영역에 배치시킵니다

최악 적합: 프로그램이나 데이터가 들어갈 수 있는 크기의 빈 영역중에서 단편화를 가장 많이 남기는 분할 영역에 배치시킵니다

*예제 - 배치 전략*


# 교체 전략

주기억장치의 모든 영역이 이미 사용중인 상태일 때 새로운 프로그램이나 데이터를 적재하기 위해 어느 영역을 교체할 것인지 결정하는 전략입니다.

교체 전략에 사용되는 주요 알고리즘은

- FIFO
- OPT
- LRU
- LFU
- NUR
- SCR
