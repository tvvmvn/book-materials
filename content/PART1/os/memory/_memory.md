# 메모리 (Memory)

기억 장치라고도 부릅니다. 마치 요리사가 조리대에서 요리를 하는 것처럼 CPU가 처리할 데이터들이 보관되는 곳입니다.

- 주기억장치 (Main Memory)
- 보조기억장치 (Secondary Memory)
- 기타

주기억장치는 우리가 흔히 '메모리', '램(RAM)'이라고 부르는 메모리입니다. 실행중인 프로그램이 거주하는 공간입니다. CPU가 램에서 할 일(프로세스)을 가져와서 처리합니다. 전원을 끄면 초기화되는 휘발성 메모리입니다.

보조기억장치는 프로그램 저장 공간입니다. 용량이 크고 저렴하지만 속도가 느립니다. 전원을 꺼도 유지되는 비휘발성 메모리입니다.
예) HDD, SSD

그 밖에 레지스터, 캐시 메모리 등이 있습니다.
레지스터는 CPU 내부에 위치한 메모리입니다. 속도가 가장 빠르지만 비싸고 용량이 작습니다.

캐시 메모리는 CPU 내부 또는 주변에 위치한 메모리입니다. 속도가 빠른 CPU와 상대적으로 느린 RAM 사이에서 속도 차이를 메우는 역할을 하는 메모리입니다.


# 메모리 주소

CPU가 어떻게 메모리에서 필요한 데이터를 찾을 수 있을까요?
메모리 주소가 있습니다. 보통 16진수로 표현됩니다.

예)x1234
