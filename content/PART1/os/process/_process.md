# 프로세스

프로세스는 프로세서에 의해 처리되는 사용자 프로그램, 즉 실행중인 프로그램을 의미합니다.

스레드는 시스템의 자원을 할당받아 실행되는 프로그램의 단위 또는 프로세스 내의 작업 단위를 의미합니다. 
하나의 프로세스에 하나의 스레드가 존재하는 경우를 단일 스레드, 하나 이상의 스레드가 존재하는 경우를 다중 스레드라고 합니다. 
프로세스의 일부 특성을 가지고 있기 때문에 경량 프로세스라고도 불립니다. 


# PCB

프로세스 제어 블록(Process Control Block)의 약자로 운영체제가 프로세스에 대한 중요한 정보를 저장해 놓는 곳입니다. 각 프로세스가 생성될 때마다 고유의 PCB가 생성되고 프로세스가 완료되면 PCB도 제거됩니다. 

PCB에 저장된 주요 정보들은 다음과 같습니다.

- 프로세스의 현재 상태
- 포인터
- 프로세스 식별자
- 스케줄링 및 프로세스 우선순위
- CPU 레지스터 정보
- 주기억장치 관리 정보


# 프로세스 상태 전이

프로세스가 시스템 내에 존재하는 동안 상태가 변하는 것을 의미합니다. 

<그림 - 프로세스 상태 전이도>


- 제출: 작업을 처리하기 위해 사용자가 작업을 시스템에 제출한 상태
- 접수: 제출된 작업이 스풀 공간인 디스크의 할당 위치에 저장된 상태
- 준비: 프로세스가 프로세서를 할당받기 위해 기다리고 있는 상태
- 실행: 준비상태 큐에 있는 프로세스가 프로세서를 할당받고 실행 중인 상태
- 대기: 입/출력이 필요한 경우 프로세스의 실행이 중단되고 입/출력이 완료될 때까지 대기 중인 상태
- 종료: 프로세스의 실행이 끝나고 프로세스 할당이 해제된 상태
- 디스패치: 준비 상태에서 대기하고 있는 프로세스가 프로세서를 할당받아 실행 상태로 변하는 것
- Wake Up: 입/출력 작업이 완료되어 프로세스가 대기 상태에서 준비 상태로 변하는 것
- Spooling: 입/출력할 데이터를 직접 입/출력 장치에 보내지 않고 나중에 한꺼번에 입/출력하기위해 디스크에 저장하는 과정.
