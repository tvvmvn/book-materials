# 프로세스 스케줄링 (Scheduling)

프로세스를 처리하기 위해 프로세스에게 자원을 할당하는 순서나 방법을 다루는 과정을 의미합니다.

- 비선점 방식 (Non-preemptive)
- 선점 방식 (Preemptive)


비선점 방식에서는 프로세스가 한번 CPU를 할당 받으면 프로세스가 완료될 때까지 CPU를 사용합니다. 일괄처리 시스템에 주로 사용됩니다.

예) FCFS, SJF, HRN


선점 방식에서는 하나의 프로세스가 CPU를 할당받고 실행 중일때 우선 순위가 더 높은 다른 프로세스가 CPU를 강제로 빼앗을 수 있습니다. 현대 컴퓨터와 같은 시분할 시스템에 주로 사용됩니다. 

예) Round Robin, SRT, MLFQ


# FCFS

FCFS(First-Come First-Service)는 준비 큐에 도착한 순서대로 CPU를 할당하는 기법입니다.

예제) 세 프로세스 P1(20ms), P2(4ms), P3(6ms)가 순서대로 준비 큐에 도착했을 때 평균 실행시간, 평균 대기시간, 평균 반환시간을 구해보세요.
(괄호 안은 실행 시간 입니다)

FCFS는 도착한 순서에 따라 실행되므로 실행 순서는 P1, P2, P3 순입니다.

각 프로세스의 실행 시간이 P1은 20, P2은 4, P3은 6이므로 평균 실행 시간은 (20 + 4 + 6)/3 = 10입니다.

각 프로세스의 대기 시간이 P1은 0, P2는 20, P3은 24이므로 평균 대기시간은 (0  +  20  +  24)/3 = 14.6입니다.

각 프로세스의 반환 시간이 P1은 20, P2는 24, P3은 30이므로 평균 반환시간은(20  +  24  +  30)/3 = 24.6입니다.


# SJF

SJF(Short-Job First)는 실행 시간이 가장 짧은 프로세스에게 먼저 CPU를 할당하는 기법입니다. 실행 시간이 긴 프로세스가 계속해서 밀려나는 기아 현상(Starvation)이 발생할 수 있습니다.

예제) 세 프로세스 P1(20ms), P2(4ms), P3(6ms)가 순서대로 준비 큐에 도착했을 때 평균 실행시간, 평균 대기시간, 평균 반환시간을 구해보세요.
(괄호 안은 실행시간 입니다)

실행 순서가 짧은 순으로 실행되므로 실행 순서는 P2, P3, P1 순입니다.

각 프로세스의 실행 시간이 P1은 20, P2은 4, P3은 6이므로 평균 실행 시간은 (20 + 4 + 6)/3 = 10입니다.

각 프로세스의 대기 시간이 P2은 0, P3는 4, P1은 10이므로 평균 대기시간은 (0 + 4 + 10)/3 = 4.6입니다.

각 프로세스의 반환 시간이 P2은 4, P3는 10, P1은 30이므로 평균 반환시간은(4 + 10 + 30)/3 = 14.6입니다.


# HRN

HRN(Highest Response-Ratio)는 SJF의 기아 현상을 해결하기 위해 고안된 기법입니다.

[우선순위 점수 = (대기 시간 + 실행 시간) / 실행 시간]

공식에서 알 수 있듯이 실행 시간이 짧을 수록 우선되는 것은 SJF와 같지만 대기 시간이 길수록 점수가 올라갑니다.

예제) 세 프로세스 P1, P2, P3의 실행 시간이 각각 20, 4, 6이고 대기 시간이 각각 10, 20, 10일 때 실행 순서를 구해보세요.

P1의 우선순위 점수: (20 + 10)/20 = 1.5
P2의 우선순위 점수: (4 + 20)/4 = 6
P3의 우선순위 점수: (6 + 10)/6 = 2.6

우선순위 점수가 클수록 우선 됩니다. 따라서 실행 순서는 P2, P3, P1 순입니다.


# Round Robin (RR)

현대 OS의 기반인 시분할 시스템에서 사용하는 방식입니다.
제비 뽑기라는 뜻처럼 이 기법은 모든 프로세스에게 똑같은 시간 할당량(Time Slice)을 줍니다. 그리고 시간이 지나면 CPU를 빼앗는 기법입니다.

예제) 세 프로세스 P1(20ms), P2(4ms), P3(6ms)가 순서대로 준비 큐에 도착하고 프로세스당 시간 할당량이 4초일 때 평균 대기시간과 평균 반환 시간을 구해보세요. (괄호 안은 실행 시간입니다)

다음 순서대로 프로세스가 실행됩니다
===
1. P1 4
2. P2 4 (P2 끝)
3. P3 4
4. P1 4
5. P3 2 (P3 끝)
6. P1 4
7. P1 4
8. P1 4
===

각 프로세스의 대기 시간을 구하는 방법을 알아봅시다. 각 프로세스의 마지막 실행을 기준으로 그 이전의 시간을 모두 더합니다. 그 다음 본인의 실행 시간을 뺍니다.
각 프로세스의 대기 시간은 다음과 같습니다.

P1: 26 - 16(본인 실행시간) = 10
P2: 4
P3: 16 - 4(본인 실행시간) = 12

따라서 평균 대기 시간은 (10 + 4 + 12)/3 = 8.6입니다

각 프로세스의 반환 시간을 구하는 방법을 알아봅시다. 각 프로세스의 마지막 실행을 포함하여 그 이전의 진행 시간을 모두 더합니다. P1는 30, P2는 8, P3는 18이므로 평균 반환시간은 (30 + 8 + 18)/3 = 18.6입니다.


# SRT

SRT는 기본적으로 SJF와 원리가 같지만 선점형입니다. 즉 짧은 프로세스에게 우선권을 주되 더 짧은 프로세스가 오면 현재 실행중인 프로세스로부터 CPU를 빼앗아 그에게 줍니다.

문제) 네 프로세스 P1, P2, P3, P4가 준비 큐에 도착한 시간이 각각 0ms, 1ms, 2ms, 3ms이고 실행 시간이 각각 8ms, 4ms, 9ms, 5ms일 때 평균 대기시간과 평균 반환시간을 구해보세요.

다음은 시간의 흐름에 따른 프로세스의 실행 흐름입니다. 괄호 안은 남은 시간입니다.
===
0ms P1(8ms) => P1 실행
1ms P1(7ms) VS P2(4ms) => P2 실행
2ms P2(3ms) VS P3(9ms) => P2 실행
3ms P2(2ms) VS P4(5ms) => P2 실행
5ms P1(7ms) VS P3(9ms) VS P4(5ms) => P4실행 
10ms P1(7ms) VS P3(9ms) => P1실행
17ms P3(9ms) => 실행
26ms 끝

그림으로 표현하면
A  B  D  A  C   
00 01 05 10 17 26 
===

위의 표로부터 얻은 프로세스별 대기/반환 시간은 다음과 같습니다.

\  대기|반환
P1 09 17
P2 00 04
P3 15 24
P4 02 07

따라서 
평균 대기시간은 (9 + 0 + 15 + 2)/4 = 6.5
평균 반환시간은 (17 + 4 + 24 + 7)/4 = 13
