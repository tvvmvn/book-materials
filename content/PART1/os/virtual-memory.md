# 가상 기억 장치

가상 기억장치는 보조기억장치의 일부를 주기억장치처럼 사용하는 것으로, 용량이 작은 주기억장치를 마치 큰 용량을 가진 것처럼 사용하는 기법입니다.

가상 기억장치의 구현 방법은

- 페이징
- 세그멘테이션


페이징: 가상기억장치에 보관된 프로그램과 주기억장치의 영역을 동일한 크기로 나눈 후 나눠진 프로그램을 동일하게 나누어진 주기억장치의 영역에 적재시키는 방법입니다. 프로그램을 일정한 크기로 나눈 단위를 페이지라고 하며 페이지 크기로 나누어진 주기억장치 내의 공간을 페이지 프레임이라고 합니다. 주소 변환을 위해 페이지의 위치 정보를 가지고 있는 페이지 맵 테이블이 필요합니다.

세그멘테이션: 가상기억장치에 보관된 프로그램을 다양한 크기의 논리적인 단위로 나눈 다음 주기억장치에 적재시키는 방법입니다. 프로그램을 배열이나 함수 등과 같이 논리적인 크기로 나눈 단위를 세그멘트라고 합니다. 주소 변환을 위해 세그먼트의 위치 정보를 가지고 있는 세그멘트 맵 테이블이 필요합니다.


## 페이징

페이징 기법에서 프로그램을 페이지 단위로 나눌 때 페이지의 크기에 따라 시스템에 미치는 영향이 다릅니다. 

페이지 크기가 작을 경우 페이지 단편화가 감소되고 한 개의 페이지를 주기억장치로 이동시키는 시간이 줆어듦니다. 

페이지 크기가 클 경우 페이지 맵 테이블의 크기가 작아지고 매핑 속도가 빨라집니다.


## 워킹 셋

프로세스가 주기억장치를 참조할 때 일부 페이지만 집중적으로 참조하는 성질을 지역성이라고 합니다. 이 지역성은 다음의 두 가지로 구분됩니다.

- 시간 지역성
- 공간 지역성

시간 구역성은 프로세스가 일정 시간 동안 특정 페이지에 집중적으로 접근하는 성질입니다.
공간 구역성은 프로세스가 특정 위치의 페이지에 집중적으로 접근하는 성질입니다. 이 지역성을 활용하여 워킹 셋을 활용하는 방법이 등장했습니다.

워킹 셋은 프로세스가 일정 시간동안 자주 참조하는 페이지들의 집합을 의미합니다. 워킹 셋을 주기억장치에 상주시키면 페이지 부재와 그에 따르는 교체 현상이 줄어들기 때문에 작업의 효율이 증가합니다. 특히 잦은 페이지의 부재로 인해 프로세스의 처리 시간보다 페이지 교체에 소요되는 시간이 더 많아지는 스레싱 현상을 방지합니다.


## 페이지 교체 알고리즘

페이지의 부재가 발생하면 가상기억장치에서 필요한 페이지를 찾아 주기억장치에 적재해야 합니다. 이때 주기억장치의 모든 페이지 프레임이 사용중일 때 어떤 페이지 프레임을 교체할 것인지 결정하는 알고리즘을 의미합니다

- OPT
- FIFO
- LRU
- LFU
- NUR
- SCR
