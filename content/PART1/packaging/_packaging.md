# 빌드 자동화 도구

빌드, 테스트, 배포를 자동화하는 도구입니다. 애자일과 같은 지속적인 통합(CI) 개발 환경에서 유용하게 활용됩니다.

- Jenkins
- Gradle
- Ant
- Maven

Jenkins는 가장 많이 사용되는 빌드 도구로, 자바 기반의 오픈소스 도구입니다. SVN, Git 등 대부분의 형상 관리 도구와 연동이 가능합니다. Web UI 제공으로 편리한 사용성이 장점입니다.

Gradle은 안드로이드 앱 개발 환경에서 사용되는 Groovy 기반의 오픈소스 빌드 도구입니다. 안드로이드 뿐만 아니라 플러그인을 설정하면 자바, C/C++, 파이썬 등의 언어로 작성된 앱도 빌드할 수 있습니다. Groovy 기반의 DSL을 스크립트 언어로 사용합니다.

Maven은 아파치 소프트웨어 재단에서 개발한 빌드 도구입니다. 의존성을 설정하여 라이브러리를 관리합니다. 


# 디지털 저작권 관리

저작권자가 배포한 디지털 콘텐츠가 의도된 용도로만 사용될 수 있도록 콘텐츠의 생성, 유통, 이용까지의 전 과정에 걸쳐 사용되는 콘텐츠 관리 및 보호 기술입니다.

DRM은 다음의 요소들로 구성됩니다

- 클리어링 하우스: 저작권에 대한 사용 권한, 라이선스 발급, 암호화된 키 관리, 사용량에 따른 결제 관리 등을 수행합니다

- 콘텐츠 제공자: 콘텐츠를 제공하는 저작권자

- 패키저: 콘텐츠를 메타 데이터와 함께 배포 가능한 형태로 묶고 암호화하는 프로그램입니다

- 콘텐츠 분배자: 암호화된 콘텐츠를 유통하는 회사나 사람

- 콘텐츠 소비자: 콘텐츠를 구매해서 소비하는 주체

- DRM 컨트롤러: 배포된 콘텐츠의 이용 권한을 통제하는 프로그램

- 보안 컨트롤러: 콘텐츠 원본을 안전하게 유통하기 위한 전자적 보안 장치


DRM의 기술 요소들

- 암호화: 콘텐츠와 라이선스를 암호화하고 전자 서명을 할 수 있는 기술

- 키 관리: 콘텐츠를 암호화하는데 사용된 키에 대한 저장과 분배 기술

- 암호화 파일 생성: 콘텐츠를 암호화하는 기술

- 식별 기술: 콘텐츠에 대한 식별 체계를 표현하는 기술

- 저작권 표현: 라이선스의 내용을 표현하는 기술

- 정책 관리: 라이선스 발급과 사용에 대한 정책 표현과 관리기술

- 크랙 방지: 크랙에 의한 콘텐츠 사용을 방지하는 기술

- 인증: 라이선스 발급과 사용의 기준이 되는 사용자 인증 기술
