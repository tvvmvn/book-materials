# 디지털 저작권 관리(DRM)

저작권자가 배포한 디지털 콘텐츠가 의도된 용도로만 사용될 수 있도록 콘텐츠의 생성부터 유통, 소비에 이르기까지 전 과정에 걸쳐 사용되는 콘텐츠 관리 및 보호 기술입니다.

예) OTT 서비스, 전자책, 기업 문서


# DRM의 구성 요소

<그림 - DRM 구성 요소와 상호작용>

- 클리어링 하우스 (Clearing House)
- 콘텐츠 제공자 (Provider)
- 콘텐츠 분배자 (Distributor)
- 콘텐츠 소비자 (Consumer)

클리어링 하우스는 저작권에 대한 사용 권한, 라이선스 발급, 암호화 키 관리, 결제 관리 등 저작권 관리의 핵심적인 역할을 수행하는 주체입니다.

콘텐츠 제공자는 콘텐츠를 생산하고 제공하는 주체입니다. DRM 패키저(DRM Packager)를 사용해 콘텐츠를 암호화하고 배포 가능한 형태(Package)로 만듭니다.

콘텐츠 분배자는 콘텐츠 제공자와 소비자 사이에서 암호화된 콘텐츠를 유통하는 주체입니다. 

콘텐츠 소비자는 콘텐츠를 구매하고 소비하는 사람입니다. DRM 컨트롤러에 의해 구매한 콘텐츠의 이용이 통제됩니다. DRM 컨트롤러는 구매한 콘텐츠를 실행하는 클라이언트 프로그램의 내부에 존재합니다.


# DRM의 기술 요소

저작권 보호와 관리에서 바탕이 되는 기술들입니다.

- 암호화(Encryption)
콘텐츠를 보호하기 위해 콘텐츠를 암호화하고 전자 서명을 할 수 있는 기술입니다. 

- 키 관리(Key Management)
콘텐츠를 암호화하는데 사용된 키를 안전하게 저장하고 분배하는 기술입니다.

- 식별 기술(Identification)
일관적인 콘텐츠 관리를 위해 콘텐츠의 식별 체계를 정의하고 표현하는 기술입니다.

- 저작권 표현(Right Expresssion)
라이선스의 내용을 정의하고 표현하는 기술입니다.
예) 홍길동은 A영상을 3번 재생할 권리가 있음

- 정책 관리(Policy Management)
라이선스 발급 및 사용에 대한 정책을 관리하는 기술입니다.

- 인증(Authentication)
사용자가 콘텐츠를 이용하기 위해 발급받은 라이선스를 인증하는 기술입니다.

- 크랙 방지(Tamper Resistance)
크랙(Crack)으로부터 콘텐츠를 보호하는 기술입니다. 크랙은 콘텐츠를 깨는(Crack) 기술을 의미합니다. 즉 콘텐츠에 적용된 저작권 보호 기술을 제거하고 불법적으로 사용하는 행위나 기술을 의미합니다.
