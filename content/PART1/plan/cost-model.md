# 비용 산정 기법

상향식 비용 산정기법과 하향식 비용 산정 기법이 있습니다


## 하향식 산정 기법

하향식 비용 산정기법은 과거의 유사한 경험을 바탕으로 전문 지식이 많은 개발자들이 참여한 회의를 통해 비용을 산정하는 비과학적인 방법입니다. 프로젝트의 전체 비용을 산정한 후 각 작업별로 비용을 세분화합니다. 전문가 감정 기법과 델파이 기법이 있습니다

전문가 감정 기법은 조직 내에 있는 경험이 많은 두 명 이상의 전문가에게 비용 삱정을 의뢰하는 기법입니다. 가장 편리하고 신속하게 비용을 산정할 수 있지만 개인적이고 주관적일 수 있습니다

델파이 기법은 전문가 감정 기법의 주관적인 편견을 보완하기 위해 많은 전문가의 의견을 종합하고 산정하는 기법입니다. 전문가들의 편견이나 분위기에 지배되지 않도록 한 명의 조정자와 여러 전문가로 구성됩니다.


## 상향식 산정 기법

프로젝트의 세부적인 작업 단위별로 비용을 산정한 후 집계하여 전체 비용을 산정하는 방법입니다. 

주요 상향식 비용 산정 기법:

- LOC 기법
- COCOMO
- Putnam
- FP


## LOC 기법

소프트웨어 각 기능의 원시 코드 라인수의 비관치, 낙관치, 기대치를 측정하여 예측치를 구하고 이를 이용하여 비용을 산정하는 기법입니다. 측정이 용이하고 이해하기 쉬워 가장많이 사용되는 기법입니다. 예측치를 이용하여 생산성, 노력, 개발 기간 등의 비용을 산정합니다. 

산정 공식은 다음과 같습니다

- 노력 = LOC / 인당 월평균 생산코드 라인수
- 개발 비용 = 노력 x 단위 비용
- 개발 기간 = 노력 / 투입 인원
- 생산성 = LOC/노력

예를 들어봅시다. LOC 기법에 의하여 예측된 총 라인수가 30,000라인, 개발에 참여할 프로그래머가 5명, 각 프로그래머들의 평균 생산성이 월간 300라인 일때 개발에 소요되는 기간은 얼마일까요? 

노력 = 30,000/300 = 100
개발 기간 = 100/5 = 20

따라서 예상되는 개발 기간은 20개월 입니다.

마지막으로 LOC 기법을 보완한 기법으로 각 기능을 구현시키는 데 필요한 노력을 생명 주기의 각 단계별로 산정하는 개발 단계별 인월수 기법이 있습니다


## COCOMO 모형

LOC를 활용한 비용 산정 기법입니다. 개발한 소프트웨어의 규모(LOC)를 예측한 후 이를 소프트웨어 종류에 따라 다르게 책정되는 비용 산정 방정식에 대입하여 비용을 산정합니다. 비용 산정결과는 프로젝트를 완성하는데 필요한 노력으로 나타납니다.
보헴이 제한했습니다

COCOMO에 따른 소프트웨어 개발 유형

- 조직형
- 반분리형
- 내장형

조직형은 중/소규모의 소프트웨어 개발 유형에 해당합니다. `5만 라인 이하`의 소프트웨어를 개발하는 유형입니다. 일괄 자료 처리용, 과학 기술 계산용, 비즈니스 자료 처리용, 사무 처리용, 업무용, 과학용 응용 소프트웨어 개발에 적합합니다.

반분리형은 조직형과 내장형의 중간형 소프트웨어를 개발하는 유형에 해당합니다. `30 라인 이하` 소프트웨어를 개발하는 유형입니다. 트랜잭션 처리 시스템, 운영체제, 데이터베이스 관리 시스템(DBMS), 컴파일러, 인터프리터 등이 개발에 적합합니다

내장형은 초대형 규모의 소프트웨어 개발 유형입니다. `30만 라인 이상`의 소프트웨어를 개발하는 유형입니다. 트랜잭션 처리 시스템, 운영체제, 신호기 제어 시스템, 미사일 유도 시스템, 실시간 처리 시스템 등의 시스템 프로그램 개발에 적합합니다


## Putnam 모형

소프트웨어 생명주기의 전 과정 동안에 사용될 노력의 분포를 예상하는 모형입니다. Putnam이 제안한 것으로 생명주기 예측 모형이라고도 합니다. 시간에 따른 함수로 표현되는 `Rayleigh-Nordan 곡선의 노력 분포도`를 기초로 합니다. 대형 프로젝트의 노력 분포 산정에 이용됩니다. 모형에 따르면 개발 기간이 늘어날수록 프로젝트에 적용되는 인원의 노력이 감소합니다.


## 기능 점수 모형

소프트웨어의 기능을 증대시키는 요인별로 가중치를 부여하고 요인별 가중치를 합산하여 총 기능점수를 산출합니다. 총 기능 점수와 영향도를 이용하여 기능 점수(FP)를 구한 후 이를 이용해서 비용을 산정하는 기법입니다. 알브레히트가 제안했습니다.

소프트웨어의 기능 증대 요인은 다음과 같습니다

- 자료 입력
- 정보 출력
- 명령어
- 데이터 파일
- 필요한 외부 루틴과의 인터페이스


## 비용 산정 자동화 도구

대표적으로 SLIM과 ESTIMATICS가 있습니다. SLIM은 Putnam 모형을 기초로 하여 개발된 자동화 도구입니다. ESTIMATICS는 FP 모형을 기초로 한 자동화 도구입니다.
