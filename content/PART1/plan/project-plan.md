# 프로젝트 일정 계획

프로젝트의 프로세스를 이루는 소작업을 파악하고 예측된 노력을 각 소작업을 분배하여 소작업의 순서와 일정을 정하는 것을 의미합니다.

다음의 주요 일정 계획에 방법이 있습니다

- PERT/CPM
- 간트 차트
- WBS


# PERT

프로그램 평가 및 검토기술(Program Evaluation and Review Technique)의 약자로 프로젝트에 필요한 전체 작업의 상호 관계를 표시하는 네트워크입니다. 각 작업별로 낙관적인 경우, 가능성이 있는 경우, 비관적인 경우 등 3가지 경우로 나누어 종료시기를 결정합니다. 개발 경험이 없어 소요 기간의 예측이 어려운 프로젝트 일정 계획에 사용합니다. 

*그림 - PERT*

노드와 간선으로 구성되며 원 노드에는 작업, 간선에는 낙관치/기대치/비관치를 표시합니다. 결정 경로, 작업에 대한 경계 시간, 작업 간의 상호 관련성 등을 알 수 있습니다.


# CPM

임계 경로 기법(Critical Path Method)의 약자로 프로젝트 완성에 필요한 작업을 나열하고 작업에 필요한 소요 기간을 예측하는데 사용되는 기법입니다. CPM은 노드와 간선으로 구성된 네트워크입니다.  노드는 작업, 간선은 작업 사이의 전후 의존 관계를 나타냅니다. 

*그림 - CPM*

원형 노드는 각각의 작업 의미하고 작업 이름과 소요 기간을 표시합니다. 박스 노드는 이정표를 의미하며 예상 완료시간을 표시합니다. 간선을 나타내는 화살표의 흐름에 따라 각 작업이 진행되며 이전 작업이 완료되어야 다음 작업을 진행할 수 있습니다.


# 간트 차트

프로젝트의 각 작업들이 언제 시간하고 언제 종료되는지에 대한 작업 일정을 막대 도표를 이용하여 표시하는 프로젝트 일정표입니다. 시간선 차트라고로 합니다. 중간 목표를 미달성 한 경우에 그 이유와 기간을 예측할 수 있게 해줍니다. 사용자와의 문제점이나 예산의 초과 지출 등도 관리할 수 있습니다. 자원 배치와 인원 계획에 유용하게 사용됩니다.

*그림 - 간트 차트*

이정표, 작업 일정, 작업 기간, 산출물로 구성되어 있습니다.
수평 막대의 길이는 각 작업의 기간을 나타냅니다
