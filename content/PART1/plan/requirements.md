# 요구사항

소프트웨어가 어떤 문제를 해결하기 위해 제공하는 서비스에 대한 설명과 정상적으로 운영되는데 필요한 제약조건을 의미합니다. 소프트웨어 개발이나 유지보수 과정에서 필요한 기준과 근거를 제공합니다. 개발에 참여하는 이해관계자들 간의 의사소통을 원활하게 하는 데 도움을 줍니다

요구사항의 유형

- 기능 요구사항
- 비기능 요구사항
- 사용자 요구사항
- 시스템 요구사항

기능 요구사항은 시스템이 무엇을 하는지, 어떤 기능을 하는지 등의 기능이나 수행과 관련된 요구사항입니다. 예를 들면 시스템의 입력이나 출력으로 무엇이 포함되어야 하는지에 대한 사항, 시스템이 어떤 데이터를 저장하거나 연산을 수행해야 하는지에 대한 사항, 시스템이 반드시 수행해야 하는 기능, 사용자가 시스템을 통해 제공받기는 원하는 기능 등입니다

비기능 요구사항은 품질이나 제약사항과 관련된 요구 사항입니다. 예를 들면 시스템의 장비구성 요구사항, 성능 요구사항, 인터페이스 요구사항, 데이터를 구축하기 위해 필요한 요구사항, 테스트 요구사항, 보안 요구사항, 품질 요구사항, 제약사항 프로젝트 관리/자원 요구사항 등이 있습니다


# 요구사항 개발 프로세스

개발 대상에 대한 요구사항을 체계적으로 도출하고 분석한 후 명세서에 정리한 다음 확인 및 검증하는 일련의 구조화된 활동입니다. 요구사항 개발 프로세스가 진행되기 전에 타당성 조사가 선행되어야 합니다. 

1. 요구사항 도출
2. 요구사항 분석
3. 요구사항 명세
4. 요구사항 확인


# 요구사항 도출 또는 수집

시스템, 사용자, 개발자 등 시스템 개발에 관련된 사람들이 서로 의견을 교환하여 요구사항을 어떻게 수집할 것인지를 식별하고 이해하는 과정입니다. 개발자와 고객 사이의 관계가 만들어지고 이해관계자가 식별되는 단계입니다. 요구사항 도출 기법으로는 청취와 인터뷰, 설문, 브레인스토밍, 워크샵, 프로토타이핑, 유스케이스 등이 있습니다


# 요구사항 분석

개발 대상에 대한 사용자의 요구사항 중 명확하지 않거나 모호하여 이해되지 않는 부분을 발견하고 이를 걸러내기 위한 과정입니다. 요구사항의 타당성을 조사하고 비용과 일정에 대한 제약을 설정합니다. 서로 상충되는 요구사항이 있으면 이를 중재하는 과정입니다. 요구사항 분석에 사용되는 대표적인 도구로 자료 흐름도(DFD)와 자료 사전(DD)가 있습니다

자료 흐름도는 요구사항 분석에서 자료의 흐름 및 변환 과정과 기능을 도형 중심으로 기술하는 방법입니다. 자료 흐름 그래프, 버블 파트라고도 합니다.

*그림 - 자료흐름도의 기본 기호*

자료 사전은 자료 흐름도에 잇는 자료를 더 자세히 정의하고 기록한 것입니다. 데이터를 설명하는 데이터라는 의미의 메타 데이터(Meta Data)라고도 부릅니다.

*표 - 자료사전에서 사용되는 표기 기호*


# 요구사항 명세

분석된 요구사항을 바탕으로 모델을 작성하고 문서화하는 단계입니다. 기능 요구사항은 빠짐없이 기술하고 비기능 요구사항은 필요한 것만 기술합니다. 구체적인 명세를 위해 소단위 명세서(Mini-Spec)가 사용될 수 있습니다

요구사항 명세 기법으로 정형 명세기법과 비정형 명세기법이 있습니다. 정형 명세 기법은 수학적 원리를 기반으로 한 기법으로 수학적 기호와 정형화된 표기법을 사용하여 요구사항을 작성합니다. 요구사항을 정확하고 간결하게 표현할 수 있고 요구사항에 대한 결과가 작성자에 관계없이 일관성이 있으므로 완전성 검증이 가능합니다. 반면 표기법이 어려워 사용자가 이해하기는 어렵습니다. 명세 종류로는 VDM, Z, Petri-net, CSP 등이 있습니다

비정형 명세기법은 상태/기능/객체 중심의 명세 기법입니다. 일반 명사, 동사 등의 자연어를 기반으로 서술하거나 다이어그램을 작성합니다. 내용의 이해가 쉬워 의사소통에 용이하다는 장점이 있습니다. 반면 자연어의 사용으로 요구사항에 대한 결과가 작성자에 따라 다르거나 해석이 달라질 수 있습니다. 명세 종류로는 FSM, Decision Table, ER 모형 등이 있습니다


# 요구사항 확인

개발 자원을 요구사항에 할당하기 전에 요구사항 명세서가 정확하게 완전하게 작성되었는지 검토하는 활동입니다. 이해관계자들이 직접 검토해야 합니다. 요구사항 관리 도구를 이용하여 요구사항 정의 문서들에 대해 형상관리(SCM)를 수행합니다.
