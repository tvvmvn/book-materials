# 프로젝트 일정 계획

프로젝트의 프로세스를 이루는 소작업을 파악하고 예측된 노력을 각 소작업을 분배하여 소작업의 순서와 일정을 정하는 것을 의미합니다.

다음의 주요 일정 계획에 방법이 있습니다

- PERT
- CPM
- 간트 차트


# PERT

PERT는 프로그램 평가 및 검토 기술(Program Evaluation and Review Technique)의 약자입니다. 예측이 어려운 불확실한 프로젝트의 일정을 계획하는 기법입니다. 1950년대 미국 해군이 폴라리스 미사일 개발 프로젝트의 일정을 관리하기 위해 고안했습니다.

노드와 화살표로 구성됩니다.

- 노드 (Node)
작업의 시작과 끝. 
- 화살표 (Arrow)
화살표에는 각 작업의 낙관치, 기대치, 비관치 기간을 표시합니다. 

<그림 - PERT>

작업의 낙관치(t0), 기대치(tm), 비관치(tp)를 바탕으로 기대 시간(te)를 계산하는 공식은 다음과 같습니다.
[ te = (t0 + 4tm + tp)/6 ]

예제) 두 작업 A, B를 수행하려고 합니다. 두 작업의 낙관치/기대치/비관치가 각각 2/4/12, 3/6/9일 때 전체 기대 시간을 구해보세요.

A의 기대 시간 = (2 + (4 * 4) + 12)/6 = 5일
B의 기대 시간 = (3 + (4 * 6) + 9)/6 = 6일

따라서 전체 기대 시간은 5일 + 6일 = 11일 입니다.


# CPM

CPM은 임계 경로 기법(Critical Path Method)의 약자입니다. 임계 경로(Critical Path)를 바탕으로 일정을 관리하는 기법입니다.

임계 경로는 프로젝트의 시작부터 끝까지 가는 길 중에서 가장 긴 시간이 걸리는 경로를 의미합니다. 임계 경로가 곧 프로젝트에 필요한 최소 기간을 의미합니다.

- 노드
작업의 시작과 끝
- 화살표
각 작업의 소요 기간

# 간트 차트 (Gantt Chart)

간트 차트는 막대 그림을 이용해 프로젝트를 구성하는 각 작업들의 진행 계획을 한눈에 확인할 수 있는 도표입니다. 

<그림 - 간트 차트>


- 가로축: 시간 (일, 주, 월 단위)
- 세로축: 작업 목록
- 막대: 작업의 시작과 끝을 표현
