# PERT

PERT는 프로그램 평가 및 검토 기술(Program Evaluation and Review Technique)을 의미하며 1950년대 미국 해군이 미사일 개발 프로젝트의 일정을 관리하기 위해 고안했습니다.

이 기법은 3점-추정(낙관적인 경우, 평범한 경우, 비관적인 경우)원칙에 기반해 일정을 계산하는 것으로 주로 불확실성이 높은 프로젝트의 일정 계획에 사용됩니다.

<그림 - PERT>

- 노드 (Node): 작업의 시작과 끝. 
- 화살표 (Arrow): 화살표에는 각 작업의 낙관치, 기대치, 비관치 기간을 표시합니다. 


작업의 낙관치(t0), 기대치(tm), 비관치(tp)를 바탕으로 기대 시간(te)를 계산하는 공식은 다음과 같습니다.
```
[ te = (t0 + 4tm + tp)/6 ]
```

예제) 두 작업 A, B를 차례로 수행하려고 합니다. 두 작업의 낙관치/기대치/비관치가 각각 2/4/12, 3/6/9일 때 전체 기대 시간을 구해보세요.
```
A의 기대 시간 = (2 + (4 * 4) + 12)/6 = 5일
B의 기대 시간 = (3 + (4 * 6) + 9)/6 = 6일

따라서 전체 기대 시간은 5일 + 6일 = 11일 입니다.
```

# CPM

CPM은 임계 경로 기법(Critical Path Method)의 약어로 1950년대 후반 미국의 듀폰사(DuPont)가 화학공장 정비 프로젝트의 일정을 관리하기 위해 개발한 방법입니다. 

이 기법은 임계 경로(Critical Path)를 바탕으로 일정을 관리합니다. 임계 경로는 프로젝트의 시작부터 끝까지 가는 길 중에서 가장 긴 시간이 걸리는 경로를 의미합니다. 임계 경로의 기간이 곧 프로젝트에 필요한 최소 기간을 의미합니다.

PERT가 불확실한 프로젝트를 위한 기법이라면 CPM은 반복적이고 경험이 많은 프로젝트에 주로 사용됩니다.

- 노드: 작업의 시작과 끝
- 화살표: 각 작업의 소요 기간

# 간트 차트 (Gantt Chart)

간트 차트는 1910년대 초 미국의 경영 컨설턴트였던 Henry Gantt(헨리 간트)가 제안한 것으로 막대 그림을 이용해 프로젝트를 구성하는 각 작업들의 진행 계획을 한눈에 확인할 수 있는 시각적 도구입니다.

제1차 세계대전 당시 군수 물자 생산 계획을 효율적으로 관리하기 위해 고안되었으며, 이후 후버 댐 건설 등 거대 프로젝트에 쓰이면서 표준이 되었습니다.

이 차트는 Jira, Noiton 등 현대적 협업 도구에서 디지털화되며 여전히 널리 사용되고 있습니다.

<그림 - 간트 차트>

- 가로축: 시간 (일, 주, 월 단위)
- 세로축: 작업 목록
- 막대: 작업의 시작과 끝을 표현
