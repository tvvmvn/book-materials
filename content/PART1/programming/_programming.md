# 프로그래밍 (Programming) 개념

프로그래밍은 프로그램(Program)을 만드는 과정을 의미합니다. 일반적으로 코드를 작성하는 코딩(Coding)을 통해 구현합니다. 개발자가 작성한 코드가 실제로 실행되기 까지는 다음과 같은 단계를 거칩니다. 

개발자가 C, Python 등의 개발 언어로 소스 코드를 작성합니다. 그 다음 컴파일러(Compiler)가 소스 코드를 컴퓨터가 이해할 수 있는 기계어(Maching Language)로 변환합니다. 컴파일된 이 일련의 기계어를 실행 파일이라고 부르며 이 실행 파일을 실행한 것이 바로 프로그램입니다

프로그래밍 패러다임으로 크게 다음의 두가지가 있습니다.

- 구조적 프로그래밍
- 객체지향 프로그래밍

구조적 프로그래밍은 구조적 방법론을 구현한 프로그래밍 기법으로 함수(프로세스)를 중심으로 코드를 작성합니다. 대표적인 구조적 프로그래밍 언어로 C가 있습니다.

객체 지향 프로그래밍은 객체지향 방법론을 구현한 프로그래밍 기법으로 객체와 클래스를 중심으로 코드를 작성합니다. 대표적인 객체 지향 프로그래밍 언어로 Java, Python 등이 있습니다.
