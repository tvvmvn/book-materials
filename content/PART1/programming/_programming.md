# 프로그래밍 (Programming) 개념

프로그래밍은 프로그램(Program)을 개발하는 것을 의미합니다. 일반적으로 코드를 작성하는 코딩(Coding)을 통해 구현합니다. 개발자가 작성한 코드가 실제로 실행되기 까지는 다음과 같은 단계를 거칩니다. 

개발자가 C, Python 등의 개발 언어로 소스 코드를 작성합니다. 그 다음 컴파일러(Compiler)가 소스 코드를 컴퓨터가 이해할 수 있는 기계어(Maching Language)로 변환합니다. 컴파일된 이 일련의 기계어를 실행 파일이라고 부르며 이 실행 파일을 실행한 것이 바로 프로그램입니다

프로그래밍 패러다임으로 크게 다음의 두가지가 있습니다.

- 절차 지향 프로그래밍: 프로그램을 일련의 절차들이 실행되는 과정으로 보는 관점에 기반한 프로그래밍입니다. 대표적인 절차지향 언어로 C 언어가 있습니다.

- 객체 지향 프로그래밍: 소프트웨어를 객체의 모임으로 보고 각 객체를 만들고 조립하여 소프트웨어를 완성하는 관점인 객체 지향에 기반한 프로그래밍 방법입니다. 대표적인 객체 지향 언어로 Java, Python 등이 있습니다.


# 프로그래밍 설계 도구

구체적인 프로그래밍 설계 도구를 소개합니다.

- 플로우 차트 (Flow Chart)
- NS 차트


플로우차트(Flowchart)는 프로세스나 알고리즘의 단계를 도형과 화살표로 시각화한 도구입니다. 복잡한 논리 구조를 한눈에 파악하고 팀원들과 소통할 때 매우 유용합니다.

- 타원 (시작/종료): 프로세스의 시작과 끝을 나타냅니다
- 직사각형 (처리): 연산, 데이터 할당 등 일반적인 작업을 나타냅니다. 
- 평행사변형 (입/출력): 사용자의 입력이나 시스템의 출력을 의미합니다.
- 마름모 (판단/조건): 참/거짓에 따라 방향이 나뉘는 분기점입니다.
- 화살표 (흐름): 단계의 흐름을 나타냅니다.

<그림 - 플로우 차트>


1973년 아이작 나시와 벤 슈나이더만이 제안한 프로그래밍 설계 도구입니다. 플로우 차트와 다르게 화살표를 사용하지 않고 도형만을 이용해 표현하는 기법입니다. 화살표를 쓰지 않기 때문에 임의의 지점으로 점프하는 GOTO 문을 표현할 수 없고 이는 자연스럽게 구조화된 설계를 유도합니다.

- 순차 구조
- 선택 구조
- 반복 구조
