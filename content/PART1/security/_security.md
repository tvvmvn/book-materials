# 보안

- 보안 요소
- 접근 제어


소프트웨어 개발의 3가지 보안 요소

- 기밀성
- 무결성
- 가용성

기밀성: 시스템 내의 정보와 자원은 인가된 사용자에게만 접근이 허용됩니다. 정보가 전송 중에 노출되더라도 데이터를 읽을 수 없습니다

무결성: 시스템 내의 정보를 오직 인가된 사용자만 수정할 수 있습니다

가용성: 인가받은 사용자는 시스템 내의 정보와 자원을 언제든지 사용할 수 있습니다


# 접근 제어

- 임의 접근 제어
- 강제 접근 제어
- 역할기반 접근 제어

임의 접근 통제는 데이터에 접근하는 사용자의 신원에 따라 접근 권한을 부여하는 방식입니다. 데이터 소유자가 접근 권한을 제어합니다. 

강제 접근 통제는 주체와 객체의 등급을 비교하고 접근 권한을 부여하는 방식입니다. 시스템이 접근 통제 권한을 지정합니다. 데이터베이스 객체별로 보안 등급을 부여할 수 있고 사용자 별로 인가 등급을 부여할 수 있습니다.

역할기반 접근통제는 임의 접근 통제와 강제 접근통제의 단점을 보완한 기법으로 사용자의 역할에 따라 접근 권한을 부여하는 방식입니다. 중앙관리자가 접근 권한을 지정합니다. 다중 프로그래밍 환경에 최적화된 방식입니다.
