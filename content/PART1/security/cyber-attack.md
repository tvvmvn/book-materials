# 멀웨어 (Malware)

Malicious + Software (악성 소프트웨어)  
피해자의 기기에 악성 소프트웨어를 심고 이를 활용하는 공격합니다.

*종류*

- Ransomware
- Spyware
- Backdoor
- Trojan Horse
- Virus
- Worm
- Key Logger Attack


## 랜섬웨어 (Ransomware)

Ransom(몸값) + Software.   
강력한 암호화를 사용하여 데이터 또는 시스템을 인질로 잡는 멀웨어입니다.
기능을 복원하는 대가로 금전을 요구합니다.
IBM의 연구결과에 따르면 전체 사이버 공격 중 17%에 해당하며, 두번째로 흔한 공격입니다.


## 백도어 (Back Door)

시스템 설계자가 서비스 기술자나 유지보수 프로그램 작성자의 접근 편의를 위해
시스템 보안을 제거하여 만들어놓은 `비밀 통로`로, 컴퓨터 범죄에 악용되기도 합니다.

*백도어 탐지 방법*

- 무결성 검사
- 열린 포트 확인
- SetUID 파일 검사 등
- 로그 분석


## 스파이웨어 (Spyware)

사용자의 신상정보, 비밀번호, 신용카드 번호와 같은 민감한 정보를 몰래 수집한 다음 해커에게 전송합니다.


## 웜 (Worm)

네트워크를 통해 연속적으로 자신을 복제하여 시스템의 부하를 높임으로써 결국 시스템을 다운시키는 바이러스의 일종입니다. 분산 서비스 공격, 버퍼 오버플로 공격, 슬래머 등이 웜 공격의 예시입니다.


## 트로이 목마 (Trojan Horse)

정상적인 프로그램으로 위장한 악성 프로그램입니다.


## Key Logger

사용자의 키보드 움직임을 탐지해 ID, 비밀번호 등 개인정보를 뺏어가는 공격입니다.


# 사회 공학 (Social Engineering)

사회 관계에서 피해자를 속여 중요한 정보를 탈취한뒤 악의적인 목적으로 사용합니다

*종류*

- Fishing
- Pharming
- Watering Hole


## Fishing

- 피싱 (Pishing)
- 스미싱 (Smishing)
- 보이스 피싱 (Voice Pishing)
- 큐싱 (Qshing)
- 스피어 피싱 (Spear Phising)

**피싱 (Pishing)** PC + Fishing  
가장 많이 사용되는 소셜 엔지니어링 공격 중 하나입니다. 
공공기관 등을 사칭하여 피해자를 악성 웹사이트로 유도하거나 피해자의 기기에 멀웨어 등을 유포하는 이메일이나 문자 메시지를 전송합니다.

**보이스 피싱** 전화 통화를 악용한 공격

**Smishing** 문자 메시지(SMS)를 악용한 공격

**Qshing** QR코드를 악용한 공격


## Watering Hole

피해자가 자주 방문하는 웹사이트를 사전에 감염시키고 피해자가 웹사이트에 접속했을 때 악성 코드에 감염되게 됩니다.

```
워터링 홀은 사전적으로 동물들이 물을 마시러 모이는 곳을 의미합니다.
피해자들이 모이는 웹사이트를 워터링 홀에 비유한 것이죠
```


# 서비스 거부 공격(DoS, Denial of Service)

시스템 리소스를 `사기 트래픽`으로 가득 채웁니다.
이 사기 트래픽은 시스템을 압도하여 합법적인 요청에 대한 응답을 방해합니다.

- Ping of Death
- Smurfing
- SYN Flooding
- TearDrop
- LAND Attack
- DDos 공격


## Ping of Death

패킷의 크기를 인터넷 프로토콜의 허용 범위 이상으로 전송하여 피해자의 네트워크를 마비시키는 공격입니다. 공격에 사용되는 큰 패킷은 수백개 패킷으로 분할되어 전송됩니다. 피해자는 분할된 대량의 패킷을 수신하게 되고, 대량의 패킷을 재조립해야하는 부담을 가지게 됩니다.


## Smurfing

IP나 ICMP의 특성을 악용하여 대량의 데이터를 한 사이트에 집중적으로 전송함으로써 네트워크를 불능 상태로 만드는 공격입니다. 예방 방법은 각 네트워크 라우터에서 브로드캐스트 주소를 사용할 수 없도록 미리 설정하는 것입니다.


## SYN Flooding

TCP는 신뢰성있는 전송을 위해 3Way Handshake 과정을 거친 후 데이터를 전송합니다. 이 때 공격자가 클라이언트로 위장하고 3Way Handshake 과정을 의도적으로 중단시킴으로써 서버가 대기 상태에 놓여 정상적인 서비스를 수행하지 못하게 하는 공격입니다.


## LAND(LAN Denial) 공격

패킷을 전송할 때 패킷의 송신 IP주소와 수신 IP주소를 모두 피해자의 IP주소로 설정합니다.
이 패킷을 받은 피해자는 송신 IP주소가 자신이므로 자신에게 응답을 수행하게 됩니다.
이러한 패킷을 계속 전송해서 피해자가 자신에 대해 무한히 응답하게 만드는 공격입니다.


## DDoS (Distributed Denial of Service)

여러곳에 분산된 공격 지점에서 한 서버에 대해 서비스 공격을 수행합니다.
네트워크에서 취약점이 있는 호스트들을 탐색한 후 이 호스트들에 분산 서비스 공격용 툴을 설치하여 에이전트로 만든 후 DDoS 공격에 이용합니다.


# 중간자 공격 (MITM: Man In The Middle)  

`도청 공격`이라고도 불립니다. 해커가 두 사람 간 또는 사용자와 서버 간의 통신을 가로챕니다. 일반적으로 해커가 보안되지 않은 공공 와이파이 네트워크를 활용하여 공격합니다.

*종류*

- 세션 하이재킹 (Session Hijacking)
- Sniffing
- 공급망 공격


## Session Hijacking

클라이언트가 정상적인 인증 과정을 거치면 서버와 클라이언트 사이의 `세션(연결 상태)`이 만들어집니다. 공격자가 이 세션을 가로채는 공격을 의마합니다.
접속을 위한 인증 과정이 없이도 가로챈 세션을 이용해 정상적인 클라이언트로 위장하여 서버의 자원을 무단으로 사용합니다.


## Sniffing

킁킁(Sniffing) 공격. 네트워크의 중간에서 남의 패킷정보를 도청하는 수동적 공격입니다.


## 공급망 공격

해커가 기업과 거래하는 소프트웨어/자재/서비스 등의 공급 업체를 해킹하여 기업에 침투합니다.

*사례 1*

2020년에 러시아 국가 활동 세력이 소프트웨어 공급업체인 SolarWinds를 해킹한 후 소프트웨어 업데이트를 가장하여 고객에게 맬웨어를 배포했습니다.. 이 맬웨어를 통해 러시아 스파이들이 재무부, 법무부, 국무부 등 SolarWinds의 서비스를 사용하는 다양한 미국 정부 기관의 민감한 데이터에 액세스할 수 있었습니다.


# 기타 공격

- XSS
- SQL Injection
- DNS Tunneling
- Zero day

## XSS (Cross Site Scripting)

웹페이지 또는 웹애플리케이션에 악성 코드를 삽입합니다. 일반적으로 JavaScript.  
사용자가 사이트에 방문하면 코드가 사용자의 웹브라우저에서 실행됩니다.
이를 통해 민감한 정보를 훔치거나 악성 웹사이트로 사용자를 이동시킵니다.


## SQL 주입 (SQL Injection)

데이터베이스에 악성 명령을 삽입하여 데이터를 빼거나 데이터를 왜곡시킵니다.
해커는 검색폼이나 로그인폼을 활용해 데이터베이스에 삽입할 명령을 입력합니다.


## 제로데이 공격 (Zero Day Attack)

보안 커뮤니티에 알려지지 않았거나 알려졌지만 아직 해결 방법이 발견되지 않은
취약점(제로 데이)를 공격합니다.


## Spoofing

속이기(Spoofing)

- DNS Spoofing
- ARP Spoofing


### DNS Spoofing

DNS 서버의 레코드를 몰래 편집하여 웹사이트의 IP주소를 조작합니다.
피해자는 `가짜 사이트`에 접속하게 됩니다.

**DNS 서버** 문자형식의 URL을 IP 주소로 변환하는 서버

![dns-spoofing](../img/dns-spoofing.jpg)


### ARP Spoofing

ARP의 취약함을 이용한 공격 기법입니다. 공격자의 물리적 주소(MAC)를 피해자의 것으로 변조하여 피해자에게 도달해야 하는 데이터 패킷을 가로채는 공격입니다.

**ARP(Address Resolution Protocol)** 호스트의 IP주소를 호스트와 연결된 네트워크 접속 장치의 물리적 주소(MAC Address)로 변환시키는 프로토콜


# Bug / 이상 / 보안 약점

- Memory Buffer Overflow
- TOCTOU
- 하드코딩된 암호화 키
- 널포인터 역참조


### Memory Buffer Overflow

정보가 다른 장치로 전송될 때 일시적으로 데이터를 기억하는 중간 장치를 메모리 버퍼(Memory Buffer)라고 합니다.

연속된 메모리 공간을 사용하는 프로그램에서 할당된 버퍼의 범위를 넘어선 위치에서 자료를 읽거나 쓰려고 할 때 발생하는 보안 약점입니다.

메모리 버퍼를 사용할 경우 적절한 버퍼의 크기를 설정하고, 설정된 범위의 메모리 내에서 읽거나 쓰도록 함으로써 방지할 수 있다


### TOC TOU  

검사 시점(Time Of Check)과 사용 시점(Time Of Use)을 고려하지 않고 코딩하는 경우 발생하는 보안 약점입니다.

```
프로세스A가 자원X를 사용하기 위해 검사한 결과, X는 사용가능한 자원임을 확인했습니다. 이제 자원X를 사용하기 위해 X를 요청하였더더니 그 사이에 프로세스 B가 A보다 먼저 자원X에 대한 사용 요청을 내고 사용해버림으로써 A는 X를 사용할 수 없는 상황이 발생합니다.
```


### 널포인터 역참조

널포인터가 가리키는 메모리의 위치에 값을 저장할 때 발생한는 보안 약점입니다.
포인터를 이용하기 전에 NULL 널값을 갖고 있는지 검사함으로써 방지할 수 있습니다.
널포인터 역참조로 오류가 발생하는 경우 "메모리 0x00000000을 참조했습니다" 라는 오류메시지가 발생합니다.

**스택가드(Stack Guard)**  널포인터 역참조와 같이 주소가 저장되는 `스택`에서 발생하는 보안 약점을 막는 기술입니다. 메모리상에서 프로그램의 복귀 주소와 변수 사이에 특정 값을 저장한 후 그 값이 변경되었을 경우 Overflow 상태로 판단하여 프로그램 실행을 중단함으로써 잘못된 복귀 주소의 호출을 막습니다.

```
함수의 실행이 끝나면 자신을 호출한 함수로 되돌아가야합니다. 이때 스택은 복귀할 주소를 기억하는데 사용됩니다.
함수는 호출된 순서의 역순으로 되돌아가야 하기 때문입니다.
```
