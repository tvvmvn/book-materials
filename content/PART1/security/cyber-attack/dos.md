# 서비스 거부 공격(DoS, Denial of Service)

피해자에게 다수의 사기 요청을 전송해 피해자가 정상적인 서비스를 할 수 없도록 만드는 공격입니다.

- Ping of Death
- Smurfing
- SYN Flooding
- LAND Attack
- DDos 공격


# Ping of Death

죽음의 핑(Ping of Death)은 시스템이 감당할 수 없는 거대한 패킷을 보내 피해자의 시스템을 다운시키는 공격입니다. 공격에 사용되는 거대한 패킷은 전송을 위해 수많은 패킷으로 분할됩니다.

분할된 대량의 패킷을 수신한 피해자가 패킷을 재조립하는 과정에서 시스템에 문제가 발생하게 됩니다.


# Smurfing

대량의 ICMP 패킷을 피해자에게 집중적으로 전송시켜 피해자를 다운시키는 공격입니다. 
다음은 스머핑의 과정입니다.

1. 공격자가 피해자가 속한 네트워크를 알아냅니다.
2. 전송할 ICMP 패킷의 출발지를 피해자의 IP 주소로 속입니다.
3. 패킷을 피해자가 속한 네트워크의 브로드캐스트 주소로 전송합니다.
4. 패킷은 네트워크의 모든 호스트에게 전달됩니다(브로드캐스팅).
5. 호스트들의 응답이 피해자 IP주소에 집중적으로 보내집니다.
6. 피해자의 시스템이 마비됩니다.

외부에서 들어오는 브로드캐스트 패킷을 차단하거나 내부 IP주소가 외부에서 들어오는 경우 차단하는 등의 예방 방법이 있습니다.


# SYN Flooding

TCP 연결 과정에서 공격자가 서버를 속여서 서버가 정상적인 서비스를 수행하지 못하게만드는 공격입니다.

TCP 프로토콜은 데이터를 전송하기 전에 클라이언트와 3-Way Handshake 과정을 통해 연결을 설정합니다. 공격자는 이 과정에서 서버의 연결 요청을 무시해버립니다. 결국 서버는 클라이언트의 응답을 무한정 기다리게 되고 서비스를 수행할 수 없는 상태에 빠집니다.


# LAND(LAN Denial) 공격

공격자가 패킷의 송/수신 IP 주소를 모두 피해자의 IP주소로 설정한 패킷을 피해자에게 전송합니다.

이 패킷을 받은 피해자는 송/수신 IP주소가 자신이므로 시스템이 다운될 때까지 자신에게 무한히 요청을 전송하게 됩니다.


# DDoS (Distributed Denial of Service)

여러 분산된 공격 지점에서 한 서버를 집중적으로 공격합니다. 한 지점에서 사기 요청을 전송하는 DoS보다 훨씬 위협적인 공격 방법입니다.

1. 공격자가 네트워크 상에서 취약점이 있는 호스트들을 탐색합니다.
2. 이 호스트들을 악성 코드에 감염시켜 좀비 PC로 만듭니다.
3. 좀비 PC들이 피해자에게 집중적으로 사기 요청을 전송해 서버를 다운시킵니다.
