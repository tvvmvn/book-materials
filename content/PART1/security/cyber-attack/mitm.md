# 중간자 공격 (MITM: Man In The Middle)  

공격자가 사용자 사이 또는 사용자와 서버 간의 통신에 불법적으로 개입하는 것에 바탕을 둔 공격입니다.

- 세션 하이재킹 (Session Hijacking)
- ARP Spoofing
- DNS Spoofing
- Sniffing


# 세션 하이재킹 (Session Hijacking)

하이재킹(Hijacking)은 우리말로 '납치, 강탈'을 뜻합니다.

클라이언트가 인증 과정(로그인 등)에 성공하면 서버와 클라이언트 사이에 세션(연결)이 만들어집니다. 세션 하이재킹은 공격자가 이 세션(연결)을 가로채서 클라이언트로 위장하고 서버의 자원을 무단으로 사용하는 공격입니다.

어떤 정보를 훔쳐 세션을 가로채는지에 따라 두가지 유형이 있습니다.

- TCP 세션 하이재킹: TCP 통신에서 클라이언트와 서버 사이에 형성된 시퀀스 번호(Sequence Number)를 훔칩니다.

- 웹 세션 하이재킹: 클라이언트와 서버 사이의 형성된 세션 ID를 훔칩니다.


# ARP Spoofing

ARP의 취약점을 이용해 패킷을 가로채는 공격입니다.

외부에서 온 패킷은 IP 주소를 따라 내가 있는 네트워크에 도달합니다.
네트워크에서 이제 나를 찾기 위해서는 물리적 주소(MAC 주소)가 필요합니다.
이때 IP 주소를 보고 올바른 물리적 주소를 찾아주는 프로토콜이 ARP입니다.

1. 공격자가 자신의 MAC 주소를 피해자의 MAC 주소로 변조합니다.
2. ARP 프로토콜은 패킷의 IP 주소를 보고 조작된 공격자의 물리적 주소를 나의 물리적 주소라고 착각합니다.
3. 공격자에게 나의 패킷이 도착하게 됩니다.


# DNS Spoofing

DNS의 취약점을 이용한 공격 기법입니다. 사용자가 입력한 도메인 네임을 잘못된 IP 주소로 변환시켜 악성 사이트로 이동시킵니다.


# Sniffing

Sniffing은 우리말로 '(코를) 킁킁거리다'라는 뜻으로 통신 과정에서 남의 패킷 정보를 도청하는 수동적 공격입니다.
