# 보안 솔루션

- 방화벽 (Firewall)
- IDS / IPS
- VPN
- SSH
- SIEM
- 템퍼 프루핑


# 방화벽 

방화벽은 인터넷을 통해 외부에서 들어오는 무분별한 정보들을 선별하여 내부 네트워크를 보호하는 성벽입니다.


# 웹 방화벽

XSS 공격, SQL 주입 등 웹 기반 공격에 대한 방어에 특화된 방화벽입니다.


# IDS/IPS

IDS는 침입 탐지 시스템(Intrusion Detection System)입니다.
건물의 CCTV처럼 침입을 감시하고 탐지하는 시스템입니다. 다음 두 종류의 탐지 기법이 있습니다.

- 이상 탐지(Anomaly Detection): 비정상적인 상황이 감지되면 경보를 울립니다.

- 오용 탐지(Misuse Detection): 알려진 공격 패턴이 감지되면 경보를 울립니다. 

IPS는 침입 방지 시스템(Intrusion Prevention System)입니다. IDS에 '차단' 기능이 추가된 시스템으로 침입이 파악되면 능동적으로 차단합니다.


# VPN

VPN은 가상 사설망(Virtual Private Network)을 의미합니다.
개방된 인터넷 환경에서 사용자의 연결을 보호하는 기술로 마치 자신의 전용 회선을 구축한 것과 같은 효과를 볼 수 있습니다. VPN을 통해 더 안전한 환경에서 인터넷을 사용할 수 있습니다.


# SSH 

SSH는 보안 셸(Secure Shell)을 의미합니다.
SSH는 원격 컴퓨터에 안전한 접속 기능을 제공하는 프로토콜입니다.

개인키 암호화 방식을 사용합니다.
공개키가 자물쇠라면 개인키는 열쇠입니다.

접속용 포트(port)는 22번이 기본값이고 보안을 위해 바꾸기도 합니다.


# SIEM

SIEM은 보안 정보 및 이벤트 관리(Security Information and Event Management)를 의미합니다.

SIEM은 IDS/IPS, 웹 방화벽, VPN 등 다양한 보안 시스템의 로그(Log) 및 이벤트 내용을 통합하고 분석하는 빅데이터 기반의 보안 솔루션입니다. 


# Tamper Proofing

템퍼 프루핑은 소프트웨어를 위/변조(Tamper) 하기 힘든 환경을 만들고 만약 위/변조 되었다면 프로그램을 종료시켜 소프트웨어를 보호하는 기술입니다.

템퍼 프루핑을 구현하는 방법은 코드 난독화, 무결성 검사, 안티 디버깅 등이 있습니다.
