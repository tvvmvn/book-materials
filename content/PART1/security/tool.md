# 보안 도구

- 방화벽
- IDS
- IPS
- VPN
- SIEM
- 템퍼 프루핑
- OAuth

방화벽은 기업이나 조직 내부의 네트워크와 인터넷 간의 전송되는 정보를 선별하고 수용/거부/수정 하는 기능을 가진 `침입 차단 시스템`입니다. 내부 네트워크에서 외부로 나가는 패킷은 그대로 통과시키고 외부에서 내부 네트워크로 들어오는 패킷은 검사하고 인증된 패킷만 통과시킵니다

침임 탐지 시스템은 컴퓨터 시스템의 비정상적인 사용, 남용 등을 실시간으로 탐지하는 시스템입니다.

침입 방지 시스템은 비정상적인 트래픽을 능동적으로 차단하고 격리하는 등의 방어 조치를 취하는 보안 솔루션입니다. 침임 방지 시스템은 방화벽과 침임 탐지 시스템을 결합한 것입니다. 침임 탐지 기능으로 패킷을 검사하고 비정상적인 패킷이 감지되면 방화벽 기능으로 패킷을 차단합니다.

VPN은 인터넷 등 통신 사업자의 공중 네트워크와 암호화 기술을 활용하여 사용자가 마치 자신의 전용 회선을 사용하는 것처럼 해주는 보안 솔루션입니다. 전용선을 구축할 필요가 없으므로 비용 부담을 줄일 수 있다.

SIEM은 다양한 장비에서 발생하는 로그 및 보안 이벤트를 통합하여 관리하는 빅데이터 기반의 보안 솔루션입니다. 방화벽, IDS, IPS, 웹 방화벽, VPN 등에서 발생한 로그와 보안 이벤트를 통합하여 관리함으로써 비용과 자원을 절약할 수 있습니다. 

템퍼 프루핑은 소푸트웨어의 위/변조가 발생할 경우 소프트웨어를 오작동하게 만들어 악용을 방지하는 기술입니다. 템퍼 프루핑은 해시 함수, 핑거 프린트, 워터 마킹 등의 보안 요소를 생성해 소프트웨어에 삽입하고 실행코드를 난독화하며 실행 시 원본 비교 및 데이터 확인을 수행함으로써 소프트웨어를 보호합니다.

OAuth는 웹 애플리케이션에서 사용자 인증에 사용되는 공개 API입니다. 사용자가 애플리케이션에 비밀번호를 제공하지 않고 접근 권한을 가질 수 있습니다.
