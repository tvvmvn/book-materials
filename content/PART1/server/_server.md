# 서버 개발 과정 

- DTO/VO 
- SQL
- DAO
- Service
- Controller

*그림 - 서버의 구조*

DTO/VO: 데이터 교환을 위해 사용되는 객체입니다

DAO: 데이터베이스에 접근하고 SQL을 활용하여 데이터베이스를 제어합니다

Service: 서버의 로직을 담당하는 부분입니다

Controller: 사용자의 요청에 적합한 서비스를 호출하고 결과를 반환하는 객체입니다.
