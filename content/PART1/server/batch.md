# 배치 프로그램 (Batch Program)

배치 프로그램은 사용자와의 상호작용 없이 정해진 주기마다 대용량의 작업을 자동으로 처리하는 프로그램입니다.

데이터베이스 백업, 정기 메시지, 고지서 발송 등의 정기적이고 반복적인 업무에 주로 활용됩니다.


다음은 배치 프로그램의 5가지 필수 요소입니다.

- 대용량 데이터: 대량의 데이터를 처리할 수 있어야 합니다.

- 자동화: 심각한 오류가 발생하는 상황을 제외하고 사용자의 개입 없이 수행되어야 합니다.

- 견고함: 여러가지 예외 상황이 발생해도 중단되지 않아야 합니다

- 안전성/신뢰성: 오류가 발생할 경우 어디서 언제 발생했는지 추적할 수 있어야 합니다.

- 성능: 지정된 시간 내에 맡은 업무를 처리해야합니다.
