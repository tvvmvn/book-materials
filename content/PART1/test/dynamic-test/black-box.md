# 블랙박스 테스트

소프트웨어의 각 기능이 완전히 작동되는 것을 입증하는 테스트로 기능 테스트라고도 불립니다. 사용자의 요구사항을 명세를 보면서 테스트합니다

주요 블랙박스 테스트 기법들

- 동치 분할 (Equivalence Partioning)
- 경계값 분석 (Boundary Value Analysis)
- 원인-효과 그래프 (Cause-Effect Graph)
- 오류 예측 (Error Guessing)
- 비교 (Comparison)


## 동치 분할

프로그램의 입력 조건으로 타당한 입력 자료와 타당하지 않은 입력 자료의 개수를 균등하게 설정합니다. 동치 클래스 분해라고도 불립니다.

*예제 - 동치분할 테스트케이스*


## 경계값 분석

입력 조건의 중간값보다 경계값에서 오류가 발생될 확률이 높다는 점을 이용한 테스트로 경계값을 이용해 프로그램을 테스트합니다.

*예제 - 경계값 분석 테스트케이스*
