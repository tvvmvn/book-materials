# 화이트박스 테스트

'화이트박스'라는 이름처럼 투명하게 모듈의 원시 코드를 오픈시킨 상태에서 테스트하는 기법입니다

- 기초 경로 검사
- 조건 검사
- 루프 검사
- 데이터 흐름 검사

기초 경로 검사: 프로그램의 논리적인 복잡도을 측정하는 테스트로 실행 가능한 모든 경로를 최소 한번 이상 테스트합니다. 대표적인 화이트박스 테스트 기법입니다

조건 검사: 프로그램에 있는 논리적 조건을 테스트합니다. 

루프 검사: 프로그램의 반복 구조를 테스트합니다

데이터 흐름 검사: 프로그램에서 변수의 생성과 소멸, 변수가 사용되는 위치 등을 테스트 합니다.


## 테스트 커버리지

- 문장 커버리지
- 분기 커버리지
- 조건 커버리지
- 분기/조건 커버리지

문장 커버리지: 소스 코드의 모든 구문이 한번 이상 수행되도록 테스트케이스를 설계합니다.

분기 커버리지: 소스코드의 모든 조건문에 대해 조건식의 결과가 참/거짓인 경우가 한번 이상 수행되도록 테스트케이스를 설계합니다. 결정 커버리지라고도 합니다.

조건 커버리지: 소스 코드의 조건문에 포함된 개별 조건식의 결과가 참/거짓인 경우가 한 번 이상 수행되도록 테스트케이스를 설계합니다.

분기/조건 커버리지: 분기 커버리지와 조건 커버리지를 모두 만족하는 설계로, 조건문이 참/거짓인 경우에 따라 조건 커버리지의 입력 데이터를 구분하는 테스트케이스를 설계합니다.
