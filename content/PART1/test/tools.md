소프트웨어 테스트 도구는 테스트 단계(단위, 통합, 시스템)와 테스트 목적(기능, 성능, 보안)에 따라 매우 다양합니다. 효율적인 테스트를 위해서는 프로젝트의 규모와 기술 스택에 맞는 도구를 선택하는 것이 중요합니다.

주요 테스트 도구들을 용도별로 분류하여 정리해 드립니다.


## 테스트 관리 및 정적 분석 도구

테스트 케이스를 관리하거나, 코드를 실행하지 않고 품질을 체크하는 도구입니다.

- SonarQube: 코드의 중복, 취약점, 버그 소지를 자동으로 분석해주는 정적 분석 도구입니다.
- Jira / TestRail: 테스트 케이스의 진행 상태, 결함(Bug) 추적 등을 관리하는 협업 도구입니다.


## 유닛 테스트(Unit Test) 및 프레임워크

개발자가 작성한 코드의 가장 작은 단위(함수, 메서드)를 검증하는 도구입니다.

- JUnit (Java): 자바 환경의 표준 테스트 프레임워크입니다.
- PyTest / Unittest (Python): 파이썬에서 가장 널리 쓰이는 간결한 테스트 도구입니다.
- Jest (JavaScript/TS): React 등 프론트엔드 및 Node.js 환경에서 강력한 기능을 제공합니다.
- Mockito: 테스트 시 가짜 객체(Mock)를 만들어 의존성을 분리해주는 보조 라이브러리입니다.


## 웹 자동화 및 UI 테스트 (블랙박스 테스트)

브라우저를 직접 띄워 사용자의 동작(클릭, 입력)을 흉내 내는 도구입니다.

- Selenium (셀레늄): 가장 오래되고 강력한 웹 자동화 도구로, 여러 언어와 브라우저를 지원합니다.
- Playwright: Microsoft에서 개발한 최신 도구로, 속도가 매우 빠르고 현대적인 웹 환경에 최적화되어 있습니다.
- Cypress: 프론트엔드 개발자가 선호하는 도구로, 브라우저 내부에서 실행되어 디버깅이 매우 쉽습니다.
- Appium: iOS, Android 등 모바일 애플리케이션 테스트를 위한 표준 자동화 도구입니다.


## 성능 및 부하 테스트 (Performance Test)

서버가 얼마나 많은 동시 접속자를 견딜 수 있는지 측정하는 도구입니다.

- Apache JMeter: 자바 기반의 전통적인 강자로, 다양한 프로토콜(HTTP, DB, FTP) 테스트가 가능합니다.
- nGrinder: 네이버에서 개발한 도구로, 대규모 부하를 생성하고 GUI를 통해 결과를 실시간 모니터링하기 좋습니다.
- Locust: 파이썬 코드로 테스트 시나리오를 작성하며, 분산 부하 테스트에 강점이 있습니다.
- K6: JavaScript 기반의 가벼운 도구로, CI/CD 파이프라인(DevOps) 연동이 매우 쉽습니다.


## API 및 인터페이스 테스트

백엔드 서버의 API 엔드포인트가 정확한 데이터를 주고받는지 검증합니다.

- Postman: API 설계, 개발, 테스트를 위한 가장 대중적인 GUI 도구입니다.
- Rest-Assured: 자바 코드로 REST API를 쉽고 직관적으로 테스트할 수 있는 라이브러리입니다.
