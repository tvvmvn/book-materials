# 결함 (Fault)

결함은 오류 발생, 작동 실패 등과 같이 소프트웨어가 개발자가 설계한 것과 다르게 동작하거나 다른 결과가 발생되는 것을 의미합니다.


# 결함 상태 추적

테스트에서 발견된 결함은 지속적으로 상태 변화를 추적하고 관리해야 합니다. 발견된 결함에 대해 결함 관리 측정 지표를 분석하여 향후 결함이 발견될 모듈/컴포넌트를 추정할 수 있습니다. 다음은 결함 관리의 측정 지표입니다.

- 결함 분포 : 모듈/컴포넌트의 특정 속성에 해당하는 결함의 개수
- 결함 추세 : 테스트 진행 시간에 따른 결함 수의 추이
- 결함 에이징 : 특정 결함 상태로 지속되는 시간


# 결함 분류

- 시스템 결함 : 애플리케이션 환경이나 데이터베이스 처리에서 발생된 결함
- 기능 결함 : 애플리케이션의 기획, 설계, 업무 시나리오 등의 단계에서 유입된 결함
- GUI 결함 : 사용자 화면 설계 과정에서 발생된 결함
- 문서 결함 : 기획자, 사용자, 개발자 간의 의사소통 및 기록이 원활하지 않아 발생된 결함
