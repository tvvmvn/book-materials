# V 모델

폭포수 모형의 확장 모델로 소프트웨어의 개발 과정에 각 과정에 필요한 테스트를 연결하여 단계별로 수행해야할 테스트를 한눈에 확인할 수 있는 모형입니다.

*그림 - V모델*

- 단위 테스트 (Unit Test)
- 통합 테스트 (Integration Test)
- 시스템 테스트 (System Test)
- 인수 테스트 (Acceptance Test)


# 단위 테스트

코딩 직후 가장 먼저 실시하는 테스트로 소프트웨어의 최소 단위인 모듈/컴포넌트를 대상으로 실시하는 테스트입니다.


# 통합 테스트

단위 테스트가 완료된 모듈들의 통합 과정을 대상으로 실시하는 테스트입니다

- 비점진적 통합 테스트: 모듈들을 단계적으로 통합하고 테스트하는 과정없이 완성된 프로그램을 대상으로 한번 테스트하는 방식입니다. 대표적으로 빅뱅 테스트가 있습니다

- 점진적 통합 테스트: 모듈들을 단계적으로 통합하고 테스트합니다. 상향식/하향식 통합 테스트와 혼합식 통합 테스트가 있습니다.

하향식 통합 테스트(Top-Down)는 상위 모듈에서 하위 모듈 방향으로 통합하고 테스트를 하는 기법입니다. 상위 모듈(제어 모듈)은 실제 모듈을 사용하고 상위 모듈에 의해 제어되는 하위 모듈(종속 모듈)은 아직 존재하지 않으므로 임시 모듈인 스텁(Stub)을 사용합니다. 테스트가 완료 후 스텁은 실제 모듈로 교체됩니다.

상향식 통합 테스트(Bottom-Up)는 하위 모듈에서 상위 모듈 방향으로 통합하고 테스트하는 기법입니다. 여러 하위 모듈을 그룹화한 클러스터(Cluster)를 대상으로 테스트를 실시합니다. 임시 모듈(Dummy)인 테스트 드라이버(Test Driver)가 하위 모듈 호출, 파라미터 전달, 결과 도출 등의 작업을 수행합니다. 테스트가 완료되면 드라이버는 실제 모듈로 교체됩니다.


# 시스템 테스트

개발된 소프트웨어가 적용 및 사용될 시스템 환경에서 정상적으로 작동하는지 검증하는 테스트입니다. 


# 인수 테스트

개발된 소프트웨어가 사용자의 요구사항을 충족하고 있는지 검증하는 테스트이며 사용자가 직접 테스트합니다. 테스트 환경에 따라 다음의 두가지로 분류됩니다

- 알파 테스트(Alpha Test)
- 베타 테스트(Beta Test)

알파 테스트는 개발자의 장소에서 사용자가 개발자 앞에서 실시하는 테스트입니다. 오류나 문제점을 사용자와 개발자가 함께 확인합니다.

베타 테스트(Beta Test)는 사용자의 환경에서 개발자 없이 진행되는 테스트로 선정된 사용자가 여러 명의 사용자 앞에서 실제 업무를 가지고 행하는 테스트입니다. 필드 테스트라고도 불립니다.
