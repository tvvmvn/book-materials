# UI

UI: 사용자와 시스템 간의 상호작용이 원활하게 이루어지도록 도와주는 장치나 소프트웨어를 의미합니다

UX: 사용자가 시스템이나 서비스를 이용하면서 느끼고 생각하게 되는 총제적인 경험을 의미합니다. 

# UI의 구분

- CLI: 명령과 출력이 텍스트 형태로 이루어지는 인터페이스입니다.
- GUI: 아이콘이나 메뉴를 마우스로 선택하여 작업을 수행하는 그래픽 환경의 인터페이스입니다
- NUI: 키보드, 마우스 등 별도의 장치 없이 사용자의 자연스러운 움직임으로 기기를 조작하는 인터페이스입니다.


# UI의 기본 원칙

- 직관성: 누구나 쉽게 이해하고 사용할 수 있어야 한다
- 유효성: 사용자의 목적을 정확하고 완벽하게 달성해야 한다
- 학습성: 누구나 쉽게 배우고 익힐 수 있어야 한다
- 유연성: 사용자의 요구사항을 최대한 수용하고 실수를 최소화해야 한다


# UI 설계 도구

- 와이어 프레임
- 목업
- 스토리보드
- 프로토타입

와이어 프레임은 페이지에 대한 개략적인 레이아웃이나 UI 요소 등에 대해 뼈대를 설계하는 도구입니다. 기획 단계의 초기에 제작합니다. 손그림, 파워포인트, 키노트, 스케치, 일러스트 등의 도구가 있습니다.

목업은 와이어프레임보다 좀 더 실제화면과 유사하게 만든 정적인 형태의 모형입니다. 디자인, 사용방법 설명, 평가 등을 위해서 만듭니다. 시각적으로만 보기위한 것으로 실제 구현되지는 않습니다. 파워 목업, 발사믹 목업 등의 도구가 있습니다.

스토리 보드는 와이어프레임에 콘텐츠에 대한 설명, 페이지 간 이동 흐름 등을 추가한 문서입니다. 디자이너와 개발자가 최종적으로 참고하는 작업 지침서입니다. 파워포인트, 키노트 스케치, Axure 등의 도구가 있습니다.

프로토타입은 와이어프레임이나 스토리 보드에 상호 작용을 추가해서 테스트가 가능한 동적인 형태의 모형입니다. 사용자의 요구사항을 개발자가 제대로 해석했는지 검증하기 위한 것입니다. 스케치, 그림, 글 등 아날로그 형식의 페이퍼 프로토타입과 파워포인트, 아크로뱃, 비지오 등과 같이 프로그램을 사용하는 디지털 프로토타입이 있습니다.
