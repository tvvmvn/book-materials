# 2차원 배열

2차원 배열은 테이블 형식으로 데이터를 저장하고 다루고 싶을 때 유용합니다. 2차원 배열은 표로 그리면 더욱 이해하기 좋습니다

2차원 배열 문법
```
자료형 변수이름[행의 개수][열의 개수] = { {1행}, {2행}, .. }
```


다음은 2행 3열 형식의 테이블을 저장한 2차원 배열입니다.

```c
int matrix[2][3] = { {1, 4, 2}, {3, 6, 8} };
```

아래는 위의 2차원 배열을 표로 나타낸 그림입니다.

*그림 - 2차원 배열을 표로 나타낸 그림*


# 요소에 접근하기

2차원 배열에 접근하기 위해서는 두개의 인덱스가 필요합니다. 첫번째 인덱스는 행, 두번째 인덱스는 열을 가리킵니다. 인덱스는 0부터 시작하는 것에 주의하세요

```c
int matrix[2][3] = {{1, 4, 2}, {3, 6, 8}};

printf("%d", matrix[0][1]);  // 4
printf("%d", matrix[1][0]);  // 3
```


# 요소 바꾸기

다음은 2차원 배열의 요소를 바꾸는 코드입니다

```c
int matrix[2][3] = { {1, 4, 2}, {3, 6, 8} };

matrix[0][0] = 9;

printf("%d", matrix[0][0]);  // 9
```
