# 시작하기

main 함수 안에 실행할 코드를 작성합니다

```c
int main() {
  //  여기에 코드 작성

  return 0;
}
```


# 출력

printf 함수에 출력할 값을 전달합니다.


```c
int main() {
  printf("Hello World!");

  return 0;
}
// Hello World!
```


# 주석

코드를 작성할 때 메모가 필요한 경우 주석을 사용합니다. 주석은 프로그램에 포함되지 않습니다. 슬래시 두개(//)로 주석을 만들 수 있습니다.

```c
int main() {
  // 메모..
}
```
