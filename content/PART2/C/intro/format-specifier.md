# basic format specifiers

There are different format specifiers for each data type. Here are some of them:

1. %d or %i
2. %f or %F
3. %lf
4. %c


## %d or %i (digit or integer)
int 

## %f or %F (float)
float 

## %lf (long float)
double 

## %c (character)
char 

## %s (string)
Used for strings (text), which you will learn more about in a later chapter
