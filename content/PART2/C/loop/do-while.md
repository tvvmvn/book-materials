# do while 문

반복 조건과 상관없이 최소 한번은 코드를 실행해야 하는 경우에 유용합니다.

```
do {
  반복 실행할 코드
} while (조건);
```

다음은 사용자가 0보다 큰 수를 고를 때까지 계속 요청하는 코드입니다. 

만약 일반 while문으로 작성한다면 input의 초기값이 조건을 만족하지 않으므로 바로 프로그램이 종료되어버립니다.

```c
int input; // 1

do {
  printf("0 보다 큰 수 아무거나 하나 골라보세요");

  scanf("%d", &input);
} while (input <= 0);
```
