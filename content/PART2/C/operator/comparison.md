# 비교 연산자

두 값을 비교하는 연산을 수행합니다. 불리언 타입의 값을 반환합니다

비교연산자 내에서 우선순위입니다.

1. <, <=, >, >=
2. ==, !=


1. == (동등 연산자)
두 값이 같은지 비교합니다.
예) 1 == 2 // false

2. != (비동등 연산자)
두 값이 다른지 비교합니다
예) 1 != 2 // true

3. > (gt 연산자)
숫자의 크기를 비교합니다. 
예) 1 > 2 // false

4. < (lt 연산자)
숫자의 크기를 비교합니다.
예) 1 < 2 // true

5. >= (gte 연산자)
크거나 작다. 
예) 1 >= 2 // false

6. <= (lte 연산자)
작거나 같다. 
예) 1 <= 2 // true
