# 논리 연산자

논리 연산을 수행합니다. 불리언 타입의 값을 반환합니다.

1. && (and): 앞과 뒤가 모두 맞으면 참, 하나라도 다르면 거짓을 반환합니다.

2. || (or): 앞과 뒤 중에서 하나라도 맞으면 참, 둘 다 틀리면 거짓을 반환합니다

3. ! (not): 참과 거짓을 뒤집습니다.


```c
#include <stdio.h>

int main() {

  printf("%d\n", 1 > 0 && 1 < 2); // 1
  printf("%d\n", 1 > 0 || 1 > 2); // 1
  printf("%d\n", !(1 > 0)); // 0
}
```
