# if 문

- if
- if / else
- else if


# if 

조건이 참인 경우 코드를 실행합니다. 조건이 거짓인 경우 무시합니다.

```
if (조건) {
  조건이 참인 경우 실행할 코드
}
```

다음은 나이가 18세 이상이면 '성인입니다'를 출력하는 코드입니다

```c
int age = 20;

if (age >= 18) {
  printf("성인입니다");
}
```


# if / else

조건이 참이면 if 코드를 실행하고 조건이 거짓이면 else 코드를 실행합니다

```
if (조건) {
  조건이 참인 경우 실행할 코드
} else {
  조건이 거짓인 경우 실행할 코드
}
```

다음은 나이에 따라 성인인지 아닌지를 판별하는 코드입니다.

```c
int age = 20;

if (age >= 18) {
  printf("성인입니다");
} else {
  printf("성인이 아닙니다");
}
```


# else if

else if는 if와 함께 쓰여야 하며 개수 제한 없이 조건을 추가할 수 있습니다. 여러 개의 조건이 참인 경우 가장 먼저 참이였던 else if 코드만 실행됩니다.

마지막에 else는 선택 사항입니다. 이 경우 앞의 모든 조건이 거짓이면 else 코드가 실행됩니다. 

```
if (조건1) {
  조건1이 참인 경우 실행할 코드
} else if (조건2) {
  조건2이 참인 경우 실행할 코드
} else if (조건3) {
  조건3이 참인 경우 실행할 코드
} 
...
else if (조건n) {
  조건n이 참인 경우 실행할 코드
} else {
  모든 조건이 거짓인 경우 (옵션)
}
```

다음은 나이에 따라 세대를 구분하는 코드입니다.

```c
int age = 20;

if (age < 18) {
  printf("10대 입니다");
} else if (age >= 18 && age < 30) {
  printf("20대 입니다");
} else if (age >= 30 && age < 40) {
  printf("30대 입니다");
} else {
  printf("40대 이상입니다");
}
// 20대 입니다
```
