# 입력 받기

scanf() 함수로 사용자로부터 입력을 받을 수 있습니다. scanf 함수의 첫번째 인자는 변수의 포맷 지정자이고 두번째 인자는 변수의 주소입니다.

```c
int age;

printf("나이를 입력하세요: ");
scanf("%d", &age);

printf("당신의 나이: %d", age);
```


문자열을 입력받을 때 문자열을 저장할 변수의 크기가 부족하지 않도록 사전에 잘 고려해야 합니다. 문자열을 입력받을 때는 변수 이름 앞에 &(참조 연산자)를 사용할 필요가 없습니다


```c
char name[10];

printf("이름을 입력하세요: ");

scanf("%s", name);

printf("안녕 %s", name);

// 안녕 John
```
