# 변수

변수는 프로그래밍에서 값을 저장하는 역할을 합니다.

다음은 변수를 선언하는 방법입니다
```
자료형 변수이름 = 값
```


# 변수 생성하기

다음은 정수형 변수에 값을 대입하는 코드입니다.

```c
int a = 1
int b = 2
```

만약 여러 개의 변수들이 같은 자료형이라면 콤마를 활용하여 코드를 줄일 수도 있습니다.

```c
int x = 5, y = 6, z = 50;
```


# 변수 수정하기

변수는 이름처럼 언제든지 값을 바꿀 수 있습니다. 

```c
int myNum = 15;  

myNum = 10;  
```


# 사용자 입력값 저장하기

아래는 정수형 변수 myNum을 먼저 선언하고 나중에 값을 대입하는 과정입니다.

변수에 사용자 입력값을 저장하는 경우 등에 유용합니다.


```c
int myNum;

// 사용자 입력
myNum = 15;
```
