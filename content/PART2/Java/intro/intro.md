# Java 인트로

자바의 모든 코드는 클래스 내에서 작성되어야 합니다.
main메서드는 프로그램의 시작점이며 프로그램마다 하나만 가집니다.

```java
public class Main {
  public static void main(String[] args) {
    // 주석
    System.out.print("Hello World");
  }
}
```

다음은 주요 출력 메서드입니다.

System.out.print: 현재 줄에 데이터를 출력합니다.
System.out.println: 새로운 줄에 데이터를 출력합니다
