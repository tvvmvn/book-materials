# Range

- Range 소개
- Range 생성하기
- 요소에 접근하기
- 요소 자르기


Range는 수정할 수 없는 숫자의 모음들로 구성된 자료 구조입니다.
반복문과 조합하여 주로 사용됩니다.


# Range 생성하기

생성자로 Range를 생성합니다. 문법은 다음과 같습니다

```
range(시작, 끝, 간격)

- 시작: 선택 사항이며 기본값은 0입니다
- 끝: 필수 사항입니다. 
- 간격: 선택 사항이며 기본값은 1입니다

시작부터 끝 - 1 까지 정해진 간격으로 숫자 모음을 생성합니다.
모든 인수값은 정수여야 합니다/
```

다음은 Range를 만드는 기본 과정입니다

```python
r = range(10)
# 0, 2, 3, ... 9
```


다음은 시작을 추가한 Range 생성 과정입니다

```python
r = range(1, 10)
# 1, 2, 3, ... 9
```


다음은 시작과 간격을 추가한 Range 생성 과정입니다

```python
r = range(1, 10, 2)
# 1, 3, 5, 7, 9
```


# Range의 요소 개수 구하기

Range에서 요소의 개수를 길이(length)라고 부릅니다. len() 함수로 요소의 개수를 구할 수 있습니다

```python
r = range(10)

print(len(r))
# 10
```


## 리스트로 변환하기

Range 타입을 다루기 좋은 리스트로 형 변환을 하여 사용하기도 합니다.
(대표적으로 Range 타입의 변수는 직접 출력시 원소 확인이 불가능합니다) 
방법은 간답합니다. list 생성자에 range를 전달하면 됩니다. 


```python
print(list(range(5)))
# [0, 1, 2, 3, 4]
```
