# 예외

프로그램 실행 도중에 발생하는 오류를 예외(exception)이라고 합니다.
예외는 프로그램을 중단시키므로 반드시 처리해야 합니다.

다음은 예외를 처리하는 문법입니다
```
try:
  일반 코드를 작성합니다
except:
  예외가 발생할 경우 예외를 처리 할 코드를 작성합니다
```


아래 코드에서 변수 x가 생성된 적이 없는데 출력을 시도했기 때문에 예외가 발생합니다.
예외 처리가 없기 때문에 프로그램이 중단될 것입니다.

```py
print(x)
```


위와 같은 코드에서 이번엔 예외를 처리하는 부분을 추가했습니다. 따라서 프로그램은 중단되지 않으며 사용자에게 예외가 발생했다는 사실을 알립니다.

```py
try:
  print(x)
except:
  print("예외가 발생했습니다")
```


# finally

finally 코드는 예외의 발생 여부와는 상관없이 실행됩니다. 예외 처리문에서 최종적으로 실행하고 싶은 코드가 있을 경우 작성합니다

```py
try:
  print(x)
except:
  print("예외가 발생했습니다")
finally:
  print("예외 처리문을 종료합니다")
```


# raise

필요한 경우 예외를 의도적으로 발생시킬 수 있습니다. 다음은 비밀번호가 일치하지 않는 경우 예외를 발생시키는 코드입니다.

```py
password = 123

try:
  if password != 1234:
    raise Exception(1)
except:
  print("비밀번호 오류")
```
