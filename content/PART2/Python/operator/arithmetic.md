# 산술

수학적 연산을 수행할 때 사용됩니다.

1. +(더하기) 덧셈 연산을 수행합니다
예) 1 + 2 = 2

2. -(빼기) 빼기 연산을 수행합니다
예) 5 - 2  = 3

3. *(곱하기) 곱하기 연산을 수행합니다
예) 5 * 2 = 10

4. /(나누기) 나누기 연산을 수행합니다
예) 5 / 2 = 2.5

5. //(몫) 나눗셈을 수행 후 몫을 구합니다
예) 5 // 2 = 2

6. %(나머지) 나눗셈을 수행 후 나머지를 구합니다
예) 5 % 2 = 1

7. **(거듭제곱) 거듭 제곱 연산을 수행합니다
예) 5 ** 2 = 25
