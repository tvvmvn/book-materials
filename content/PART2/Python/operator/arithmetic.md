# 산술 연산자

수학적 연산을 수행할 때 사용됩니다

1. + (더하기 연산자)
덧셈 연산을 수행합니다
예) 1 + 2 는 3을 반환합니다

2. - (빼기 연산자)
빼기 연산을 수행합니다
예) 5 - 2 는 3을 반환합니다

3. * (곱하기 연산자)
곱하기 연산을 수행합니다
예) 5 * 2 는 10을 반환합니다

4. / (나누기 연산자)
나누기 연산을 수행합니다
예) 5 / 2 는 2.5를 반환합니다

5. // (몫 연산자)
나눗셈을 수행 후 몫을 구합니다
예) 5 // 2 는 2를 반환합니다

6. % (나머지 연산자)
나눗셈을 수행 후 나머지를 구합니다
예) 5 % 2 는 1을 반환합니다

7. ** (거듭제곱 연산자)
거듭 제곱 연산을 수행합니다
예) 5 ** 2 는 25를 반환합니다
