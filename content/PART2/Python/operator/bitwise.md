# Bitwise Operators

숫자를 2진수로 변환한 다음 비트 단위로 연산합니다

1. & (and)
두 값이 모두 1이면 1을 저장합니다

예) x & y 

2. | (or)
두 값중 하나가 1이면 1을 저장합니다

예) x | y 

3. ^ (xor)
두 값중 하나만 1인 경우 1을 저장합니다

예) x ^ y 

4. ~ (not)
모든 비트를 뒤집습니다

예) ~x 

5. << (왼쪽 시프트)
입력한 수 만큼 0의 개수를 오른쪽에 삽입합니다. 이에 따라 왼쪽의 비트는 삽입된 비트만큼 떨어져 나갑니다.

예) x << 2 

6. >> (오른쪽 시프트)
이진수에서 첫번째 값에 해당하는 비트를 왼쪽에 삽입합니다. 이에 따라 오른쪽 비트는 삽입된 비트만큼 떨어져 나갑니다

예) x >> 2


```python
print(5 & 2) # 0
print(5 | 2) # 7
print(5 ^ 2) # 7
print(~5) # -6
print(5 << 2) # 20
print(5 >> 2) # 1
```
