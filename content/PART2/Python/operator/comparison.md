# 비교 연산자

두 값을 비교하는 연산을 수행합니다. 불리언 타입의 값을 반환합니다

1. == (동등 연산자)
두 값이 같으면 참, 다르면 거짓을 반환합니다
예) x == y

2. != (비동등 연산자)
두 값이 다르면 참, 다르면 거짓을 반환합니다
예) x != y

3. > (gt 연산자)
왼쪽 숫자가 크면 참, 아니면 거짓을 반환합니다
예) x > y

4. < (lt 연산자)
왼쪽 숫자가 작으면 참, 아니면 거짓을 반환합니다
예) x < y

5. >= (gte 연산자)
왼쪽 숫자가 더 크거나 둘이 같으면 참, 아니면 거짓을 반환합니다.
예) x >= y

6. <= (lte 연산자)
왼쪽 숫자가 더 작거나 둘이 같으면 참, 아니면 거짓을 반환합니다.
예) x <= y
