# 배열 (Array)

자료형이 동일한 구성 요소들이 차례대로 나열된 자료 집합입니다. 

*그림 - 배열*

그렇다면 배열은 어디에 사용될까요? 일련의 목록 형태들이 배열로 표현될 수 있습니다. 예를 들어 매출 데이터나 게시물 목록 등. 특히 2차원 배열을 사용하면 표(Table)의 형태를 표현할 수도 있어 활용도가 높습니다.


# 물리적 구조와 코드 구현

배열에서 구성 요소들이 메모리 상에서 일렬로 붙어 있습니다. 각 요소는 고유한 인덱스(Index)를 가지며 인덱스를 알면 특정 요소에 한번에 접근할 수 있습니다.

물리적으로 붙어있기 때문에 중간에 자료를 삽입하거나 특정 요소를 삭제하는 등의 작업을 하기 어렵습니다. 반면 구성 요소들을 활용하여 반복적인 작업을 할 때에는 이 특징이 장점이 됩니다.

*그림 - 메모리 상에서의 배열 모습*

다음은 배열을 선언하고 인덱스로 특정 요소에 접근하는 C 언어 프로그램입니다.

```c
#include <stdio.h>

int main() {
  int arr[] = {5, 12, 9, 4, 10};

  printf("첫번째 요소: %d\n", arr[0]);
  printf("두번째 요소: %d\n", arr[1]);
  printf("마지막 요소: %d\n", arr[4]);

  return 0;
}

// 첫번째 요소: 5
// 두번째 요소: 12
// 마지막 요소: 10
```


# 정렬 알고리즘

배열의 요소를 정렬하는 알고리즘입니다.

- 버블 정렬 (Bubble Sort)
- 선택 정렬 (Selection Sort)
- 삽입 정렬 (Insertion Sort)
- 퀵 정렬 (Quick Sort)
- 힙 정렬 (Heap Sort)
- 2Way 합병 정렬 (2Way Merge Sort)


# 버블 정렬

오른쪽으로 진행하며 인접한 두 개의 레코드 값을 비교하고 비교 결과에 따라 레코드의 위치를 서로 교환합니다. 

다음은 배열 {8, 5, 6, 2, 4}를 버블 정렬 알고리즘으로 정렬하는 과정입니다.

```
1회
{8, 5, 6, 2, 4} => 1, 2 비교 
{5, 8, 6, 2, 4} => 2, 3 비교
{5, 6, 8, 2, 4} => 3, 4 비교
{5, 6, 2, 8, 4} => 4, 5 비교
{5, 6, 2, 4, 8}

2회
{5, 6, 2, 4, 8} => 1, 2 비교
{5, 6, 2, 4, 8} => 2, 3 비교
{5, 2, 6, 4, 8} => 3, 4 비교
{5, 2, 4, 6, 8}

3회
{5, 2, 4, 6, 8} => 1, 2 비교
{2, 5, 4, 6, 8} => 2, 3 비교
{2, 4, 5, 6, 8}

4회
{2, 4, 5, 6, 8} => 1, 2 비교 
{2, 4, 5, 6, 8} 
```


# 선택 정렬

n개의 레코드 중에서 최소값을 찾아 첫번째 레코드 위치에 놓고 나머지 (n - 1)개 중에서 다시 최소값을 찾아 두번째 레코드 위치에 놓는 작업을 반복합니다. 

다음은 배열 {8, 5, 6, 2, 4}를 선택 정렬 알고리즘으로 정렬하는 과정입니다.

```
1회
{8, 5, 6, 2, 4} => 1, 2 비교
{5, 8, 6, 2, 4} => 1, 3 비교
{5, 8, 6, 2, 4} => 1, 4 비교
{2, 8, 6, 5, 4} => 1, 5 비교
{2, 8, 6, 5, 4}

2회
{2, 8, 6, 5, 4} => 2, 3 비교
{2, 6, 8, 5, 4} => 2, 4 비교
{2, 5, 8, 6, 4} => 2, 5 비교
{2, 4, 8, 6, 5} 

3회
{2, 4, 8, 6, 5}  => 3, 4 비교
{2, 4, 6, 8, 5}  => 3, 5 비교
{2, 4, 5, 8, 6}  

4회 
{2, 4, 5, 8, 6} => 4, 5 비교
{2, 4, 5, 6, 8} 
```


# 삽입 정렬

레코드를 이전 값들과 각각 비교하고 비교한 값이 더 큰 경우 레코드를 비교한 값 자리에 삽입합니다. 

다음은 배열 {8, 5, 6, 2, 4}를 삽입 정렬 알고리즘으로 정렬하는 과정입니다.

```
1회
{8, 5, 6, 2, 4} => 1, 2 비교
{5, 8, 6, 2, 4} 

2회
{5, 8, 6, 2, 4} => 1, 3 비교
{5, 8, 6, 2, 4} => 2, 3 비교
{5, 6, 8, 2, 4} 

3회
{5, 6, 8, 2, 4} => 1, 4 비교
{2, 5, 6, 8, 4} => 2, 4 비교
{2, 5, 6, 8, 4} => 3, 4 비교
{2, 5, 6, 8, 4}

4회
{2, 5, 6, 8, 4} => 1, 5 비교
{2, 5, 6, 8, 4} => 2, 5 비교
{2, 4, 5, 6, 8} => 3, 5 비교
{2, 4, 5, 6, 8} => 4, 5 비교
{2, 4, 5, 6, 8} 
```

# 기타 정렬 알고리즘

퀵 정렬은 키를 기준으로 작은 값은 왼쪽, 큰 값은 오른쪽 서브 파일에 분해시키는 과정을 반복합니다. 레코드의 많은 자료 이동을 없애고 하나의 파일을 부분적으로 나누어가면서 정렬합니다.

힙 정렬은 완전 이진 트리(Complete Binary Tree)를 이용한 정렬 알고리즘입니다. 구성된 완전 이진 트리를 힙 트리(Heap Tree)로 변환하고 정렬합니다.

2Way 합병 정렬은 이미 정렬되어 있는 두 개의 파일을 한 개의 파일로 합병하는 정렬 알고리즘입니다.


# C 언어로 구현한 버블 정렬

```c
#include <stdio.h>

int main() {
  int arr[] = {64, 34, 25, 12, 22, 11, 90, 5};
  int n = sizeof(arr) / sizeof(arr[0]);

  for (int i = 0; i < n-1; i++) {
    for (int j = 0; j < n-i-1; j++) {
      if (arr[j] > arr[j+1]) {
        int temp = arr[j];
        arr[j] = arr[j+1];
        arr[j+1] = temp;
      }
    }
  }

  printf("결과: ");
  for (int i = 0; i < n; i++) {
    printf("%d ", arr[i]);
  }
  printf("\n");

  return 0;
}

// 결과: 5 11 12 22 25 34 64 90
```
