# INSERT INTO

INSERT INTO는 테이블에 레코드를 추가하는 명령어입니다. 

```sql
INSERT INTO 테이블_이름 (컬럼1, 컬럼2, 컬럼3, ...)
VALUES (컬럼1 값, 컬럼2 값, 컬럼3 값, ...);
```
만약 삽입할 때 모든 컬럼의 값을 지정한다면 컬럼 이름을 명시하지 않아도 됩니다.


예제)
다음의 컬럼들로 구성된 테이블 <학생>이 있을 때

- 이름
- 학년
- 성별
- 이메일

다음은 3개의 컬럼 값을 지정하고 새 레코드를 추가하는 명령문입니다. 지정되지 않은 컬럼들의 값은 NULL이거나 기존에 지정한 기본값이 적용됩니다.

```sql
INSERT INTO 학생 (이름, 학년, 이메일) VALUES ('김철수', 1, 'kim@example.com');
```

다음은 모든 컬럼 값을 지정하고 삽입하는 명령문입니다.
```sql
INSERT INTO 학생 VALUES ('김철수', 1, '남', 'kim@example.com');
```
