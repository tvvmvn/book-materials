# 집계 함수

주로 GROUP BY (HAVING) 명령어와 함께 쓰이며 그룹을 대상으로 여러 연산을 수행할 수 있습니다. COUNT를 제외한 집계 함수는 인자가 NULL인 레코드는 무시합니다?

- MIN
- MAX
- COUNT
- SUM
- AVG

```sql
SELECT 집계 함수 GROUP BY 컬럼 HAVING 그룹 필터링 조건
```


# MIN() & MAX()

레코드들로부터 제시한 컬럼의 최소값과 최대값을 구하는 함수입니다.

예제)
다음은 <제품> 테이블에서 가장 비싼 상품의 가격을 추출하는 명령문입니다.

```sql
SELECT MAX(가격) FROM 제품;
```


# COUNT()

주어진 컬럼을 포함한 레코드의 개수를 세는 함수입니다. COUNT 에서 *(와일드카드) 대신 컬럼을 지정하면 지정된 컬럼이 NULL값이 레코드는 제외합니다.

예제)
다음은 테이블 <제품>에서 총 레코드의 개수를 구하는 명령문입니다.
```sql
SELECT COUNT(*) FROM 제품;
```

예제)
제품 이름이 NULL인 레코드들은 제외하고 개수를 셉니다.
```sql
SELECT COUNT(제품 이름) FROM 제품;
```

예제)
다음은 <고객>테이블에서 도시별 고객의 수를 추출하는 명령문입니다.
```sql
SELECT 도시, COUNT(고객 ID) FROM 고객
GROUP BY 도시;
```

예제)
다음은 <고객>에서 도시별 고객의 수를 추출하는 명령문입니다. 단 고객의 수가 10명 이상인 도시의 정보만 조회합니다.
```sql
SELECT 도시, COUNT(고객 ID) FROM 고객
GROUP BY 도시 HAVING COUNT(도시) > 10;
```


# SUM()

레코드들로부터 주어진 컬럼의 합을 구하는 함수입니다.

예제)
다음은 <주문 정보>에서 총 주문 수량을 구하는 명령문입니다.
```sql
SELECT SUM(수량) FROM 주문 정보;
```


# AVG()

레코드들로부터 주어진 컬럼의 평균을 구하는 함수입니다.

예제)
다음은 <제품>으로부터 모든 제품의 평균 가격을 구하는 명령문입니다.
```sql
SELECT AVG(가격) FROM 제품;
```
