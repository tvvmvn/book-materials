# 조인 (Join)

- 내부 조인 (Inner Join)
- 외부 조인 (Outer Join)


# 내부 조인

두 테이블을 대상으로 교차곱을 수행한 다음 ON에 명시된 조건을 만족하는 레코드를 추출합니다.

```sql
... FROM 테이블1 JOIN 테이블2
ON 테이블1.컬럼 = 테이블2.컬럼;
```

예시)
다음과 같이 <상품>, <카테고리> 테이블이 있을 때 상품들을 카테고리의 이름과 함께 조회하고 싶을 때 적합한 명령문입니다. 

<상품> [상품ID, 상품명, 카테고리ID, 가격]
<카테고리> [카테고리ID, 카테고리 이름]

```sql
SELECT * FROM 상품 JOIN 카테고리 
ON 제품.카테고리ID = 카테고리.카테고리ID;
```
실행 결과: [상품ID, 상품명, 카테고리ID, 가격, 카테고리ID, 카테고리 이름]


# 외부 조인

- LEFT JOIN
- RIGHT JOIN
- FULL JOIN


# LEFT JOIN

INNER JOIN을 수행후 왼쪽 테이블에서 조건을 만족하지 않는 레코드들을 포함시킵니다. 이렇게 포함된 레코드들은 오른쪽 테이블에 속한 컬럼값으로 NULL을 가집니다.

```sql
... FROM 테이블1 LEFT JOIN 테이블2
ON 테이블1.컬럼 = 테이블2.컬럼;
```

예시)
다음은 고객별로 주문 상세정보를 알고싶을 때 적합한 명령문입니다. 
주문이 없는 고객도 포함시킵니다.

<고객> [고객ID, 이름, 주소]
<주문> [주문ID, 주문 날짜, 고객ID]

```sql
SELECT * FROM 고객 LEFT JOIN 주문
ON 고객.고객ID = 주문.고객ID
```
실행 결과: [고객ID, 이름, 주소, 주문ID, 주문 날짜, 고객ID]


# RIGHT JOIN

INNER JOIN을 수행 후 오른쪽 테이블에서 조건을 만족하지 않는 레코드들을 포함시킵니다. 이렇게 포함된 레코드들은 왼쪽 테이블에 속한 컬럼값으로 NULL을 가집니다.

```sql
...
FROM 테이블1 RIGHT JOIN 테이블2
ON 테이블1.컬럼 = 테이블2.컬럼;
```


# FULL JOIN

FULL JOIN은 내부 조인 결과에 왼쪽 테이블과 오른쪽 테이블에서 ON에 명시된 조건을 만족하지 않는 레코드들도 전부 포함시키는 명령어입니다. 이때 연결로 인해 발생한 레코드상의 추가적인 컬럼들은 NULL 값을 가집니다.

```sql
...
FROM 테이블1 FULL JOIN 테이블2
ON 테이블1.컬럼 = 테이블2.컬럼;
```
