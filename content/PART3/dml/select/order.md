# ORDER BY

추출할 레코드의 순서를 정렬하는 명령어입니다.
정렬 명령을 따로 명시하지 않으면 문자는 알파벳순, 숫자는 오름차순으로 정렬됩니다.

```sql
FROM 테이블 ORDER BY 컬럼1, 컬럼2, ... ASC|DESC;
```

예제)
다음은 '제품 이름'을 기준으로 레코드를 알파벳순으로 정렬하고 추출하는 명령문입니다.
```sql
SELECT * FROM 제품 ORDER BY 제품 이름;
```

예제)
다음은 '가격'을 기준으로 내림차순으로 정렬하고 추출하는 명령문입니다.
```sql
SELECT * FROM 제품 ORDER BY 가격 DESC;
```

예제)
여러 개의 컬럼을 기준으로 정렬하는 경우를 생각해봅시다. 우선 '도시'를 기준으로 오름차순 정렬합니다. 그리고 '도시'가 같은 레코드들을 '고객 이름'을 기준으로 오름차순 정렬합니다. 
```sql
SELECT * FROM 고객 ORDER BY 도시, 고객 이름;
```

예제)
다음은 우선 '도시'를 기준으로 오름차순 정렬합니다. 그리고 '도시'가 같은 레코드들을 '고객 이름'을 기준으로 내림차순 정렬합니다.
```sql
SELECT * FROM 고객
ORDER BY 도시 ASC, 고객 이름 DESC;
```
