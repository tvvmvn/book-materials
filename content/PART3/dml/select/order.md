# ORDER BY

추출할 레코드의 순서를 정렬하는 명령어입니다. 정렬 명령을 따로 명시하지 않으면 문자는 알파벳순, 숫자는 오름차순으로 정렬됩니다.

```sql
... FROM 테이블 ORDER BY 컬럼1, 컬럼2, ... ASC|DESC;
```

예제)
다음은 <학생> 테이블에서 '이름'을 기준으로 알파벳순으로 정렬하고 추출하는 명령문입니다.
```sql
SELECT * FROM 학생 ORDER BY 이름;
```

예제)
다음은 '이름'을 기준으로 역 알파벳순으로 정렬하고 추출하는 명령문입니다.
```sql
SELECT * FROM 학생 ORDER BY 이름 DESC;
```

예제)
여러 개의 컬럼을 기준으로 정렬하는 경우를 생각해봅시다. 우선 '이름'을 기준으로 정렬합니다. 그리고 '이름'이 같은 레코드 그룹에서 '나이'를 기준으로 정렬합니다. 
```sql
SELECT * FROM 학생 ORDER BY 이름, 나이;
```

예제)
다음은 우선 '이름'을 기준으로 알파벳순으로 정렬합니다. 그리고 '이름'가 같은 레코드들을 '나이'을 기준으로 내림차순 정렬합니다.
```sql
SELECT * FROM 학생
ORDER BY 이름 ASC, 나이 DESC;
```
