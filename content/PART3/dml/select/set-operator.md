# 집합 연산 (Set Operation)

집합 연산에 참여하는 두 테이블은 컬럼의 개수가 일치해야 합니다. 또한 각 컬럼의 자료형이 일치해야 합니다.

```sql
테이블A(SELECT문 결과) 집합_연산자 테이블B(SELECT문 결과)
```

다음은 SQL의 집합 연산자입니다.

- UNION 
- UNION ALL 
- INTERSECT 
- EXCEPT 


# UNION

합집합 연산자입니다. 두 테이블의 레코드들을 합친 후 중복되는 행은 삭제합니다. 참여한 컬럼들의 값이 모두 일치하면 중복된 것으로 봅니다.


예제)
다음 명령문은 <인사부>, <영업부>로부터 '이름', '나이'들을 추출합니다. 만약 이름과 나이가 같은 직원이 있다면 한명만 추출됩니다.
```sql
SELECT 이름, 나이 FROM 인사부
UNION
SELECT 이름, 나이 FROM 영업부
```


# UNION ALL

UNION와 기본적으로 같은 연산이지만 중복된 행도 포함시킵니다.

예제)
다음 명령문은 <인사부>, <영업부>로부터 '이름', '나이'를 추출합니다. 이름과 나이가 같은 직원이 있어도 모두 나타납니다.
```sql
SELECT 이름, 나이 FROM 인사부
UNION
SELECT 이름, 나이 FROM 영업부
```


# INTERSECT

두 SELECT 문의 조회 결과 중 공통된 행만 출력합니다.

예제)
다음은 <인사부>, <영업부>에 공통적으로 있는 '이름'를 알고싶을 때 적절한 명령문입니다.
```sql
SELECT 이름 FROM 인사부
INTERSECT
SELECT 이름 FROM 영업부;
```


# EXCEPT

첫번째 SELECT문의 조회 결과에서 두번째 SELECT문의 조회 결과를 제외한 행을 출력합니다.
